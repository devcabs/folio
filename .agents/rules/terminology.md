# Rule: Canonical Terminology

## Applications Built with `folio-engine`
- **Term**: **Consumers** (singular: **Consumer**)
- **Usage**: Refer to applications built with or powered by `@devcabs/folio-engine` as **Consumers** (or a **Consumer**).
  - Examples: *"Publish a Consumer"*, *"All Consumers share..."*, *"Migrating your Consumer to v0.2"*.
- **Distinction**:
  - **Folio Engine** (`@devcabs/folio-engine`): The underlying installable React 19 engine and component library.
  - **Consumer** / **Consumers**: The applications built on top of Folio Engine.
