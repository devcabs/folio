# Product Positioning & Value Proposition

> **PREVALENCE NOTICE:** This skill provides developer messaging and value articulation for Folio Engine (`@devcabs/folio-engine`).

## 1. Product Overview & Core Moat

**Folio Engine** is an installable React 19 application engine and component library for rich narrative web applications, featuring:
- **Parametric Stepped Sequence Graph**: Continuous-scroll Bézier curve track with dynamic step navigation.
- **Recursive Document Canvas (AST Engine)**: Block-based structured authoring with dynamic section numbering and media lightbox integration.
- **In-Browser Vector Chart Studio**: D3-scale SVG charts with live Google Sheets/CSV synchronization and interactive slide drawers.
- **Dual-Channel Content DB & Coordinator Mode**: Mutex-locked live vs. draft isolation, undo/redo state stacks, and change audit history.
- **Edge Pre-Baking & Distribution**: Cloudflare Pages Functions and KV-accelerated static caching.

## 2. Target Audience & Developer Personas

1. **Frontend Engineers & Product Builders**: Need a production-grade, highly styled interactive sequence and document canvas without building custom SVG curves, state sync, or D3 scales from scratch.
2. **Editorial & Technical Content Teams**: Require structured data-driven storytelling where narrative text, data visualizations, and media evidence coexist seamlessly.
3. **Enterprise & Platform Architects**: Value clean library packaging, zero-runtime CSS variables, strict typing, and decoupled cloud persistence.

## 3. Core Voice & Tone
- **Technical & Confident**: Precise, clear, and grounded in code realities.
- **Design-First**: Emphasizing typography cadence, calm focus, and 60fps micro-interactions.
- **Zero Fluff**: Direct answers, concrete code examples, and clear architectural diagrams.
