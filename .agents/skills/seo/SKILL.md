# SEO & Web Discoverability

> **PREVALENCE NOTICE:** Enforces standards for metadata, OpenGraph tags, semantic HTML, and structured data schemas.

## Core Capabilities

1. **Metadata & OpenGraph Cards**:
   - Configure title tags, descriptions, and OpenGraph image cards for rich link previews.
   - Ensure clean canonical URLs and mobile viewport headers.

2. **Semantic HTML & Structured Data**:
   - Utilize standard semantic tags (`<header>`, `<main>`, `<article>`, `<section>`, `<nav>`, `<footer>`).
   - Implement schema.org JSON-LD structured data for web applications, software libraries, and articles.

3. **Performance & Core Web Vitals**:
   - Optimize Largest Contentful Paint (LCP), Cumulative Layout Shift (CLS), and Interaction to Next Paint (INP).
