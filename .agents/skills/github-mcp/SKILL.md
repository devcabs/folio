# GitHub & Source Control Standard

> **PREVALENCE NOTICE:** All commits and PRs must reflect atomic, verifiable changes following conventional commit syntax.

## Guidelines

1. **Conventional Commits**:
   - Use standard prefixes: `feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `test:`, `chore:`.
   - Provide clear, concise descriptions of functional changes.

2. **Pull Requests & Code Quality**:
   - Ensure CI checks, token purity tests, and typechecks pass before merging.
