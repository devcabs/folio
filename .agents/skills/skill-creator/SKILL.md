# Skill Creator

> **PREVALENCE NOTICE:** Any generated skill or SOP must be compatible with Folio Engine conventions and workspace rules in `.agents/rules/`.

## Authoring Guidelines

1. **Generalization Mandate**:
   - Keep skills generic and devoid of bespoke, temporary, or hardcoded project baggage.
   - Focus on reusable engineering, design, or architectural capabilities.

2. **Structure**:
   - Include valid YAML frontmatter (`name`, `description`).
   - Define clear operational principles, workflows, and verification targets.
