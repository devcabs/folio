## 🎯 Purpose & Scope

Eliminate long connection stalls and broken image icons in `src/components/canvas/CanvasPhoto.tsx` caused by direct fallback swaps to raw Google Drive URLs (`https://drive.google.com/thumbnail?id=...`).

When an image fails to load through the Edge Media Proxy (`/api/media/drive/:fileId`), the current implementation attempts to fall back to Google Drive's thumbnail API. Because Google Drive enforces strict authentication, CORS headers, and third-party cookie restrictions, these requests stall connection pools for 5–15 seconds before failing, ultimately leaving an ugly browser-native broken image icon.

This task replaces direct Drive thumbnail fallbacks with an immediate, token-styled photographic fallback card that preserves layout geometry and provides clear diagnostics.

---

## 🔍 Problem Statement

In `src/components/canvas/CanvasPhoto.tsx` (lines 101–110):
```ts
  const handleImageError = useCallback(() => {
    if (driveFileId) {
      const fallbackUrl =
        currentPhoto.rawDriveUrl ||
        `https://drive.google.com/thumbnail?id=${encodeURIComponent(driveFileId)}&sz=w1600`;
      if (activeImgSrc !== fallbackUrl) {
        setActiveImgSrc(fallbackUrl);
      }
    }
  }, [driveFileId, currentPhoto.rawDriveUrl, activeImgSrc]);
```

### The Stalling Chain:
1. Edge proxy `/api/media/drive/:fileId` fails (e.g. file deleted, permissions revoked).
2. `handleImageError` triggers and sets `src` to `drive.google.com/thumbnail?id=...`.
3. The browser attempts to load from Google Drive.
4. Google Drive responds with 403 Forbidden or blocks cross-origin requests.
5. The request hangs the HTTP/2 connection slot for several seconds.
6. The second error has no handler, resulting in a broken image icon and collapsed container.

### Step 1: Update State in `src/components/canvas/CanvasPhoto.tsx`

```tsx
const [hasLoadError, setHasLoadError] = useState(false);

// Reset error state if image src changes
useEffect(() => {
  setHasLoadError(false);
  setActiveImgSrc(initialSrc);
}, [initialSrc]);

const handleImageError = useCallback(() => {
  // Never swap to raw Google Drive URLs that stall browser connections!
  setHasLoadError(true);
}, []);
```
