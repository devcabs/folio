## 🎯 Purpose & Scope

Eliminate the jarring ~100ms flash of default system baseline content during cold public page loads. Because the project strictly enforces a `< 5 KB` Zero-LocalStorage document policy (purging bloated canvas ASTs on startup), cold public visits have no cached canvas document in `localStorage`. 

Currently, `getNodeCanvas(nodeId, false)` defaults to the hardcoded System Baseline, which renders briefly before being replaced by the Cloudflare Edge KV fetch `/api/public/node/:nodeId`. This task introduces an `isHydrating` state and renders a token-styled ghost skeleton wireframe until the edge document resolves, ensuring zero layout shift (CLS = 0) and zero content flashing.

---

## 🔍 Problem Statement

In `src/hooks/useDocumentCanvas.ts` and `src/components/canvas/NodeCanvas.tsx`:
1. For public visitors (`isDevMode = false`), `getNodeCanvas(nodeId, false)` runs on mount.
2. Because `purgeLegacyDocumentStorage()` runs at module load, `localStorage` has no document.
3. `getNodeCanvas` falls back to `createDefaultCanvasDocument(nodeId)`.
4. The page paints the default 6-year baseline sections and titles.
5. In the background, `fetch('/api/public/node/' + nodeId)` completes in 30–80ms and re-renders the real published sections.
6. This produces a noticeable content "jump" and visual flicker on every cold visitor page load.

## 🛠️ Step-by-Step Implementation Instructions

### Step 1: Add `isHydrating` to `useDocumentCanvas.ts`

In `src/hooks/useDocumentCanvas.ts`:
```ts
export interface UseNodeCanvasReturn {
  document: NodeCanvasDocument;
  isPending: boolean;
  isHydrating: boolean; // Add this
  ...
}

export function useDocumentCanvas(nodeId: string): UseNodeCanvasReturn {
  const { isDevMode } = useDeveloperMode();
  const [isHydrating, setIsHydrating] = useState<boolean>(() => !isDevMode && typeof window !== 'undefined');

  // In the Edge hydration useEffect:
  useEffect(() => {
    if (!isDevMode && nodeId) {
      let isCancelled = false;

      fetch(`/api/public/node/${nodeId}`)
        .then(res => res.ok ? res.json() : null)
        .then(edgeData => {
          if (isCancelled) return;
          if (edgeData?.canvas && Array.isArray(edgeData.canvas.sections)) {
            documentRef.current = edgeData.canvas;
            startTransition(() => {
              setDocument(edgeData.canvas);
            });
          }
        })
        .finally(() => {
          if (!isCancelled) {
            setIsHydrating(false);
          }
        });

      return () => { isCancelled = true; };
    } else {
      setIsHydrating(false);
    }
  }, [nodeId, isDevMode]);
```
