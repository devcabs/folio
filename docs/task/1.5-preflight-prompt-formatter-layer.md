## 🎯 Purpose & Scope

Extract AI prompt generation out of the migration service and into a dedicated, side-effect-free utility. A service that handles domain logic (semver comparison, watermark persistence, migration diffing) must not also own presentation/formatting concerns. Isolating the formatter enables independent unit testing, easy extension for new AI agent formats, and future i18n support — without touching the domain service.

---

## 🔍 Problem Statement

Task 1.11 specifies `generateAiMigrationPrompt()` as a method on `migrationService.ts`. A service that handles domain logic (semver comparison, watermark persistence, migration diffing) should not also own presentation/formatting concerns. String template changes, new AI agent formats (Cursor vs Claude vs Antigravity), or i18n would require touching a domain service. This violates single-responsibility and makes the formatter untestable in isolation.

---

## 📄 Key Files to Create / Modify

1. **`src/utils/migrationPromptFormatter.ts`** *(New)*
   - `generateAiMigrationPrompt(report: PendingMigrationReport, options?: { agentHint?: 'claude' | 'cursor' | 'antigravity' | 'generic' }): string`
     - **Pure function** — zero side effects, no imports from service files, no imports from context files.
     - Formats a structured GitHub-flavored Markdown string containing:
       - `# AI Migration Prompt` header.
       - Engine version transition subtitle: `Updating from v{contentVersionWatermark} → v{currentEngineVersion}`.
       - Numbered list of `pendingContentChanges`, each containing:
         - `## {index}. {title}` heading.
         - `**Required:** Yes/No` status.
         - `**Affected Entities:** {affectedEntities.join(', ')}` (omit if empty).
         - Description paragraph.
         - `**Instructions:**\n{migrationPrompt}` block (omit if `migrationPrompt` is undefined).
       - Footer block:
         ```
         <!-- Generated by @devcabs/folio-engine migrationService -->
         ```
     - Accepts `PendingMigrationReport` type from `src/types/migration.ts` — the only allowed import.
     - `agentHint` is reserved for future format variations; for now all hints produce the same output.

2. **`src/services/migrationService.ts`** *(Pre-wire for 1.11)*
   - `generateAiMigrationPrompt` is **NOT** implemented in the service.
   - The service may optionally re-export `generateAiMigrationPrompt` from `src/utils/migrationPromptFormatter.ts` for convenience:
     ```ts
     export { generateAiMigrationPrompt } from '../utils/migrationPromptFormatter';
     ```
   - But the service must not contain its own implementation of the formatting logic.

3. **`src/index.ts`** *(Modify)*
   - Export `generateAiMigrationPrompt` directly from `./utils/migrationPromptFormatter`.
