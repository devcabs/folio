## 🎯 Purpose & Scope

1. **Purge Cold-Miss KV Poisoning:** Stop `src/edge/handlers/publicHandler.ts` from permanently writing synthetic empty canvases (`sections: []`) and fake snapshot manifests into Cloudflare KV on cache misses.
2. **Purge Client Credential Leaks:** Remove `CLOUDFLARE_API_TOKEN` and direct `api.cloudflare.com` REST invocations from client-side accessible modules in `src/services/edgePreBakeService.ts`.
3. **Fix CDN Cache Stale Lag:** Update Cache-Control on `/api/public/manifest` from `s-maxage=86400` (24-hour delay) to `max-age=0, must-revalidate` so newly published snapshots are visible worldwide immediately upon publication.

---

## 🔍 Problem Statement

1. **The Poisonous Cold-Miss Fallback:** In `src/edge/handlers/publicHandler.ts#L145-L147` and `L206-L208`:
   When a node or manifest is not found in KV, the handler constructs an empty canvas (`sections: []`) or empty manifest and executes:
   ```ts
   if (kv && ctx && typeof ctx.waitUntil === 'function') {
     ctx.waitUntil(kv.put(kvKey, fallbackString));
   }
   ```
   This permanently writes a blank document into Cloudflare KV! Visitors are served a blank page cached for 24 hours under `s-maxage=86400`.
2. **Client Credential Exposure:** In `src/services/edgePreBakeService.ts#L308-L378`, `deployPayloadsToCloudflareKV` inspects `getSafeEnv('CLOUDFLARE_API_TOKEN')` and contacts `api.cloudflare.com`. Cloudflare KV deployment belongs strictly on the server edge inside `publishHandler.ts`.
3. **The 24-Hour Cache Trap:** Responses from `/api/public/manifest` and `/api/public/node/:nodeId` carry `s-maxage=86400` without any zone cache purge. Visitors continue to see stale versions for up to 24 hours after an author publishes.

## 🏛️ Karpathy Heuristics & Rules

1. **Think Before Coding:**
   - A cold miss is a read event; it must never mutate the database or KV store.
   - Root discovery pointers (`portal:manifest`) must be validated with fast ETags, not cached for 24 hours.
2. **Make Surgical Changes:**
   - Delete the `ctx.waitUntil(kv.put(...))` calls in `publicHandler.ts`.
   - Remove `deployPayloadsToCloudflareKV` and `compileAndDeployToEdgeKV` from `edgePreBakeService.ts`.
   - Set manifest cache headers to `public, max-age=0, must-revalidate`.
