## 🎯 Purpose & Scope

Create the single source of truth (`src/migrations/ledger.ts`) populated with baseline version history (0.1.0 to current 0.1.3). Implement the runtime migration service (`src/services/migrationService.ts`) to calculate pending content migrations, format copyable AI prompts, and handle watermark persistence.

---

## 📄 Key Files to Create / Modify

1. **`src/migrations/ledger.ts`** *(New)*
   - Strongly typed array `FOLIO_MIGRATION_LEDGER: MigrationEntry[]`.
   - Baseline entries:
     - `0.1.0`: Initial release of Folio Engine with Document AST and Stepped Sequence roadmap.
     - `0.1.1`: Added cloud draft sync, local storage mutex locks, and undo/redo service.
     - `0.1.2`: Enhanced Google Sheets chart sync, Drive photo verification, and vector chart drawers.
     - `0.1.3`: Standalone library distribution (`dist/folio.js`, `dist/edge.js`, `dist/diagnostics.js`), token CSS bundles, and deploy automation.
   - Semver comparison utilities (`compareSemver(v1, v2)`).

2. **`src/services/migrationService.ts`** *(New)*
   - `getMigrationLedger(): MigrationEntry[]`
   - `getContentVersionWatermark(): string` (Checks `EngineConfig.contentVersion`, fallback to `localStorage.getItem('folio_content_version')`, fallback to oldest known or current).
   - `setContentVersionWatermark(version: string): void` (Persists to local storage and updates in-memory config).
   - `getPendingMigrations(watermark?: string): PendingMigrationReport`
     - Filters ledger for entries newer than `watermark`.
     - Collects all unapplied `contentChanges`.
     - Determines `hasPendingContentChanges`.
   - `generateAiMigrationPrompt(report: PendingMigrationReport): string`
     - Formats an actionable, structured markdown prompt with exact tasks, affected files, and instructions suitable for Claude Code, Antigravity, or Cursor agents.

3. **`src/index.ts`** *(Modify)*
   - Export migration services and ledger.
