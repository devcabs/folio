## 🎯 Purpose & Scope

Ensure drafts never silently lock into obsolete snapshots when the published baseline advances:
1. **Invalidate Clean Drafts When Active Snapshot Advances:** In `src/services/draftService.ts#initDraftSession()`, if the draft is clean (`!isDraftDirty()`) but `inMemoryDraftBaseId !== resolvedBaseSnapshotId`, do not short-circuit; reload the draft from the new Edge KV published baseline.
2. **Harden Stale Checks Against Missing Base IDs:** If a cloud draft or local draft has a missing, null, or empty `baseSnapshotId`, treat it as stale when comparing against an established published snapshot ID.
3. **Draft Discard Fidelity:** When `discardDraftSession()` is invoked, immediately re-clone the active published state from Edge KV into `inMemoryDraftCanvases` and broadcast `dispatchAggregateCanvasChange(true)` so the canvas instantly displays the active published baseline.

## 🔍 Problem Statement

1. **The Clean Draft Stagnation Trap:** In [draftService.ts#L477](file:///Users/francisdave/Documents/folio/src/services/draftService.ts#L477):
   ```ts
   if (!forceFresh && (sessionActive || isDraftModeActive()) && draftExists && Object.keys(inMemoryDraftCanvases).length > 0) {
     setDraftModeActive(true);
     return;
   }
   ```
   If a coordinator unlocked Developer Mode previously, `inMemoryDraftCanvases` remains in memory. If another user published a new revision, or if the active snapshot changed, this line returns immediately without checking `isDraftDirty()`. Even though the coordinator made zero edits, their workspace remains stuck on the obsolete snapshot.
2. **Falsy Staleness Evaluation:** In [draftService.ts#L507 & L537](file:///Users/francisdave/Documents/folio/src/services/draftService.ts#L507):
   ```ts
   const isCloudStale = Boolean(
     cloudDraft.baseSnapshotId && cloudDraft.baseSnapshotId !== resolvedBaseSnapshotId
   );
   ```
   If `cloudDraft.baseSnapshotId` is null, undefined, or empty, `cloudDraft.baseSnapshotId && ...` evaluates to `false`. An unanchored draft is deemed "fresh" and loaded over the published snapshot.
3. **Blank State on Discard:** When `discardDraftSession()` clears storage, it does not re-populate `inMemoryDraftCanvases` with the active published baseline before dispatching changes.

## 🏛️ Karpathy Heuristics & Rules

1. **Think Before Coding:**
   - A draft that has no uncommitted changes (`isDraftDirty() === false`) has no author work to protect; it should always track the current published baseline.
   - A draft that has uncommitted changes (`isDraftDirty() === true`) MUST be preserved, and the user must be alerted to staleness via `DevPublishModal`.
2. **Make Surgical Changes:**
   - Check `isDraftDirty()` before short-circuiting in `initDraftSession()`.
   - Update `isCloudStale` and `isLocalStale` to treat missing `baseId` as stale when `resolvedBaseSnapshotId` is valid.
3. **Verify Everything:**
   - Verify that when a clean draft exists and a new snapshot is published, re-initializing the draft updates it to the new snapshot.

## 📄 Key Files to Modify

1. **`src/services/draftService.ts`**
   - In `initDraftSession()`, resolve `resolvedBaseSnapshotId` before checking the in-memory short-circuit.
   - If `!isDraftDirty()` and `inMemoryDraftBaseId !== resolvedBaseSnapshotId`, allow the function to re-clone the latest baseline from Edge KV.
   - Update `isCloudStale` and `isLocalStale` conditions.
   - In `discardDraftSession()`, call `initDraftSession(true)` to cleanly re-populate from live published baseline.

## 🛠️ Step-by-Step Implementation Instructions

### Step 1: Fix Short-Circuit & Staleness in `initDraftSession`

In `src/services/draftService.ts`:
```ts
      // 1. Resolve active published snapshot ID first
      let resolvedBaseSnapshotId = getActivePublishedId();
      if (typeof window !== 'undefined' && typeof fetch === 'function') {
        try {
          const manifestRes = await fetch('/api/public/manifest');
          if (manifestRes.ok) {
            const manifestData = await manifestRes.json();
            if (manifestData?.activeSnapshotId) {
              resolvedBaseSnapshotId = manifestData.activeSnapshotId;
              setActivePublishedId(manifestData.activeSnapshotId);
            }
          }
        } catch {
          // Edge manifest unreachable
        }
      }

      // 2. Retain existing in-memory draft ONLY IF:
      // a) forceFresh is false, AND
      // b) draft has uncommitted changes OR inMemoryDraftBaseId matches current published baseline
      const isDirty = isDraftDirty();
      const baseMatches = inMemoryDraftBaseId === resolvedBaseSnapshotId;
      if (
        !forceFresh &&
        (sessionActive || isDraftModeActive()) &&
        draftExists &&
        Object.keys(inMemoryDraftCanvases).length > 0 &&
        (isDirty || baseMatches)
      ) {
        setDraftModeActive(true, inMemoryDraftBaseId || resolvedBaseSnapshotId);
        return;
      }
```

### Step 2: Harden Stale Draft Detection

```ts
      // Stale check for cloud draft:
      // If cloudDraft has no base_snapshot_id OR base_snapshot_id differs from resolvedBaseSnapshotId, treat as stale
      const isCloudStale = !cloudDraft.baseSnapshotId || cloudDraft.baseSnapshotId !== resolvedBaseSnapshotId;

      // Stale check for local persistent draft:
      const localBaseId = getDraftBaseId();
      const isLocalStale = !localBaseId || localBaseId !== resolvedBaseSnapshotId;
```

### Step 3: Re-populate Baseline on Discard

In `discardDraftSession()`:
```ts
export async function discardDraftSession(): Promise<void> {
  clearDraftTombstones();
  clearDraftStorage();

  const config = getSupabaseConfig();
  if (config && isTableAvailable('engine_drafts')) {
    try {
      await fetch(`${config.url}/rest/v1/engine_drafts?id=eq.active_draft`, {
        method: 'DELETE',
        headers: {
          apikey: config.anonKey,
          Authorization: `Bearer ${config.anonKey}`,
        },
      });
    } catch (err) {
      console.warn('[draftService] Discard cloud draft failed:', err);
    }
  }

  // Immediately re-populate draft from authoritative published baseline
  await initDraftSession(true);
}
```
