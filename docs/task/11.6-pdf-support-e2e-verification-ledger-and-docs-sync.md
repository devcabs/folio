- Add the new release entry to `_RAW_LEDGER` in `src/migrations/ledger.ts`:
  - **`breakingChanges`**: Note that `CanvasElementType` and `CanvasLeafElement` unions now include `'pdf'` (`PdfElement`) and `'documents'` (`DocumentsElement`); Consumers with exhaustive `switch (leaf.type)` statements without a `default` branch should handle `'pdf'` and `'documents'` (or delegate leaf rendering to `<DocumentCanvas>`).
  - **`codeActions`**: Provide before/after examples for advancing `EngineConfig.contentVersion` and handling `'pdf'` | `'documents'` in any custom AST traversal in Consumer applications.

    1. Optional content change explaining how coordinators can embed Single PDFs (`drive.google.com/file/d/{id}/view`) and sync Google Drive PDF folders (`drive.google.com/drive/folders/{id}`) on the canvas.
