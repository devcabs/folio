## 🎯 Purpose & Scope

Implement a comprehensive, automated test suite that validates the Epic 3 single-source data model, deterministic UX fallbacks, and design token purity across the read and write pipelines.

This suite acts as the final quality gate to guarantee that:
1. Public visitors never touch `localStorage` for canvas rendering.
2. Unconfigured charts never borrow sibling data.
3. Empty canvas domains present dignified notices rather than blank page voids.
4. Internal developer placeholders never leak into public HTML.
5. All newly authored UI components strictly adhere to `src/styles/tokens.css` and the Universal Zero Outline Policy.

---

## 🔍 Problem Statement

Without end-to-end integration tests, multi-tier fallback regressions easily slip into production:
- A developer might re-introduce a `localStorage.getItem()` fallback "just in case", causing cold load layout shifts to return.
- A well-meaning change might restore the sibling chart fallback `c.nodeId === nodeId` to prevent empty cards, re-introducing counterfeit data.
- Hardcoded hex colors or arbitrary pixel values might be introduced in CSS modules, violating token discipline.

## 🛠️ Step-by-Step Implementation Instructions

### Step 1: Create `tests/integration/single-source-data.test.ts`

```ts
import { describe, it, expect, beforeEach, vi } from 'vitest';
import { renderHook } from '@testing-library/react';
import { useSheetChartData } from '../../src/hooks/useSheetChartData';
import { isAuthoringPlaceholder } from '../../src/utils/canvasDefaults';

describe('Epic 3 — Single-Source Data Architecture & Integrity Gates', () => {
  beforeEach(() => {
    vi.clearAllMocks();
  });

  describe('3.2 Purging Misleading Sibling Chart Fallback', () => {
    it('returns null dataset for unrecognized chartId even if valid nodeId is provided', () => {
      const { result } = renderHook(() =>
        useSheetChartData({
          chartId: 'non-existent-chart-id',
          nodeId: 'access',
          isDevMode: false,
        })
      );

      expect(result.current.dataset).toBeNull();
      expect(result.current.status).toBe('pending_data');
    });
  });

  describe('3.5 Authoring Placeholder Sanitization Gate', () => {
    it('correctly identifies all factory authoring default strings', () => {
      expect(isAuthoringPlaceholder('Click Edit to add narrative text for this section.')).toBe(true);
      expect(isAuthoringPlaceholder('Photo documentation.')).toBe(true);
      expect(isAuthoringPlaceholder('Section Title')).toBe(true);
      expect(isAuthoringPlaceholder('Subsection Title')).toBe(true);
      expect(isAuthoringPlaceholder('   ')).toBe(true);
      expect(isAuthoringPlaceholder(null)).toBe(true);
    });

    it('preserves genuine user-authored narratives', () => {
      expect(isAuthoringPlaceholder('Our district attained a 94.2% completion rate across all cohorts.')).toBe(false);
      expect(isAuthoringPlaceholder('Annual Financial Transparency Report')).toBe(false);
    });
  });
});
```
