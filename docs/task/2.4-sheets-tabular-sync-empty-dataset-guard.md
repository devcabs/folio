## 🎯 Purpose & Scope

Protect existing chart visual configurations and datasets against accidental wipeout when syncing Google Sheets. Currently, if a linked spreadsheet tab is blank, an invalid range is provided (e.g. `Z1:Z100`), or permissions are revoked, `useSheetChartData.ts` treats 0 returned rows as a success, risking permanent loss of the previous working chart dataset.

This task enforces a defensive non-destructive guard: if a sync yields 0 rows, the sync aborts, the previous dataset is retained, and a clear explanatory warning is displayed.

---

## 🔍 Problem Statement

In `src/hooks/useSheetChartData.ts`:
1. `syncLiveSheet()` calls `fetchLiveSheetMatrix()`.
2. Lines 294–297 handle empty matrices:
   ```ts
   if (liveMatrix && liveMatrix.length > 0) {
     ...
   } else {
     setStatus('success');
     return [];
   }
   ```
3. If the coordinator made a typo in the range notation or selected an empty sheet tab, `setStatus('success')` is set and an empty array is returned.
4. If an empty dataset were persisted to `cachedDataset`, it would wipe out the chart display across public views.
5. In accordance with the decision log, **existing data must be protected**: 0-row results must be rejected with an informative error while keeping the previous snapshot completely intact.

```ts
    }

    const activeConfig = config || cachedConfig;
    if (!activeConfig?.sheetUrl) {
      throw new Error('No Google Sheet linked to this chart.');
    }

    setStatus('syncing');
    setErrorMessage(undefined);

    const syncPromise = (async () => {
      try {
        const liveMatrix = await fetchLiveSheetMatrix({
          sheetUrl: activeConfig.sheetUrl,
          tabName: activeConfig.tabName,
          sheetGid: activeConfig.sheetGid,
          range: activeConfig.range,
          timeoutMs: 8000,
        });

        if (!isMountedRef.current) return null;

        // Defensive Guard: Reject empty or 0-row results
        if (!liveMatrix || liveMatrix.length === 0) {
          const emptyMsg = 'Google Sheet returned 0 valid data rows. Previous chart data preserved.';
          setStatus('error');
          setErrorMessage(emptyMsg);
          throw new Error(emptyMsg);
        }

        // Proceed with parsing and saving if liveMatrix has rows...
        ...
      } finally {
        inFlightSyncRef.current = null;
      }
    })();

    inFlightSyncRef.current = syncPromise;
    return syncPromise;
  }, [chartId, config, cachedConfig, nodeId]);
```
