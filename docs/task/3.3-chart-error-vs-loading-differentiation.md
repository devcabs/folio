## 🎯 Purpose & Scope

Eliminate "The Forever Loader" antipattern in `src/components/chart/` by cleanly separating transient loading states from permanent or unlinked problem states.

Currently, `DataPendingCard.tsx` renders an animated `ChartGhostWireframe` skeleton behind every unconfigured or errored chart. Because the wireframe presents subtle pulsing ghost bars, public visitors and coordinators perceive the system as "still loading" indefinitely, rather than recognizing a static unlinked or misconfigured state.

This task establishes a clear visual and semantic distinction:
1. **Transient Loading (`status === 'syncing'`):** Active pulsing skeleton with `aria-busy="true"` and "Fetching latest data..." indicator.
2. **Permanent Problem / Unlinked (`status === 'error' | 'pending_data'`):** Clean, calm token-styled diagnostic card with a static background (no animated ghost bars), explicit status badges, and actionable next steps.

---

## 🔍 Problem Statement

In `src/components/chart/DataPendingCard.tsx` and `ChartCard.tsx`:
1. `DataPendingCard` unconditionally mounts `<ChartGhostWireframe />` as its background at line 97.
2. If a Google Sheet URL is broken, permissions are private, or a chart was never configured:
   - The card remains on screen permanently.
   - The SVG skeleton in `ChartGhostWireframe.tsx` renders vertical bar silhouettes.
   - Users report that "the chart is stuck loading and won't finish".
3. For coordinators, diagnostic badges exist, but they are layered directly over the skeleton, visually conflicting with the wireframe lines.
4. For public visitors, the pulsing shapes create cognitive fatigue and give the impression of a broken web application.

---

## 📄 Key Files to Create / Modify

1. **`src/components/chart/DataPendingCard.tsx`** *(Modify)*
   - Accept an optional `isLoading?: boolean` prop.
   - Only render `<ChartGhostWireframe />` when `isLoading === true`.
   - When not loading (i.e. static pending or error), render a calm, textured architectural background utilizing design tokens (`var(--folio-bg-surface)`, `var(--folio-border)`).
   - Ensure `aria-busy` is only `"true"` when actively syncing.

2. **`src/components/chart/ChartCard.tsx`** *(Modify)*
   - Pass `isLoading={isSyncing || status === 'syncing'}` to `DataPendingCard`.
   - When `status === 'error'`, explicitly pass `errorMessage` and ensure error category is prominent.

3. **`src/components/chart/DataPendingCard.module.css`** *(Modify)*
   - Style the static diagnostic state using tokenized borders and surfaces without shimmering keyframes.
   - Strictly adhere to Universal Zero Outline Policy and 4-state matrix for all interactive elements.
