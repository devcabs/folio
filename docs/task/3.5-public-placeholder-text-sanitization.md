## 🎯 Purpose & Scope

Prevent internal authoring instructions and factory placeholder copy from leaking into the public portal.

Currently, factory default functions in `src/utils/canvasDefaults.ts` generate strings like `"Click Edit to add narrative text for this section."` and `"Photo documentation."`. If an editor inserts a section or text element and publishes without entering custom copy, public visitors are shown raw authoring prompts.

This task establishes an automated sanitization and suppression gate: in public viewing mode, authoring prompts are never rendered.

---

## 🔍 Problem Statement

In `src/utils/canvasDefaults.ts` and `src/components/canvas/CanvasText.tsx`:
1. `createDefaultText` produces:
   ```ts
   content: 'Click Edit to add narrative text for this section.'
   ```
2. When published, public visitors read:
   > "Click Edit to add narrative text for this section."
3. Visitors cannot click edit, and the text exposes engine implementation details, reducing portal credibility.
4. Similar placeholder copy exists in:
   - Photo captions: `"Photo documentation."`
   - Subsections: `"Subsection details and documentation"`

## 🛠️ Step-by-Step Implementation Instructions

### Step 1: Define `AUTHORING_PLACEHOLDERS` in `src/utils/canvasDefaults.ts`

```ts
export const AUTHORING_PLACEHOLDERS = new Set<string>([
  'Click Edit to add narrative text for this section.',
  'Photo documentation.',
  'Milestone initiatives and summary of progress',
  'Subsection details and documentation',
  'Subsection Title',
  'Section Title',
]);

/**
 * Checks whether a text string contains unedited factory authoring placeholder copy.
 */
export function isAuthoringPlaceholder(text?: string | null): boolean {
  if (!text) return true;
  const trimmed = text.trim();
  return trimmed.length === 0 || AUTHORING_PLACEHOLDERS.has(trimmed);
}
```

### Step 2: Sanitize `CanvasText.tsx`

In `src/components/canvas/CanvasText.tsx`:
```tsx
import { isAuthoringPlaceholder } from '../../utils/canvasDefaults';

export const CanvasText: React.FC<CanvasTextProps> = memo(({
  element,
  nodeId,
  accentColor,
  onEdit,
}) => {
  const { isDevMode } = useDeveloperMode();
  const isPlaceholder = isAuthoringPlaceholder(element.content);

  // In public mode, suppress text blocks that only contain authoring instructions
  if (!isDevMode && isPlaceholder) {
    return null;
  }

  // In dev mode, show prompt in subdued styling so author knows where to click
  return (
    <div className={styles.textWrapper}>
      <p className={`${styles.content} ${isPlaceholder ? styles.devPlaceholderText : ''}`}>
        {element.content}
      </p>
    </div>
  );
});
```

### Step 3: Sanitize `CanvasPhoto.tsx`

In `src/components/canvas/CanvasPhoto.tsx`:
```tsx
const displayCaption = useMemo(() => {
  if (!currentPhoto.caption) return '';
  if (!isDevActive && isAuthoringPlaceholder(currentPhoto.caption)) {
    return '';
  }
  return currentPhoto.caption;
}, [currentPhoto.caption, isDevActive]);
```

Use `displayCaption` for caption rendering and lightbox metadata.
