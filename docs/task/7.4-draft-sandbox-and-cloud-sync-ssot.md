## 🎯 Purpose & Scope

Establish Cloudflare KV (`draft:workspace`) as the **single, live source of truth** for the Developer Mode draft workspace across `src/edge/handlers/draftHandler.ts`, `src/edge/router.ts`, and `src/services/draftService.ts`:
1. **Eliminate Supabase `engine_drafts`, `localStorage`, and Module-Level `inMemoryDraft*` Globals (`src/services/draftService.ts`)**:
   - Delete `inMemoryDraftCanvases`, `inMemoryDraftActive`, `inMemoryDraftBaseId`, and `inMemoryDraftDirty` module-level singletons.
   - Delete all `localStorage` reads and writes (`_draft_active`, `_draft_dirty`, `_draft_canvas_${nodeId}`).
   - Delete all Supabase `engine_drafts` calls (`syncDraftToCloud`, `fetchActiveCloudDraft`, `clearCloudDraft`).
2. **Authoritative Cloudflare KV Draft Endpoint (`/api/draft` → KV key `draft:workspace`)**:
   - Implement `src/edge/handlers/draftHandler.ts` and wire `/api/draft` in `src/edge/router.ts` (and `functions/api/draft.ts`), requiring `Authorization: Bearer <lockToken>` verified against `lock:coordinator.lockToken` in KV (returning HTTP 401/409 if invalid or not held by caller):
     - `POST /api/draft/init`: Accepts `{ nodeIds: string[] }` in the request body (derived from `getActiveNodeIds()` on the client). Reads `draft:workspace`, `portal:manifest`, and `history:index` from Cloudflare KV (returning HTTP 503 if `!kv`):
       - **Active Draft Exists**: If `draft:workspace` exists in KV and its `baseSnapshotId` matches `portal:manifest.activeSnapshotId` (or `draft:workspace.dirty === true`), returns it directly.
       - **Published Baseline Exists (`portal:manifest !== null`)**: Reads `node:${portal:manifest.activeSnapshotId}:${nodeId}` (or `node:${nodeId}`) for all `nodeIds`. If any expected baseline `node:*` key in `portal:manifest.nodeIds` is missing or unreadable, **fails stop with HTTP 502** (preventing partial/corrupted baseline cloning). Constructs a fresh `DraftWorkspacePayload` (`baseSnapshotId: portal:manifest.activeSnapshotId`, `dirty: false`, `revision: 1`, `updatedAt`, `authorSessionId`, `canvases`, `contentOverrides`), writes it to KV key `draft:workspace`, and returns it.
       - **First-Time Cold Boot (`portal:manifest === null && history:index === null`)**: When the KV namespace is completely unseeded on a brand-new deployment, bootstraps an initial `DraftWorkspacePayload` (`baseSnapshotId: 'uninitialized'`, `dirty: true`, `revision: 1`, `updatedAt`, `authorSessionId`, empty `createDefaultCanvasDocument(nodeId)` for each requested `nodeId` in `body.nodeIds`, `contentOverrides: {}`), writes it to KV key `draft:workspace`, and returns it—eliminating any circular cold-boot 404 deadlock!
     - `GET /api/draft`: Reads `draft:workspace` directly from Cloudflare KV (`Cache-Control: no-store`). Returns HTTP 404 if no active draft workspace exists, or HTTP 503 if `!kv`.
     - `PUT /api/draft`: Verifies `Authorization: Bearer <lockToken>` against `lock:coordinator` in KV (HTTP 401/409 if lock not held by caller) and enforces **Optimistic Concurrency Control**: compares `body.expectedUpdatedAt` (or `body.expectedRevision`) against the stored `draft:workspace.updatedAt` (`revision`). If they do not match, returns `HTTP 409 Conflict` (`{ error: 'Draft workspace was modified concurrently', latestWorkspace }`) so background Sheet/Drive syncs can never overwrite concurrent canvas or text edits. Otherwise increments `revision`, updates `draft:workspace` (`canvases`, `contentOverrides`, `dirty: true`, `updatedAt`) directly in Cloudflare KV, and returns the saved `DraftWorkspacePayload`. Fails stop with HTTP 502/503 if `kv.put` fails.
     - `DELETE /api/draft`: Verifies `Authorization: Bearer <lockToken>` against `lock:coordinator`, then discards `draft:workspace` in Cloudflare KV by re-cloning from the live `portal:manifest` and `node:${activeSnapshotId}:${nodeId}` KV keys (or resetting to empty baseline canvases if `portal:manifest === null`).
3. **Strict Fail-Stop on Draft Read/Write**:
   - Every client call in `draftService.ts` (`initDraftSession`, `fetchDraftWorkspace`, `saveDraftWorkspace`, `discardDraftWorkspace`) goes directly to `/api/draft` and throws an explicit `Error` on any non-2xx HTTP status or network error—never falling back to local memory or default empty documents.
