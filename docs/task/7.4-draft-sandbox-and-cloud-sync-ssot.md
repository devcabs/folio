## 🎯 Purpose & Scope

Establish Cloudflare KV (`draft:workspace`) as the **single, live source of truth** for the Developer Mode draft workspace across `src/edge/handlers/draftHandler.ts`, `src/edge/router.ts`, and `src/services/draftService.ts`:
1. **Eliminate Supabase `engine_drafts`, `localStorage`, and Module-Level `inMemoryDraft*` Globals (`src/services/draftService.ts`)**:
   - Delete `inMemoryDraftCanvases`, `inMemoryDraftActive`, `inMemoryDraftBaseId`, and `inMemoryDraftDirty` module-level singletons.
   - Delete all `localStorage` reads and writes (`_draft_active`, `_draft_dirty`, `_draft_canvas_${nodeId}`).
   - Delete all Supabase `engine_drafts` calls (`syncDraftToCloud`, `fetchActiveCloudDraft`, `clearCloudDraft`).
2. **Authoritative Cloudflare KV Draft Endpoint (`/api/draft` → KV key `draft:workspace`)**:
   - Implement `src/edge/handlers/draftHandler.ts` and wire `/api/draft` in `src/edge/router.ts` (and `functions/api/draft.ts`):
     - `POST /api/draft/init`: Reads `draft:workspace` from Cloudflare KV. If an active draft workspace already exists in KV for the current published baseline, returns it. Otherwise, reads `portal:manifest` and `node:${nodeId}` for all configured nodes from Cloudflare KV, constructs a fresh `DraftWorkspacePayload` (`baseSnapshotId`, `dirty: false`, `updatedAt`, `authorSessionId`, `canvases`, `contentOverrides`), writes it to KV key `draft:workspace`, and returns it. Fails stop with HTTP 503 if `!kv` or HTTP 404/502 if any baseline KV key is missing or unreadable.
     - `GET /api/draft`: Reads `draft:workspace` directly from Cloudflare KV (`Cache-Control: no-store`). Returns HTTP 404 if no active draft workspace exists, or HTTP 503 if `!kv`.
     - `PUT /api/draft`: Validates the coordinator's `authorSessionId` against `lock:coordinator` in KV (HTTP 409 if lock not held by caller), updates `draft:workspace` (`canvases`, `contentOverrides`, `dirty: true`, `updatedAt`) directly in Cloudflare KV, and returns the saved `DraftWorkspacePayload`. Fails stop with HTTP 502/503 if `kv.put` fails.
     - `DELETE /api/draft`: Discards or resets `draft:workspace` in Cloudflare KV by re-cloning from the live `portal:manifest` and `node:*` KV keys (or deleting `draft:workspace`).
3. **Strict Fail-Stop on Draft Read/Write**:
   - Every client call in `draftService.ts` (`initDraftSession`, `fetchDraftWorkspace`, `saveDraftWorkspace`, `discardDraftWorkspace`) goes directly to `/api/draft` and throws an explicit `Error` on any non-2xx HTTP status or network error—never falling back to local memory or default empty documents.
