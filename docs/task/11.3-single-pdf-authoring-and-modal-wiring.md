## 🎯 Purpose & Scope

Complete Phase 1 (Single `pdf` MVP) by wiring end-to-end Developer Mode creation, editing, deletion confirmation, and AST persistence for `PdfElement` across `CanvasAddBar`, `UniversalEditModal`, `CanvasDeleteConfirmModal`, and `DocumentCanvas`:
1. **`CanvasAddBar.tsx`**: Add a `Document` palette entry (`DocumentIcon`) to `PALETTE_OPTIONS` so coordinators can insert a PDF element anywhere on the canvas (with a submenu structure ready for Phase 2's `PDF Folder` option).
2. **`UniversalEditModal.tsx`**: Add the `elementType === 'pdf'` authoring panel in Domain A (Canvas Mode) supporting `Google Drive PDF URL *` (auto-resolved via `resolveSingleDrivePdfUrl`), `Document Title`, and optional `Caption` toggle + input.
3. **`CanvasDeleteConfirmModal.tsx`**: Add `'pdf'` (`{ title: 'Delete PDF Document', noun: 'PDF document' }`) and `'documents'` (`{ title: 'Delete Document Folder', noun: 'document folder' }`) to `getItemTypeLabel`.
4. **`DocumentCanvas.tsx`**: Render `<CanvasPdf>` in `renderCanvasLeaf` for `case 'pdf'`, and wire `handleAddElement`, `handleEditLeaf`, `handleExecuteAdd`, and `handleModalSubmit` so both the floating toolbar `Edit` icon (`CanvasItemControls`) and `<CanvasPdf>`'s side `✎ Edit` button open the exact same `<UniversalEditModal elementType="pdf">` instance and persist directly to the `NodeCanvasDocument` AST (`PUT /api/draft`).

### Explicit Non-Goals
- Do **not** wire the `documents` (PDF folder) sync or `<LinkFolderModal>` flow yet (covered in Subtasks 11.4 and 11.5).
- Do **not** write any `PdfElement` fields to legacy `ContentDB`; the Canvas AST in Cloudflare KV (`PUT /api/draft`) is the single source of truth.

## 🛠️ Step-by-Step Implementation Plan

### Step 1: Add `Document` Option to `CanvasAddBar.tsx`
- Add a clean geometric `DocumentIcon` SVG component (page with folded corner and horizontal text lines, matching the 15x15 `strokeWidth="2"` style of `PhotoIcon` and `ChartIcon`).
- Add `{ type: 'pdf', label: 'Document', IconComponent: DocumentIcon }` to `PALETTE_OPTIONS` between `Photo` and `Chart`.
- *(Note: In Subtask 11.5, hovering/clicking `Document` will open the `Single PDF` / `PDF Folder` submenu mirroring `Photo`.)*

### Step 2: Add `elementType === 'pdf'` Panel to `UniversalEditModal.tsx`
- Import `resolveSingleDrivePdfUrl` from `../../utils/mediaUrl`.
- In `getSubmitNoun(type)`:
  ```ts
  case 'pdf':
    return 'PDF';
  case 'documents':
    return 'Document Folder';
  ```
- Add `handlePdfUrlChange(val: string)`:
  ```ts
  const handlePdfUrlChange = useCallback((val: string) => {
    const resolved = resolveSingleDrivePdfUrl(val);
    if (resolved) {
      setCanvasDraft((prev) => ({
        ...prev,
        src: resolved.previewUrl,
        driveUrl: resolved.rawUrl,
      }));
    } else {
      setCanvasDraft((prev) => ({
        ...prev,
        src: val,
        driveUrl: val,
      }));
    }
  }, []);
  ```
- Render the `isCanvasDomain && elementType === 'pdf'` form panel:
  1. **Document Title** (`id="canvas-pdf-title"`, optional editorial heading, placeholder `"e.g. Division Memorandum No. 42, s. 2026"`).
  2. **Google Drive PDF URL \*** (`id="canvas-pdf-url"`, required, placeholder `"Paste Google Drive PDF link (https://drive.google.com/file/d/.../view)"`). Show inline feedback if a Drive folder link (`/folders/`) or non-Drive URL is pasted.
  3. **Show caption below document** checkbox + **Caption** input (`id="canvas-pdf-caption"`).

### Step 3: Update `CanvasDeleteConfirmModal.tsx`
- In `getItemTypeLabel(type: CanvasElementType)`:
  ```ts
  case 'pdf':
    return { title: 'Delete PDF Document', noun: 'PDF document' };
  case 'documents':
    return { title: 'Delete Document Folder', noun: 'document folder' };
  ```

### Step 4: Wire `PdfElement` in `DocumentCanvas.tsx`
- In `renderCanvasLeaf`:
  ```tsx
  case 'pdf':
    return (
      <CanvasPdf
        element={leaf}
        nodeId={nodeId}
        accentColor={accentColor}
        onEdit={onEditLeaf ? () => onEditLeaf(leaf) : undefined}
      />
    );
  ```
- In `handleEditLeaf(leaf)`:
  ```tsx
  if (leaf.type === 'pdf') {
    pointId = leaf.pointId;
    initialData = {
      title: leaf.title || '',
      src: leaf.src || '',
      driveUrl: leaf.driveUrl || '',
      caption: leaf.caption || '',
      showCaption: Boolean(leaf.showCaption || (leaf.caption && leaf.caption.trim().length > 0)),
    };
  }
  ```
- In `handleExecuteAdd`:
  ```tsx
  } else if (type === 'pdf') {
    const pdfId = generateCanvasId('pdf');
    const pointId = `node.${nodeId}.pdf.${pdfId}`;
    const rawInput = payload.driveUrl?.trim() || payload.src?.trim() || '';
    const resolved = resolveSingleDrivePdfUrl(rawInput);
    leaf = {
      id: pdfId,
      type: 'pdf',
      pointId,
      title: payload.title?.trim() || undefined,
      src: resolved ? resolved.previewUrl : ( payload.src?.trim() || undefined ),
      driveFileId: resolved?.fileId,
      driveUrl: resolved ? resolved.rawUrl : ( payload.driveUrl?.trim() || undefined ),
      caption: payload.showCaption ? (payload.caption?.trim() || undefined) : undefined,
      showCaption: Boolean(payload.showCaption),
    };
  }
  ```
- In `handleModalSubmit` (`mode === 'edit'`):
  ```tsx
  } else if (elementType === 'pdf' && itemId) {
    const rawInput = data.driveUrl?.trim() || data.src?.trim() || '';
    const resolved = resolveSingleDrivePdfUrl(rawInput);
    updateItem<PdfElement>(itemId, {
      title: data.title?.trim() || undefined,
      src: resolved ? resolved.previewUrl : (data.src?.trim() || undefined),
      driveFileId: resolved?.fileId,
      driveUrl: resolved ? resolved.rawUrl : (data.driveUrl?.trim() || undefined),
      caption: data.showCaption ? (data.caption?.trim() || undefined) : undefined,
      showCaption: Boolean(data.showCaption),
    });
  }
  ```
