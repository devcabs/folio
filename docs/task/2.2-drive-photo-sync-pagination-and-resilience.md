## 🎯 Purpose & Scope

Eliminate silent photo loss when syncing Google Drive folders with more than 100 images. Currently, `fetchDriveFolderImages()` queries the Google Drive REST API v3 with `pageSize=100` and ignores `nextPageToken`. Folders with 101+ photos silently lose the remaining images, causing the differential reconciliation engine to permanently prune them as deleted!

This task adds an automatic `nextPageToken` loop (up to a configurable safety limit of 500 images) and adds structured diagnostic logging when subfolder fetching fails.

---

## 🔍 Problem Statement

In `src/services/drivePhotoSyncService.ts`:
1. `fetchDriveFolderImages(folderUrlOrId: string)` constructs:
   ```ts
   const endpoint = `https://www.googleapis.com/drive/v3/files?q=${...}&fields=${...}&pageSize=100&...`;
   ```
2. The Google Drive API returns `{ files: [...], nextPageToken: "..." }`.
3. Because `nextPageToken` is completely ignored, only the first 100 images are returned.
4. Downstream, `reconcileDrivePhotos()` compares `existingItems` against `incomingFiles`. Any item in `existingItems` not present in `incomingFiles` is tallied in `removed` and purged from `reconciled.items`!
5. In addition, lines 322–347 probe 1st-level subfolders within a broad `try { ... } catch {}` block that completely swallows any network or permission failure.

### Step 2: Implement Pagination Loop

Replace the single fetch in `fetchDriveFolderImages` with a while-loop:
```ts
export const MAX_SYNC_PAGES = 5; // Up to 500 images per folder

let pageToken: string | undefined = undefined;
let pageCount = 0;
const allFiles: DrivePhotoFile[] = [];

do {
  let endpoint = `https://www.googleapis.com/drive/v3/files?q=${encodeURIComponent(
    query
  )}&fields=${encodeURIComponent(
    fields
  )}&pageSize=100&supportsAllDrives=true&includeItemsFromAllDrives=true&key=${encodeURIComponent(
    apiKey
  )}`;

  if (pageToken) {
    endpoint += `&pageToken=${encodeURIComponent(pageToken)}`;
  }

  const response = await fetch(endpoint, {
    method: 'GET',
    headers,
  });

  if (!response.ok) {
    // Existing error handling logic (HTTP 403, 404, etc.)
    ...
  }

  const data = (await response.json()) as { files?: DrivePhotoFile[]; nextPageToken?: string };
  if (Array.isArray(data.files)) {
    allFiles.push(...data.files);
  }

  pageToken = data.nextPageToken;
  pageCount++;
} while (pageToken && pageCount < MAX_SYNC_PAGES);
```
