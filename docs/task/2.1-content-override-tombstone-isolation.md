## 🎯 Purpose & Scope

Ensure that when a coordinator resets a content override to its system default in Developer Mode, that field is genuinely cleared upon publishing. Currently, resetting a field deletes it from the draft cache, but `getAllContentOverrides(true)` merges `{ ...loadLiveCache(), ...loadDraftCache() }`, causing the old live value to resurrect and re-publish!

This task introduces an explicit in-memory tombstone set (`draftTombstones`) in `src/utils/contentDb.ts` to track cleared keys during a draft session.

---

## 🔍 Problem Statement

In `src/utils/contentDb.ts`:
1. `resetContent(key, isDevMode = true)` runs `delete cache[key]; saveDraftCache(); notifySubscribers(key, null, true);`.
2. When the coordinator subsequently publishes via `historyService.publishNewSnapshot()`, it bundles content overrides via `getAllContentOverrides(true)`.
3. `getAllContentOverrides(true)` executes:
   ```ts
   if (isDevMode) {
     return { ...loadLiveCache(), ...loadDraftCache() };
   }
   ```
4. Because the key was deleted from `draftCache`, the fallback `{ ...loadLiveCache() }` still possesses the previous published live override. The old value is bundled into the new snapshot and re-published, directly violating user intent!

## 🛠️ Step-by-Step Implementation Instructions

### Step 1: Add Tombstone State in `src/utils/contentDb.ts`

Around line 33, define the tombstone set:
```ts
const draftTombstones = new Set<string>();
```

### Step 2: Update `setContent` to Clear Tombstone

In `setContent(key: string, value: string, isDevMode = false)`:
- When `isDevMode === true`, if `draftTombstones.has(key)`, delete it: `draftTombstones.delete(key);`.

### Step 3: Record Tombstone in `resetContent`

In `resetContent(key: string, isDevMode = false)`:
- When `isDevMode === true`:
  - Delete `cache[key]`.
  - Add to tombstones: `draftTombstones.add(key);`.
  - Save draft cache and notify subscribers as currently implemented.

### Step 4: Honor Tombstones in `getAllContentOverrides`

Update `getAllContentOverrides(isDevMode = false)` around line 249:
```ts
export function getAllContentOverrides(isDevMode = false): Record<string, string> {
  if (isDevMode) {
    const live = loadLiveCache();
    const draft = loadDraftCache();
    const merged: Record<string, string> = {};

    // Copy live entries unless explicitly tombstoned in draft
    for (const [key, value] of Object.entries(live)) {
      if (!draftTombstones.has(key)) {
        merged[key] = value;
      }
    }

    // Layer active draft overrides
    for (const [key, value] of Object.entries(draft)) {
      merged[key] = value;
    }

    return merged;
  }
  return { ...loadLiveCache() };
}
```

### Step 5: Export `clearDraftTombstones()` and Hook into Lifecycle

Add export:
```ts
export function clearDraftTombstones(): void {
  draftTombstones.clear();
}
```
- In `resetAllContentOverrides(isDevMode)`: if `isDevMode`, call `draftTombstones.clear();`.
- In `src/services/draftService.ts` (`syncDraftWithPublished`, `clearDraftStorage`, `discardDraftSession`), call `clearDraftTombstones()`.
