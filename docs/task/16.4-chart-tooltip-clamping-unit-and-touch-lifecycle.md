## Objective

Eliminate all `ChartTooltip` viewport clipping (`left: -39.5px`, `top: -21.8px`, `right: 341px > 320px`), render the currently ignored `unit` prop, fix `ScatterPlot.tsx:500–511` `onFocus` raw-SVG-coordinate positioning (`left: 672px`), and establish one consistent touch tap-to-inspect + tap-outside-to-dismiss lifecycle across all 5 chart visualizers.

---

## Scope & Exact File Changes

### 1. `useChartTooltip` Clamping & Touch-Dismiss Hook
- **[src/hooks/useChartTooltip.ts](file:///Users/francisdave/Documents/folio/src/hooks/useChartTooltip.ts)**:
  - Add container-aware clamping (`clampX`, `clampY`) and automatic vertical placement flip (`placement: 'above' | 'below'`) when `y` is too close to the top of the chart container, ensuring the tooltip stays strictly inside `[8px, containerWidth - tooltipWidth - 8px]` horizontally and never clips above the top edge.
  - Support a unified `pinned` / touch-active state:
    - For `pointerType === 'mouse'`: hover enters (`showTooltip`) and leave hides (`hideTooltip`).
    - For `pointerType === 'touch'` (or click/tap): tapping a mark pins/shows the tooltip (tapping the same mark again toggles it off); tapping anywhere outside the chart or pressing `Escape` dismisses it cleanly.
  - Expose a helper to convert SVG coordinates `(svgX, svgY)` into container-relative CSS pixel coordinates `(x, y)` using the `<svg>`'s `getBoundingClientRect()` and `viewBox` (so keyboard `onFocus` handlers never pass raw SVG coordinates).

### 2. `ChartTooltip` Component
- **[src/components/chart/ChartTooltip.tsx](file:///Users/francisdave/Documents/folio/src/components/chart/ChartTooltip.tsx)** & **[src/components/chart/ChartTooltip.module.css](file:///Users/francisdave/Documents/folio/src/components/chart/ChartTooltip.module.css)**:
  - **Fix Ignored `unit` Prop (`ChartTooltip.tsx:22`):** Render `unit` cleanly beside `.value` when provided (and not already duplicated in the formatted value string).
  - Support `placement?: 'above' | 'below'` transform (`translate(-50%, -100%)` vs `translate(-50%, 12px)`) and horizontal edge shift/clamping so wide labels (`max-width: 220px`) never overflow `320px` viewports.

### 3. Wire Unified Tooltip Clamping & Touch Lifecycle into All 5 Visualizers
- **[src/components/chart/BarChart.tsx](file:///Users/francisdave/Documents/folio/src/components/chart/BarChart.tsx)**:
  - Pass container bounds to `useChartTooltip` and guard `onPointerLeave` against `pointerType === 'touch'` so taps don't vanish immediately on `touchend`.
- **[src/components/chart/LineChart.tsx](file:///Users/francisdave/Documents/folio/src/components/chart/LineChart.tsx)**:
  - Pass container bounds to `useChartTooltip`; fix stuck tooltip after tap by using unified tap-to-inspect + tap-outside-to-dismiss and pointer-type-aware leave handling.
- **[src/components/chart/DonutChart.tsx](file:///Users/francisdave/Documents/folio/src/components/chart/DonutChart.tsx)**:
  - Pass container bounds to `useChartTooltip`; allow touch tap to keep the tapped slice's center callout and tooltip visible until tapped again or dismissed outside (instead of flashing and resetting to total on `touchend`).
- **[src/components/chart/ScatterPlot.tsx](file:///Users/francisdave/Documents/folio/src/components/chart/ScatterPlot.tsx)**:
  - **Fix `ScatterPlot.tsx:500–511` `onFocus` Defect:**
    1. Convert `(cx, cy)` from SVG coordinate space into container-relative CSS pixel coordinates before calling `showTooltip` (eliminating `left: 672px` off-screen clipping at `320px`).
    2. Use unified touch tap/dismiss so tapping a point doesn't get stuck via `onFocus` re-triggering after `touchend`.
- **[src/components/chart/HistogramChart.tsx](file:///Users/francisdave/Documents/folio/src/components/chart/HistogramChart.tsx)**:
  - Pass container bounds to `useChartTooltip` and guard `onPointerLeave` against `pointerType === 'touch'` so tapped bin tooltips remain visible until dismissed.
