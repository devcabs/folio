## 🎯 Purpose & Scope

Streamline Folio Engine's revision history, changelog diffing, and snapshot restoration mechanisms into a **pure Canvas AST architecture**.

Currently, historical snapshots bundle and duplicate both the Canvas AST and flat `ContentDB` key dictionaries. When restoring a previous revision (`restoreSnapshotToDraft`), the system attempts to reconstitute legacy `contentOverrides` in draft storage and run migration folding algorithms (`migrateCanvasOverridesIntoAst('draft')`). Furthermore, diff calculations in `computeMetricsSummary` count flat text keys alongside AST elements, creating phantom diffs.

This task:
1. Enforces that `localStorage.getItem('folio_history_manifest')` contains strictly lightweight metadata headers (`< 5 KB`), with full historical snapshot trees residing exclusively in IndexedDB and Supabase.
2. Refactors `restoreSnapshotToDraft` to perform a clean, pure AST tree injection into the in-memory draft sandbox without mutating or reconciling `ContentDB`.
3. Updates `computeMetricsSummary` to calculate changelog metrics strictly against the Canvas AST hierarchy.

## 🔍 Problem Statement

In `src/services/historyService.ts` and `src/components/history/HistoryHubModal.tsx`:
1. **Rollback Re-Hydration Bloat (lines 719–723):**
   ```ts
   setAllContentOverrides(snapshot.contentOverrides || {}, true);
   migrateCanvasOverridesIntoAst('draft');
   ```
   When a coordinator restores a past version, it re-populates dead flat keys in `_draft_content_overrides` and runs `migrateCanvasOverridesIntoAst('draft')`. This re-introduces the very dual-storage desynchronization that Epic 3 is eliminating!
2. **Dual-Path Diffing:**
   `computeMetricsSummary` includes `totalTextOverrides: Object.keys(contentOverrides || {}).length`. In a single-source AST world, text belongs to `TextElement`, `SectionElement.title`, or `PhotoElement.caption`. Tracking flat keys adds phantom counts.
3. **Storage Quota Risk:**
   If full snapshot trees with 5 canvas nodes are written to the browser's `localStorage` history manifest, browser storage is quickly exhausted (`QuotaExceededError`). Full snapshot trees belong in IndexedDB and Supabase.

### Step 1: Pure AST Rollback in `src/services/historyService.ts`

Refactor `restoreSnapshotToDraft`:
```ts
export function restoreSnapshotToDraft(
  snapshot: PublishedSnapshot | UnifiedPortalSnapshot
): boolean {
  try {
    setDraftModeActive(true, snapshot.id);
    const nowIso = new Date().toISOString();

    // 1. Restore Canvas ASTs directly into In-Memory Draft Sandbox
    for (const nodeId of getActiveNodeIds()) {
      const baseDoc = snapshot.canvases?.[nodeId] || createDefaultCanvasDocument(nodeId);
      const doc: NodeCanvasDocument = {
        ...JSON.parse(JSON.stringify(baseDoc)),
        nodeId,
        sections: renumberSections(baseDoc.sections || []),
        updatedAt: nowIso,
      };

      setInMemoryDraftCanvas(nodeId, doc);

      // Lightweight backup in draft storage if supported
      const storage = getStorage();
      if (storage) {
        try {
          storage.setItem(getDraftCanvasKey(nodeId), JSON.stringify(doc));
        } catch {
          // In-memory sandbox remains authoritative
        }
      }
    }

    // 2. Clear lingering draft tombstones and DO NOT restore flat contentOverrides for canvas elements
    clearDraftTombstones();

    // 3. Dispatch draft canvas change events to update active UI views immediately
    if (typeof window !== 'undefined') {
      for (const nodeId of getActiveNodeIds()) {
        const doc = getNodeCanvas(nodeId, true);
        const detail: CanvasChangeEventDetail = {
          nodeId,
          document: doc,
        };
        window.dispatchEvent(new CustomEvent(EVENT_DRAFT_CANVAS_CHANGE, { detail }));
      }
      dispatchAggregateCanvasChange(true);
    }

    setDraftDirty(true);
    triggerDebouncedCloudDraftSync();
    return true;
  } catch (err) {
    console.warn('[historyService] Failed to restore snapshot to draft:', err);
    return false;
  }
}
```

### Step 2: Update `computeMetricsSummary` for Pure AST Traversal

In `src/services/historyService.ts`:
```ts
export function computeMetricsSummary(
  canvases: Record<string, NodeCanvasDocument>,
  _legacyContentOverrides?: Record<string, string>
): UnifiedPortalSnapshot['summary'] {
  let totalSections = 0;
  let totalSubsections = 0;
  let totalLeafElements = 0;
  let totalTextElements = 0;
  let totalPhotoElements = 0;
  let totalChartElements = 0;

  for (const doc of Object.values(canvases)) {
    if (!doc || !Array.isArray(doc.sections)) continue;
    totalSections += doc.sections.length;

    for (const sec of doc.sections) {
      if (!sec || !Array.isArray(sec.elements)) continue;
      for (const el of sec.elements) {
        if (el.type === 'subsection') {
          totalSubsections += 1;
          const sub = el as SubsectionElement;
          if (Array.isArray(sub.elements)) {
            totalLeafElements += sub.elements.length;
            for (const leaf of sub.elements) {
              if (leaf.type === 'text') totalTextElements += 1;
              if (leaf.type === 'photo') totalPhotoElements += 1;
              if (leaf.type === 'chart') totalChartElements += 1;
            }
          }
        } else {
          totalLeafElements += 1;
          if (el.type === 'text') totalTextElements += 1;
          if (el.type === 'photo') totalPhotoElements += 1;
          if (el.type === 'chart') totalChartElements += 1;
        }
      }
    }
  }

  return {
    totalSections,
    totalSubsections,
    totalLeafElements,
    totalTextOverrides: totalTextElements, // Preserves contract compatibility
  };
}
```
