## 🎯 Purpose & Scope

Implement `src/services/pageTreeService.ts` as a **100% pure, immutable, zero-DOM / zero-React / zero-KV domain service** that owns all page-tree logic for Epic 13: ID generation, slug sanitization & sibling-only uniqueness, CRUD, cycle-safe reparenting, canvas-to-subpage order syncing, arbitrary-depth folder path resolution, breadcrumb ancestor chains, 2-level navigation tree generation, and Smart 404 fuzzy ranking + nearest valid ancestor discovery.

### Step-by-Step Implementation Blueprint

Create `src/services/pageTreeService.ts` exporting the following pure functions (every mutator returns a **new** `PageRegistry` object without mutating its input):

1. **ID Generation & Slug Sanitization / Validation**
   - `RESERVED_SLUGS = new Set(['node', 'page', 'api', 'index', 'index.html', 'assets', 'static', 'favicon.ico', 'robots.txt'])`
   - `generatePageId(): string`: returns `page-${Date.now().toString(36)}-${Math.random().toString(36).substring(2, 7)}`, guaranteed to match `PAGE_ID_REGEX` (`/^[a-z0-9_-]{1,64}$/`).
   - `sanitizeSlug(raw: string): string`:
     - Lowercase, NFKD normalize + strip diacritics (`[\u0300-\u036f]`), replace any non-`[a-z0-9]` sequences with `-`, collapse consecutive `-`, trim leading/trailing `-`, cap at 64 chars (re-trimming trailing `-`).
     - Returns `""` if input produces no valid characters.
   - `validateSlug(slug: string, parentId: string | null, pages: PageRegistry, excludePageId?: string): { valid: boolean; sanitized: string; error?: string; suggestedSlug?: string }`:
     - Sanitizes input; rejects empty string (`"URL name is required."`), rejects `RESERVED_SLUGS` (`"This URL name is reserved."`), checks **sibling-only** collision (only pages with identical `parentId` and `id !== excludePageId`).
     - If sibling collision exists, returns `valid: false`, descriptive inline error (e.g., `"A sibling page already uses \"overview\"."`), and `suggestedSlug` via `ensureUniqueSiblingSlug`.
     - Identical slugs under **different** parents MUST return `valid: true`.
   - `ensureUniqueSiblingSlug(baseSlug: string, parentId: string | null, pages: PageRegistry, excludePageId?: string): string`:
     - Starts with sanitized slug (falling back to `'page'` if empty or reserved); if taken by a sibling under `parentId`, appends `-2`, `-3`, ... until unique.
   - `countSummaryWords(text?: string): number` & `MAX_PAGE_SUMMARY_WORDS = 15`: helper for `editorial-restraint.md` ≤15-word summary validation.

2. **Immutable Tree CRUD & Cycle-Safe Reparenting**
   - `createPageNode(pages: PageRegistry, input: { parentId: string; title: string; slug?: string; subtitle?: string; summary?: string; order?: number; id?: string; nowIso?: string }): { pages: PageRegistry; page: PageNode }`:
     - Computes unique sibling slug (using `input.slug` if supplied, else `sanitizeSlug(input.title)`), defaults `order` to sibling count if omitted, sets `createdAt` & `updatedAt`, returns updated `pages` and newly created `page`.
   - `updatePageNodeMetadata(pages: PageRegistry, pageId: string, updates: Partial<Pick<PageNode, 'title' | 'slug' | 'subtitle' | 'summary' | 'order'>>, nowIso?: string): { pages: PageRegistry; page: PageNode }`:
     - Throws if `pageId` does not exist; if `updates.slug !== undefined`, sanitizes and checks sibling uniqueness (throwing a descriptive error on sibling conflict or empty/reserved slug); updates `updatedAt`.
   - `getDescendantPageIds(pages: PageRegistry, pageId: string): string[]`:
     - BFS/DFS collecting all descendant `PageNode.id`s (with a `visited` set guard against corrupted cycles). Does **not** include `pageId` itself.
   - `countDescendantPages(pages: PageRegistry, pageId: string): number`:
     - Returns exact count `getDescendantPageIds(pages, pageId).length` (used by Evaluative Ease deletion modal).
   - `cascadeDeleteSubtree(pages: PageRegistry, pageId: string): { pages: PageRegistry; deletedIds: string[] }`:
     - Removes `pageId` and all descendants from `pages`; returns `{ pages: nextPages, deletedIds: [pageId, ...descendants] }`. If `pageId` is absent, returns `{ pages, deletedIds: [] }`.
   - `reparentPageNode(pages: PageRegistry, pageId: string, newParentId: string, nowIso?: string): { pages: PageRegistry; page: PageNode }`:
     - **Strict Circular-Reparenting Guard**: rejects if `newParentId === pageId` or `getDescendantPageIds(pages, pageId).includes(newParentId)` (throws explicit error `"Cannot move a page into itself or one of its subpages."`).
     - Re-checks sibling slug uniqueness under `newParentId` (auto-disambiguating via `ensureUniqueSiblingSlug` if needed) and assigns next `order`.

3. **Canvas-Driven Order Synchronization**
   - `extractPageLinkOrderFromCanvas(canvas: NodeCanvasDocument): string[]`:
     - Walks `canvas.sections` -> `section.elements` -> nested `subsection.elements` in exact document reading order and extracts `leaf.targetPageId` for every `PageLinkElement` (deduplicated preserving first appearance).
   - `deriveSubpageOrderFromCanvas(pages: PageRegistry, parentId: string, canvas: NodeCanvasDocument, nowIso?: string): { pages: PageRegistry; changed: boolean }`:
     - Updates `order` (`0, 1, 2, ...`) on direct children of `parentId` to match `extractPageLinkOrderFromCanvas(canvas)`; any direct child not present in the canvas retains relative order appended after linked children. Returns `changed: false` when order is already identical (avoiding redundant KV writes).
   - `getDirectChildren(pages: PageRegistry, parentId: string): PageNode[]`:
     - Returns direct children sorted stably by `(a.order - b.order) || a.createdAt.localeCompare(b.createdAt) || a.id.localeCompare(b.id)`.

4. **Folder Path Resolution, Ancestor Chains & 2-Level Nav Builder**
   - `buildPagePath(pageId: string, rootNodes: NodeItem[], pages: PageRegistry, basePath?: string): string`:
     - If `pageId` is a root chapter in `rootNodes`, returns `${normBase}/node/${root.id}/`.
     - Otherwise walks `parentId` chain up to root chapter (with `visited` cycle guard) and joins slugs: `${normBase}/node/${root.id}/${seg1}/${seg2}/.../`.
   - `resolvePathToPage(segments: string[], rootNodes: NodeItem[], pages: PageRegistry): { matched: true; pageId: string; rootNode: NodeItem; pageNode: PageNode | null; ancestors: PageAncestorItem[] } | { matched: false; rootNode: NodeItem | null; nearestValidAncestor: PageAncestorItem | null }`:
     - `segments` are decoded, lowercased path segments after `/node/` (e.g., `['access', 'research', '2026-notes']`).
     - Matches `segments[0]` against `rootNodes` by `id.toLowerCase()`. If missing, returns `{ matched: false, rootNode: null, nearestValidAncestor: null }`.
     - Walks `segments[1..n]` matching direct children under `currentParentId` by `child.slug.toLowerCase() === seg`. Tracks the deepest valid `nearestValidAncestor` along the way so partial paths like `/node/access/research/typo` return `nearestValidAncestor = research`!
   - `getAncestorChain(pageId: string, rootNodes: NodeItem[], pages: PageRegistry, basePath?: string, titleResolver?: (rootNode: NodeItem) => string): { rootNode: NodeItem | null; ancestors: PageAncestorItem[]; parent: PageAncestorItem | null }`:
     - Returns full ordered chain `[rootChapter, ...intermediatePages, currentPage]`, plus `rootNode` (for `accentColor` inheritance) and `parent` (for `EditorialSidebar` sticky `< <Parent Page Title>` back-link).
   - `buildTwoLevelNavTree(rootNodes: NodeItem[], pages: PageRegistry, activePageId?: string | null, basePath?: string, titleResolver?: (rootNode: NodeItem) => string): NavItem[]`:
     - Strictly **2 levels**: each main chapter becomes a top-level `NavItem` (`level: 'chapter'`, `pageId: root.id`, `href: buildPagePath(...)`, `isActive` when `activePageId` is the chapter or any descendant of it) with `children` containing **only direct Level 2 subpages** (`level: 'subpage'`, `pageId: child.id`, sorted via `getDirectChildren`, zero Level 3+ nesting).

5. **Smart 404 Fuzzy Similarity Matcher**
   - `levenshteinDistance(a: string, b: string): number`: standard iterative O(m*n) distance.
   - `findSimilarPages(attemptedSegments: string[], rootNodes: NodeItem[], pages: PageRegistry, options?: { limit?: number; basePath?: string; minScore?: number; titleResolver?: (n: NodeItem) => string }): PageMatchCandidate[]`:
     - Builds a searchable corpus of all root chapters + all reachable `PageNode`s (with full `path` and human `breadcrumbLabel`, e.g. `"Access / Research / 2026 Notes"`).
     - Combines three normalized signals into a deterministic `[0, 1]` score:
       1. **Token overlap (Jaccard / Dice)** between attempted path tokens (split on `/` and `-`) and candidate slug + title tokens.
       2. **Normalized Levenshtein similarity** (`1 - dist / maxLen`) between the attempted leaf segment (and full path) vs. candidate slug & title.
       3. **Substring bonus** when attempted leaf or tokens are a prefix/substring of candidate slug or title (and small ancestor-chapter bonus if `attemptedSegments[0]` matches candidate's root chapter).
     - Filters by `minScore` (default `0.2`), sorts descending by `score` (stable tie-break by shorter path then alphabetical title), and returns top `limit` (default `5`, capping between 3–5 matches for UI).

## 🛡️ Architectural & UI/UX Guardrails

- **Immutability**: Never mutate caller-supplied `pages`, `rootNodes`, or `canvas` objects in place.
- **Cycle Resilience**: Every parent-pointer traversal (`buildPagePath`, `getAncestorChain`, `getDescendantPageIds`) MUST track a `Set<string>` of visited IDs so even manually corrupted KV JSON can never trigger an infinite loop.
- **Zero-DOM / Edge Portability**: No `window`, `document`, or React imports inside `src/services/pageTreeService.ts`.
- **Single Source of Ordering Truth**: `buildTwoLevelNavTree` and `getDirectChildren` always order by `PageNode.order`, which `deriveSubpageOrderFromCanvas` keeps in lockstep with parent canvas `PageLinkElement` positions.
