## 🎯 Purpose & Scope

Upgrade `src/components/feedback/PageNotFound.tsx` from a static dead-end 404 screen into a **Smart Fuzzy Recovery Page** that gracefully handles moved or mistyped nested subpage URLs:
1. Replace the raw `<button>` (line 47 of `PageNotFound.tsx`) with canonical `<Button>` from `src/components/ui/Button.tsx` (`canonical-ui-enforcement.md`).
2. Add primary **"Return to `<Nearest Valid Parent>`"** CTA when a URL prefix matches an existing chapter or ancestor subpage (falling back cleanly to `"Return to Overview"` when no parent matched).
3. Render **top 3–5 clickable fuzzy-matched page suggestions** (from `pageTreeService.findSimilarPages`) showing each match's page title and muted breadcrumb trail (e.g., `Access / Research / 2026 Notes`) with calm full-width editorial rows, 4-state interactive matrix, and Universal Zero Outline Policy.
4. Wire `src/App.tsx`'s `route === 'not-found'` branch (lines 306–319) to compute `suggestions` via `findSimilarPages(attemptedSegments, ...)` and pass `nearestParent`, `suggestions`, and `onSelectSuggestion`.

### Step-by-Step Implementation Blueprint

1. **Extend `PageNotFoundProps` in `src/components/feedback/PageNotFound.tsx`**
   - Keep all existing props backward compatible (`onReturn`, `title`, `description`, `errorCode`, `returnLabel`, `className`).
   - Add:
     ```ts
     nearestParent?: {
       id: string;
       title: string;
       path?: string;
     } | null;
     onReturnToParent?: (pageId: string) => void;
     suggestions?: PageMatchCandidate[];
     onSelectSuggestion?: (pageId: string) => void;
     ```
   - **Primary CTA Behavior**:
     - If `nearestParent && onReturnToParent`: render canonical `<Button variant="primary" onClick={() => onReturnToParent(nearestParent.id)}>` with label `Return to ${nearestParent.title}` (and optional secondary ghost `<Button variant="ghost" onClick={onReturn}>Return to Overview</Button>` if `onReturn` is also provided).
     - Otherwise if `onReturn`: render canonical `<Button variant="primary" onClick={onReturn}>` with `<EditableText pointId="notFound.returnButton" defaultText={returnLabel} as="span" inline={true} />`.
     - Zero raw `<button>` elements anywhere in `PageNotFound.tsx`.
   - **Fuzzy Suggestions List**:
     - Render only when `suggestions && suggestions.length > 0` (sliced defensively to max 5 items).
     - Semantic `<section aria-label="Similar pages">` with calm caption heading `"Were you looking for"` (zero synthetic badges, zero horizontal dividing lines, generous whitespace `var(--space-flow-layout)`).
     - Render each suggestion as a clean clickable `<a href={item.path}>` (or canonical `<Button variant="ghost">`) row styled via `PageNotFound.module.css` displaying:
       - Thin-stroke `<PageIcon size={16} />` from `src/components/ui/PageIcon.tsx`
       - Match `item.title` (`var(--text-body)`, `var(--text-primary)`, `font-weight: 600`)
       - Match `item.breadcrumbLabel` (`var(--text-caption)`, `var(--text-muted)`, `var(--font-mono)` or sans muted trail)
       - Quiet right arrow using Epic 12's shared `<ArrowRightIcon size={14} className={styles.suggestionArrow} />` from `src/components/ui/Icons.tsx` (nudges `translateX(3px)` on hover — zero copy-pasted inline arrow `<svg>`).
     - Clicking calls `e.preventDefault(); onSelectSuggestion?.(item.id)`.
   - **Prune Epic 12 Exemption (`tests/canonical-ui-enforcement.test.ts`)**:
     - Once the raw `<button>` at line 47 of `PageNotFound.tsx` is replaced with canonical `<Button>`, remove `'src/components/feedback/PageNotFound.tsx': new Set(['button'])` from `RAW_CONTROL_EXEMPTIONS` in `tests/canonical-ui-enforcement.test.ts` (line 47) so the static guardrail locks in compliance permanently.

2. **Update `src/components/feedback/PageNotFound.module.css`**
   - Remove unused legacy `.returnButton` styles once migrated to canonical `<Button>`.
   - Add token-only classes for `.actionsRow`, `.suggestionsSection`, `.suggestionsHeading`, `.suggestionsList`, `.suggestionRow`, `.suggestionMeta`, `.suggestionTitle`, `.suggestionPath`, `.suggestionArrow`.
   - Enforce **4-State Interactive Matrix & Universal Zero Outline Policy** on `.suggestionRow`:
     - Default: `background: var(--page-link-bg)`, `border: 1px solid var(--page-link-border)`, `box-shadow: var(--page-link-shadow)`, `border-radius: var(--page-link-radius)`.
     - Hover: `background: var(--page-link-hover-bg)`, `border-color: var(--page-link-hover-border)`, `transform: translateY(-2px)`, `box-shadow: var(--page-link-hover-shadow)`.
     - Active: `background: var(--page-link-active-bg)`, `transform: translateY(1px)`.
     - Focus / Focus-Visible: `outline: none; outline: 0; background: var(--page-link-hover-bg); border-color: var(--border-focus);`.
   - Respect `@media (prefers-reduced-motion: reduce)` for hover transforms.
   - Zero horizontal dividing lines (`border-top`, `border-bottom`, `<hr>`) between list items — use `gap: var(--space-3)`.

3. **Wire `src/App.tsx` (`route === 'not-found'`, lines 306–319)**
   - Compute `notFoundSuggestions = useMemo(() => route === 'not-found' ? findSimilarPages(attemptedSegments, nodes, portalChrome?.pages ?? {}, { limit: 5, basePath: engineConfig.basePath }) : [], [...])`.
   - Pass `nearestParent={nearestValidAncestor ? { id: nearestValidAncestor.id, title: nearestValidAncestor.title, path: nearestValidAncestor.path } : null}`, `onReturnToParent={(id) => navigateToPage(id)}`, `suggestions={notFoundSuggestions}`, `onSelectSuggestion={(id) => navigateToPage(id)}`, and `onReturn={() => navigateToHome(1)}`.
