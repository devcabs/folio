## 🎯 Purpose & Scope

Enforce the **Single Source of Truth** principle by eliminating the legacy multi-tier fallback maze in draft saving and fetching:
1. **Purge Legacy LocalStorage Draft Reading:** Remove Step 1b in `src/services/draftService.ts#initDraftSession()` that attempts to read draft documents from `window.localStorage` (`folio_draft_canvas_*`). This adheres strictly to the Epic 3/4 Zero-LocalStorage Document Policy.
2. **Purge LocalStorage Live Canvas Fallbacks:** Remove the fallback to `getLiveNodeCanvas(nodeId)` in `initDraftSession()`. Draft baselines hydrate strictly from Cloudflare Edge KV (`/api/public/node/:nodeId`).
3. **Cold-Miss Empty Payload Guard:** When cloning from `/api/public/node/:nodeId`, do not overwrite an existing populated canvas with a cold-miss synthetic empty canvas (`sections: []`).

---

## 🔍 Problem Statement

In `src/services/draftService.ts` and `src/services/canvasLayoutService.ts`:
1. **Multi-Source Draft Fetching:** When initializing a draft, the code checks:
   - In-memory cache
   - Supabase `engine_drafts`
   - LocalStorage draft keys (`getDraftCanvasKey`)
   - Edge KV (`/api/public/node/:nodeId`)
   - LocalStorage live keys (`getLiveNodeCanvas`)
   This creates a 5-tier fallback maze where stale data from old sessions or empty localStorage keys corrupt the draft baseline.
2. **Violation of Zero-LocalStorage Policy:** In Epic 3 (Subtask 3.1) and Epic 4, `purgeLegacyDocumentStorage()` was established to delete `_draft_canvas_*` and `_live_canvas_*` from `localStorage` to prevent 5MB quota crashes. Retaining fallback reads to these keys creates ghost states that can never succeed.
3. **Cold-Miss Overwrite:** When Edge KV returns a cold-miss payload (`sections: []`), `initDraftSession` accepts it as a valid published canvas, clobbering rendered content.

## 🏛️ Karpathy Heuristics & Rules

1. **Think Before Coding:**
   - Both public visitors and authoring drafts must fetch their baseline from the exact same single place: Cloudflare Edge KV (`/api/public/node/:nodeId`).
   - Eliminate all legacy fallback branches that query `localStorage` for canvas documents.
2. **Make Surgical Changes:**
   - Delete Step 1b (`storage.getItem(getDraftCanvasKey(nodeId))`) from `initDraftSession()`.
   - In `getNodeCanvas(nodeId, isDevMode)`: read `inMemoryDraftCanvases` exclusively when `isDevMode === true`.
   - Guard against cold-miss empty payloads clobbering existing populated documents.
3. **Verify Everything:**
   - Verify that `initDraftSession()` clones from `/api/public/node/:nodeId` without touching `localStorage`.

### Step 1: Strip LocalStorage Draft Reading from `canvasLayoutService.ts`

In `src/services/canvasLayoutService.ts#getNodeCanvas()`:
```ts
export function getNodeCanvas(nodeId: string, isDevMode = false): NodeCanvasDocument {
  // Developer Mode: Read strictly from in-memory draft channel (Zero-LocalStorage policy)
  if (isDevMode) {
    const memoryDraft = getInMemoryDraftCanvas(nodeId);
    if (memoryDraft && isValidCanvasDocument(memoryDraft, nodeId)) {
      return {
        ...memoryDraft,
        sections: renumberSections(memoryDraft.sections),
      };
    }
    return createDefaultCanvasDocument(nodeId);
  }

  // Public Mode: Return baseline shell; Edge KV is the sole authority
  return createDefaultCanvasDocument(nodeId);
}
```

### Step 2: Strip Fallback Maze in `draftService.ts`

In `src/services/draftService.ts#initDraftSession()`:
1. **Remove** Step 1b (local storage reading loop for `getDraftCanvasKey(nodeId)`).
2. Refactor Step 2 to hydrate strictly from Edge KV:
```ts
      // 2. Clone active published baseline strictly from Cloudflare Edge KV (Single Source of Truth)
      if (typeof window !== 'undefined' && typeof fetch === 'function') {
        await Promise.all(
          NODE_IDS.map(async (nodeId) => {
            try {
              const res = await fetch(`/api/public/node/${nodeId}`);
              if (res.ok) {
                const edgePayload = await res.json();
                if (edgePayload?.canvas && isValidCanvasDocument(edgePayload.canvas, nodeId)) {
                  const existingDoc = inMemoryDraftCanvases[nodeId];
                  const incomingSections = edgePayload.canvas.sections;
                  // Guard: do not overwrite populated document with cold-miss empty canvas
                  if (
                    incomingSections.length > 0 ||
                    !existingDoc ||
                    existingDoc.sections.length === 0
                  ) {
                    inMemoryDraftCanvases[nodeId] = JSON.parse(JSON.stringify(edgePayload.canvas));
                  }
                  return;
                }
              }
            } catch {
              // Network unreachable: retain existing in-memory document
            }
          })
        );
      }
```
