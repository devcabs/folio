## 🎯 Purpose & Scope

Build the `<CanvasPageLink>` editorial card leaf component and wire it into `<DocumentCanvas>` with automatic **canvas-to-page-tree order synchronization**:
1. Render `<CanvasPageLink>` as a **calm full-width editorial row** matching the reading column width—resolving live `PageNode.title`, optional `PageNode.summary`, and folder URL directly from `PortalChromeContext.pages` (single authority, never stale).
2. Enforce the complete **4-State Interactive Matrix**, **Universal Zero Outline Policy**, **zero horizontal dividing lines**, **zero badge theater**, and **Disabled / Missing Target** handling (hidden from public visitors; calm recovery/missing state in Dev Mode).
3. Register `'page-link'` in `DocumentCanvas.tsx` (`renderCanvasLeaf`, `CanvasItemControls`, click navigation via `onNavigateToPage`, uniform `✎ Edit` hook point for `13.13`, and Delete hook point for `13.15`).
4. Wire **automatic order sync on reorder**: whenever a `PageLinkElement` is reordered on a canvas via `moveItem` (up/down) or `relocateItem` (drag-and-drop), run `deriveSubpageOrderFromCanvas` and atomically persist the updated `pages` order alongside the reordered canvas (with a single workspace undo command) so `AppHeader`'s Level 2 dropdown reflects the new order immediately!

### Step-by-Step Implementation Blueprint

1. **Create `src/components/canvas/CanvasPageLink.tsx` & `CanvasPageLink.module.css`**
   - Props:
     ```ts
     export interface CanvasPageLinkProps {
       element: PageLinkElement;
       nodeId: string;
       accentColor?: string;
       onNavigate?: (pageId: string) => void;
       onEdit?: () => void;
       className?: string;
     }
     ```
   - Read `pages = portalChrome?.pages ?? {}`, `targetPage = pages[element.targetPageId]`, and `{ isDevMode, isDesktop } = useDeveloperMode()`.
   - **Missing Target Handling**:
     - If `!targetPage`:
       - **Public Mode (`!isDevMode`)**: return `null` (completely hidden from public readers — zero broken cards!).
       - **Dev Mode (`isDevMode`)**: render a calm, non-navigable disabled card (`opacity: var(--page-link-disabled-opacity)` / `cursor: not-allowed`, `aria-disabled="true"`) displaying thin-stroke `<PageIcon />` + `"Linked subpage unavailable"` + muted caption `"Target page no longer exists in draft registry. Remove or undo to restore."` so coordinators can delete or undo cleanly.
   - **Valid Target Rendering**:
     - Compute canonical `href = buildPagePath(targetPage.id, getActiveNodes(), pages, getEngineConfig().basePath)`.
     - Render outer `<div className={styles.rowWrapper}>` (supporting uniform side `✎ Edit` canonical `<Button variant="admin" size="xs">✎ Edit</Button>` in Dev Mode on desktop — matching `CanvasPdf`/`CanvasText` side edit pattern, strictly labeled `"Edit"` with zero custom text!).
     - Render clickable full-width editorial anchor `<a href={href} className={styles.cardLink} onClick={(e) => { e.preventDefault(); onNavigate?.(targetPage.id); }}>`:
       - Left: `<span className={styles.iconSlot} aria-hidden="true"><PageIcon size={18} /></span>` (shared canonical primitive from `13.3` — zero emoji, zero duplicated inline `<svg>`).
       - Center: `<span className={styles.textBlock}>`
         - `<span className={styles.title}>{targetPage.title}</span>` (`var(--font-display)` or `var(--font-sans)` semi-bold `var(--text-subhead)`, `var(--tracking-tight)`, `var(--text-primary)`).
         - Optional `{targetPage.summary && <span className={styles.summary}>{targetPage.summary}</span>}` (`var(--text-caption)` or `var(--text-body-sm)`, `var(--text-secondary)` / `var(--text-muted)`, 1-line calm rhythm).
       - Right: `<span className={styles.arrow} aria-hidden="true"><ArrowRightIcon size={14} /></span>` (consuming Epic 12's shared `ArrowRightIcon` from `src/components/ui/Icons.tsx`; nudges `transform: translateX(4px)` on hover — zero copy-pasted inline `<svg>`).
     - **Zero Badge Theater**: Do NOT render child counts, `"Subpage"` pills, or timestamps on the card.
   - **Styling in `CanvasPageLink.module.css`** (100% pure tokens from `src/styles/tokens.css`):
     - Full reading-column width (`width: 100%; box-sizing: border-box;`), vertical rhythm `margin: var(--space-3) 0;`, **zero horizontal dividing lines** (`border-top`/`border-bottom` rules as dividers prohibited; only subtle perimeter card hairline `border: 1px solid var(--page-link-border)`).
     - **4-State Interactive Matrix**:
       - Default: `background: var(--page-link-bg); border: 1px solid var(--page-link-border); box-shadow: var(--page-link-shadow); border-radius: var(--page-link-radius); padding: var(--page-link-padding-y) var(--page-link-padding-x);`
       - Hover: `background: var(--page-link-hover-bg); border-color: var(--page-link-hover-border); transform: translateY(-2px); box-shadow: var(--page-link-hover-shadow);` + `.arrow { transform: translateX(4px); color: var(--folio-primary); }`
       - Active / Pressed: `background: var(--page-link-active-bg); transform: translateY(1px);`
       - Focus / Focus-Visible: `outline: none; outline: 0; background: var(--page-link-hover-bg); border-color: var(--border-focus);` (Universal Zero Outline Policy).
       - Disabled / Missing: `opacity: var(--page-link-disabled-opacity); cursor: not-allowed; pointer-events: none;` (while leaving Dev Mode `CanvasItemControls` Delete/Edit operable on the outer wrapper).
     - Respect `@media (prefers-reduced-motion: reduce)`.

2. **Register `CanvasPageLink` & Export Barrel**
   - Export `CanvasPageLink` and `type CanvasPageLinkProps` from `src/components/canvas/index.ts`.
   - Extend `NodeCanvasProps` in `src/components/canvas/DocumentCanvas.tsx` (line 44) with optional `onNavigateToPage?: (pageId: string) => void;`.
   - Add `case 'page-link':` to `renderCanvasLeaf` (line 111 of `DocumentCanvas.tsx`) rendering `<CanvasPageLink element={leaf} nodeId={nodeId} accentColor={accentColor} onNavigate={onNavigateToPage} onEdit={onEditLeaf ? () => onEditLeaf(leaf) : undefined} />`.

3. **Automatic Canvas Reorder → `PageNode.order` Synchronization**
   - In `src/hooks/useDocumentCanvas.ts` (inside `moveItem` and `relocateItem`):
     - After computing `nextDoc` for `nodeId`, inspect whether the canvas contains any `page-link` elements (or check `portalChrome?.pages`).
     - Call `deriveSubpageOrderFromCanvas(currentPages, nodeId, nextDoc)` from `pageTreeService.ts`.
     - If `changed === true`:
       - Persist BOTH `{ canvases: { [nodeId]: nextDoc }, pages: nextPages }` in the **same atomic `PUT /api/draft`** request (via `commitWorkspaceMutation` / `commitDraftWorkspaceTransaction`) and store BOTH `before: { canvases, pages: prevPages }` and `after: { canvases, pages: nextPages }` inside the single workspace undo command!
       - Because `PortalChromeContext.pages` updates immediately on commit, `AppHeader`'s Level 2 dropdown order updates in real time with zero reload—and pressing `Cmd+Z` reverts BOTH the card position AND the `AppHeader` dropdown order atomically!

## 🛡️ Architectural & UI/UX Guardrails

- **Zero Horizontal Dividing Lines (`editorial-restraint.md` §6)**: Card rows stack via spacing (`--space-3` / `--space-4`), never `<hr>` or row divider lines.
- **Zero Badge Theater**: Never render child-page counters, `"Subpage"` tags, or status dots on `CanvasPageLink`.
- **Single Title Authority**: `CanvasPageLink` NEVER stores a duplicated title in `PageLinkElement`; it reads live `pages[element.targetPageId].title` and `.summary`.
- **Canonical UI**: Consumes `<PageIcon />`, `<ArrowRightIcon />`, and `<Button variant="admin">` from `src/components/ui/`; zero raw `<button>`, zero cross-component `.module.css` imports, zero copy-pasted `<svg>` (`tests/canonical-ui-enforcement.test.ts` passes). Note that `CanvasItemControls` already consumes Epic 12's `IconButton`, `EditIcon`, and `TrashIcon` for `'page-link'` items automatically.
