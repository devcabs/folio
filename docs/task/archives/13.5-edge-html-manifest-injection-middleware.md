## 🎯 Purpose & Scope

Eliminate the ~150ms cold-load manifest fetch gap on deep subpage URLs (`/node/<chapter>/<subpage>/.../`) by injecting the active `portal:manifest` JSON directly into HTML document responses (`window.__FOLIO_MANIFEST__`) at the Cloudflare Edge inside `handleFolioEdgeRequest`. This guarantees **zero-wait (0ms) synchronous page-tree resolution** on initial boot with zero false 404 flashes, while strictly preserving the 5-line Consumer `worker.ts` delegation contract.

### Step-by-Step Implementation Blueprint

1. **Create `src/edge/handlers/htmlManifestInjector.ts`**
   - Export `serializeManifestForHtmlScript(manifestJson: string): string`:
     - Validates/normalizes JSON string (or accepts `PublicPortalManifestPayload` object) and escapes every dangerous character sequence for safe embedding inside `<script>` tags:
       - `<` -> `\\u003c` (prevents `</script>` breakout and `<!--` HTML comments)
       - `>` -> `\\u003e`
       - `&` -> `\\u0026`
       - `\u2028` -> `\\u2028` (JS line separator safety)
       - `\u2029` -> `\\u2029` (JS paragraph separator safety)
     - Returns `<script id="folio-manifest-bootstrap">window.__FOLIO_MANIFEST__=${escaped};</script>`.
   - Export `injectManifestIntoHtml(html: string, manifestRaw: string): string`:
     - Parses `manifestRaw` safely (try/catch; if malformed JSON, returns original `html` untouched — never crashes an HTML page render!).
     - Builds script tag via `serializeManifestForHtmlScript`.
     - Injects immediately before closing `</head>` (case-insensitive `/<\/head>/i`). If `</head>` is absent, prepends before `</body>` or at start of HTML.
   - Export `maybeInjectManifestResponse(request: Request, response: Response, kv: KVNamespace | null): Promise<Response>`:
     - **Fast Passthrough Guards** (return original `response` untouched):
       - `request.method.toUpperCase() !== 'GET'`
       - `!kv`
       - `response.status < 200 || response.status >= 300`
       - Content-Type header does NOT include `text/html` (so `.js`, `.css`, `.png`, `.svg`, `.woff2`, `.json` assets pass through with zero body buffering!)
     - Reads `const manifestRaw = await kv.get('portal:manifest')` inside `try/catch` (graceful passthrough if `null` or KV read throws).
     - Reads `const html = await response.text()`, runs `injectManifestIntoHtml(html, manifestRaw)`.
     - Clones response headers, deletes stale `content-length` and `etag` (since body bytes changed), sets `Cache-Control: public, max-age=0, must-revalidate` (so newly published subpages are reflected immediately on reload), and returns `new Response(injectedHtml, { status: response.status, statusText: response.statusText, headers })`.

2. **Wire Multi-Segment SPA Fallback & HTML Injection in `src/edge/router.ts`**
   - Inspect `src/edge/router.ts` lines 194–203 (Section 2: Static Assets & Single Page App Fallthrough):
     - Add optional `disableHtmlManifestInjection?: boolean` to `FolioEdgeOptions`.
     - Fetch asset response via `let assetResponse = await env.ASSETS.fetch(request)`.
     - **Multi-Segment SPA Fallback Safety**: If `assetResponse.status === 404` and the request is a `GET` for an HTML navigation route (not starting with `/api`, no file extension in the last path segment like `.js`/`.css`/`.png`/`.ico`, or `Accept` includes `text/html`), retry `env.ASSETS.fetch(new Request(new URL('/index.html', request.url), { method: 'GET', headers: request.headers }))` so deep folder URLs (`/node/access/research/2026-notes/`) always serve the SPA shell even if host `wrangler.toml` lacks explicit SPA fallback rules.
     - If `!options?.disableHtmlManifestInjection`, resolve `kv = resolveKVNamespace(env, options)` and return `await maybeInjectManifestResponse(request, assetResponse, kv)`.

3. **Export Helpers from `src/edge.ts`**
   - Export `serializeManifestForHtmlScript`, `injectManifestIntoHtml`, and `maybeInjectManifestResponse` from `src/edge.ts` so they are available on `@devcabs/folio-engine/edge` while consumers keep the exact 5-line `worker.ts` delegation (`return handleFolioEdgeRequest(request, env, ctx)`).

## 🛡️ Architectural & UI/UX Guardrails

- **XSS Defense (`security-guidance`)**: NEVER interpolate raw `manifestRaw` directly into `<script>` without escaping `<`, `>`, `&`, `\u2028`, `\u2029`.
- **Zero-Latency Asset Path**: Non-HTML responses MUST return immediately before touching KV or calling `.text()`.
- **Zero Consumer Duplication (`version-doctor`)**: Consumer apps MUST NOT add custom middleware in `worker.ts`; `handleFolioEdgeRequest` handles HTML injection automatically.
