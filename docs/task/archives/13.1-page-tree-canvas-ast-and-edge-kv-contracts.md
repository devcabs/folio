## 🎯 Purpose & Scope

Establish the foundational, backward-compatible TypeScript data contracts and runtime Zod schemas for Epic 13's dynamic nested subpage tree across all layers (Canvas AST, Edge KV, Revision History, Undo/Redo, and 2-Level Navigation) before any service, Edge handler, or UI component is implemented.

### Step-by-Step Implementation Blueprint

1. **Create `src/types/page.ts` (Canonical Page Tree Contract & Zod Schema)**
   - Define and export:
     - `PAGE_ID_REGEX = /^[a-z0-9_-]{1,64}$/` (strictly matching `NODE_ID_REGEX` in `src/edge/handlers/publicHandler.ts` line 14 so `/api/public/node/:nodeId` serves dynamic `page-*` canvases with zero route changes).
     - `PAGE_SLUG_REGEX = /^[a-z0-9]+(?:-[a-z0-9]+)*$/` (lowercase alphanumeric kebab-case; length 1–64).
     - `PageNode`:
       ```ts
       export interface PageNode {
         /** Unique stable page identifier matching PAGE_ID_REGEX (e.g. "page-<base36ts>-<rand>") */
         id: string;
         /** Parent chapter ID (from EngineConfig.nodes) or parent PageNode.id; null reserved for future root compatibility */
         parentId: string | null;
         /** URL folder segment under its parent (strictly sanitized, unique among siblings) */
         slug: string;
         /** Single-authority display title shared across Page Link card, PageTitle, Breadcrumb, and AppHeader */
         title: string;
         /** Optional extended subtitle */
         subtitle?: string;
         /** Optional 1-line summary (recommended <= 15 words per editorial-restraint.md) */
         summary?: string;
         /** Zero-based display order among siblings (synced from parent canvas PageLinkElement order) */
         order: number;
         /** ISO 8601 creation timestamp */
         createdAt: string;
         /** ISO 8601 last-update timestamp */
         updatedAt: string;
       }
       ```
     - `PageRegistry = Record<string, PageNode>`
     - `PageNodeSchema` (Zod): validates `id` against `PAGE_ID_REGEX`, `parentId: z.string().min(1).nullable()`, `slug` against `PAGE_SLUG_REGEX` (max 64 chars), `title: z.string().min(1)`, optional `subtitle`/`summary`, `order: z.number().int().nonnegative()`, `createdAt: z.string().min(1)`, `updatedAt: z.string().min(1)`.
     - `PageRegistrySchema = z.record(z.string(), PageNodeSchema)`.
     - Helper interfaces used downstream by `pageTreeService.ts` and routing:
       - `PageAncestorItem`: `{ id: string; title: string; slug: string; path: string; isRootChapter: boolean }`
       - `PageMatchCandidate`: `{ id: string; title: string; path: string; breadcrumbLabel: string; score: number }`
       - `PageMutationPayload` (optional shared DTO for `PUT /api/draft` extensions): `{ pages?: PageRegistry; deletedPageIds?: string[] }`.

2. **Extend `src/types/edge.ts` (KV, Manifest & Canvas Zod Schemas)**
   - Import `PageNode`, `PageNodeSchema`, `PageRegistrySchema` from `./page` and re-export them so `@devcabs/folio-engine/edge` has access without circular imports.
   - Add `pages?: Record<string, PageNode>` to:
     - `PublicPortalManifestPayload` (line 92)
     - `DraftWorkspacePayload` (line 103)
   - Add `deletedPageIds?: string[]` to a new exported `DraftWorkspaceUpdateRequest` interface (extending `Partial<DraftWorkspacePayload>` with `expectedRevision?: number`, `expectedUpdatedAt?: string`, `deletedPageIds?: string[]`) used by `draftHandler.ts` and `draftService.ts`.
   - Extend `PublicPortalManifestPayloadSchema` (line 117) with `pages: PageRegistrySchema.optional()`.
   - Add `PageLinkElementSchema`:
     ```ts
     export const PageLinkElementSchema = z.object({
       id: z.string(),
       type: z.literal('page-link'),
       targetPageId: z.string().min(1),
     }).passthrough();
     ```
   - Add `PageLinkElementSchema` to `CanvasLeafElementSchema` union (line 186) so `compilePublicNodePayload` (`PublicNodePayloadSchema.parse(payload)`) validates published canvases containing `page-link` blocks without throwing.
   - Add `declare global { interface Window { __FOLIO_MANIFEST__?: PublicPortalManifestPayload; } }` in `src/types/edge.ts` (or `src/vite-env.d.ts` + exported helper type) so browser code can safely read `window.__FOLIO_MANIFEST__` without `any` casts.

3. **Extend `src/types/canvas.ts` (Canvas AST & Modal Contracts)**
   - Add `'page-link'` to `CanvasElementType` (line 10) and `CanvasModalElementType` (line 199).
   - Define `PageLinkElement`:
     ```ts

     ```
   - Add `PageLinkElement` to `CanvasLeafElement` union (line 104).
   - Update `isLeafElement` (line 158) to include `el.type === 'page-link'` and export `isPageLinkElement(el: CanvasElement): el is PageLinkElement`.
   - Extend `CanvasElementFormData` (line 208) with optional page fields:
     - `slug?: string;` (URL segment name for `page-link` add/edit)
     - `summary?: string;` (optional ≤15-word 1-line summary for `page-link` add/edit)
   - Update `src/utils/canvasDefaults.ts`: add `createDefaultPageLink(targetPageId: string): PageLinkElement` using `generateCanvasId('page-link')` (zero parentheses in any copy).

4. **Extend `src/types/history.ts`, `src/types/draft.ts`, and `src/types/navigation.ts`**

     - Add optional `totalSubpages?: number` and `totalPageLinkElements?: number` to `SnapshotMetricsSummary` (line 59).
   - **`src/types/draft.ts`**:
