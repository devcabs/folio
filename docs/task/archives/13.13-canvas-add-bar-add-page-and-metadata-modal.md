## 🎯 Purpose & Scope

Enable editors in Developer/Coordinator Mode to **create nested subpages** and **edit subpage metadata** right from the canvas with a **1:1 Card-to-Subpage Lifecycle** and atomic persistence:
1. Add the **"Page"** (`type: 'page-link'`) option into `CanvasAddBar`'s element palette (alongside Section, Subsection, Text, Photo, Document, Chart), consuming the shared thin-stroke `PageIcon` primitive from `src/components/ui/PageIcon.tsx`.
2. Wire the canonical `'page-link'` Add/Edit Page fields into **Epic 12's shared `src/components/canvas/CanvasElementFields.tsx`** (consumed by both `UniversalEditModal.tsx` and `CanvasAddModal.tsx`, which already includes `'page-link'` in `CanvasElementFieldType` at line 24 — strictly consuming canonical `FormField` and `Input` from `src/components/ui/` with **zero raw `<input>` or `<button>` elements** and zero inline form duplication in `UniversalEditModal.tsx`!):
   - **Page Title** (required)
   - **URL Name / Slug** (required; smart default auto-generated from Title as the editor types until manually edited, strictly URL-sanitized via `pageTreeService.sanitizeSlug`, inline sibling-uniqueness validation via `pageTreeService.validateSlug`, plus live `var(--font-mono)` full folder-path preview e.g. `/node/access/research/2026-notes/`)
   - **Optional 1-Line Summary** (validated against `MAX_PAGE_SUMMARY_WORDS = 15` per `editorial-restraint.md`, with live exact word count e.g. `7 / 15 words`).
3. On **Add Page** save: execute **one atomic `PUT /api/draft` transaction** that registers the new `PageNode` in `draft.pages`, initializes `draft.canvases[newPageId] = createDefaultCanvasDocument(newPageId)`, and inserts the `PageLinkElement` at the chosen position in the parent canvas (plus syncs `order`), recording **one workspace-level undo command** (`type: 'page_create'`)!
4. On **Edit Page Link Card** (`✎ Edit`): open the same canonical `'page-link'` form pre-populated from live `PageNode`, and save updated `title`, `slug`, and `summary` atomically to `draft.pages` with **one workspace-level undo command** (`type: 'page_update_metadata'`).

## 🛡️ Architectural & UI/UX Guardrails

- **Canonical UI Enforcement & Anti-Duplication**: The `'page-link'` fields MUST live inside Epic 12's shared `CanvasElementFields.tsx` (never duplicated inline in `UniversalEditModal.tsx`), strictly consuming canonical `<FormField>`, `<Input>`, `<Button>`, `<Modal>`, and `<ModalActions>` from `src/components/ui/` — zero raw `<input>` or `<button>` (`tests/canonical-ui-enforcement.test.ts` passes).
- **Atomic 1:1 Lifecycle**: NEVER create a `PageNode` without inserting its `PageLinkElement` (or vice versa) — both MUST commit in a single `PUT /api/draft` payload so partial failure cannot produce ghost/orphan pages.
- **Word-Budget Restraint**: Enforce the ≤15-word summary limit with exact Evaluative Ease feedback (`N / 15 words`).
- **Fail-Stop Error Handling**: If `PUT /api/draft` fails, do NOT close the modal silently — surface the error via `showToast(..., 'error')` and leave the form open so the editor does not lose typed metadata.
