## Objective

Establish the minimal TypeScript contracts, Zod edge schemas, standard-link URL resolver (Google Drive + YouTube), default factory, and CSS design tokens needed for inline `video` blocks and mixed photo/video Drive galleries.

### 4. Standard Video URL Resolver (No YouTube API)
- **[src/utils/mediaUrl.ts](file:///Users/francisdave/Documents/folio/src/utils/mediaUrl.ts)**:
  - Add `extractYouTubeVideoId(input: string): string | null` supporting:
    - `youtube.com/watch?v={id}`
    - `youtu.be/{id}`
    - `youtube.com/shorts/{id}`
    - `youtube.com/live/{id}`
    - `youtube.com/embed/{id}`
  - Add `resolveSingleVideoUrl(input: string): ResolvedSingleVideo | null`:
    - Returns `{ provider: 'youtube', fileId, embedUrl: 'https://www.youtube-nocookie.com/embed/{id}', viewUrl: 'https://www.youtube.com/watch?v={id}', rawUrl }` (preserving optional `?t=` / `?start=` seconds if present).
    - Otherwise falls back to `extractDriveFileId(input)` (rejecting `/folders/`): `{ provider: 'drive', fileId, embedUrl: buildDrivePreviewUrl(fileId), viewUrl: buildDriveViewUrl(fileId), rawUrl }`.
    - Returns `null` for unsupported/invalid URLs or Drive folder links.
  - Add `formatVideoDuration(durationMs?: number): string | null`:
    - Formats milliseconds as `M:SS` or `H:MM:SS` (returns `null` for invalid/`<= 0`).

## TDD Test Plan

Write `tests/utils/video-url-resolver.test.ts` **first**:
1. Resolves all 5 YouTube URL formats (`watch`, `youtu.be`, `shorts`, `live`, `embed`) to `youtube-nocookie.com/embed/{id}`.
2. Preserves `?t=90`, `?t=1m30s`, and `?start=45` as `?start=...` on YouTube embed URLs.
3. Resolves Google Drive single-file links (`/file/d/{id}/view`, `/open?id=`, bare ID) to `provider: 'drive'` + `/preview`.
4. Rejects Google Drive folder URLs (`/folders/...`) and non-video URLs.
5. `formatVideoDuration` formats `0` → `null`, `5000` → `'0:05'`, `125000` → `'2:05'`, `3661000` → `'1:01:01'`.
6. `VideoElementSchema.safeParse` accepts valid `VideoElement` payloads and rejects invalid types.
