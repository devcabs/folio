## 🎯 Purpose & Scope

Eliminate fake publishing fallbacks and unbacked sync promises across the client authoring UI:
1. **Fail-Stop on Remote Errors:** When `POST /api/publish` returns non-2xx (400, 404, 500, 502) or fetch throws a network exception, `publishNewSnapshot()` in `src/services/historyService.ts` must abort immediately. It must **never** advance `activePublishedId`, **never** save to live storage, and **never** clear `isDraftDirty()`.
2. **Purge "Close Anyway" Bypass:** Remove the "Close Anyway" button and the misleading `edge_failed` checklist from `DevPublishModal.tsx`. When publish fails, the modal stays open displaying the real error with **Retry** and **Cancel** buttons.
3. **Purge Ghost Sync Toast:** Remove `"Published locally. Cloud sync pending reconnection"` from `DevModeBadge.tsx`. Display success only when publication is confirmed live.
4. **Server Handler Verification:** In `src/edge/handlers/publishHandler.ts`, return HTTP 200 `{ success: true }` only when edge deployment succeeds. If Cloudflare KV or Supabase fails, return HTTP 502 with `{ success: false, error: ... }`.

## 🔍 Problem Statement

1. **The Fallback Illusion:** In `src/services/historyService.ts#L1085-L1173`, when `/api/publish` fails with 404, 500, or a network timeout, the client falls through to saving the snapshot into `localStorage` (`folio_live_canvas_*`), advances `activePublishedId`, clears the dirty draft, and reports `success: true`. The coordinator thinks their changes are live, while the public portal remains completely unchanged.
2. **The "Close Anyway" Trap:** In `src/components/dev/DevPublishModal.tsx#L168-L173`, when edge deployment fails, clicking "Close Anyway" fires `onPublished`, celebrating a successful publication even though the edge was never updated.
3. **Ghost Toast:** In `src/components/dev/DevModeBadge.tsx#L331-L339`, the UI promises cloud sync is pending reconnection without any background sync engine or service worker.

### Step 1: Enforce Fail-Stop in `src/services/historyService.ts`

```ts
// In publishNewSnapshot() around line 1073:
let publishData: any = null;

try {
  const endpoint =
    typeof window !== 'undefined' && window.location?.origin
      ? `${window.location.origin}/api/publish`
      : '/api/publish';

  const publishRes = await fetch(endpoint, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ snapshot }),
  });

  if (!publishRes.ok) {
    let errorMsg = `Server publish failed with HTTP ${publishRes.status}`;
    try {
      const errJson = await publishRes.json();
      if (errJson?.error) errorMsg = errJson.error;
    } catch {
      // Body not JSON
    }
    return {
      success: false,
      snapshot: null as unknown as PublishedSnapshot,
      localSaved: false,
      cloudSynced: false,
      edgeDeployed: false,
      error: errorMsg,
    };
  }

  publishData = await publishRes.json();
} catch (err: unknown) {
  const msg = err instanceof Error ? err.message : 'Network error during publish';
  return {
    success: false,
    snapshot: null as unknown as PublishedSnapshot,
    localSaved: false,
    cloudSynced: false,
    edgeDeployed: false,
    error: `Unable to reach publish server: ${msg}`,
  };
}

if (!publishData || publishData.success !== true) {
  return {
    success: false,
    snapshot: null as unknown as PublishedSnapshot,
    localSaved: false,
    cloudSynced: false,
    edgeDeployed: false,
    error: publishData?.error || 'Server did not confirm publication',
  };
}

// ONLY reached upon confirmed server success:
for (const nodeId of getActiveNodeIds()) {
  saveLiveNodeCanvas(canvases[nodeId], { silent: true });
}
dispatchAggregateCanvasChange(false);
setLiveContentOverrides(contentOverrides);

manifest.snapshots = [unifiedSnapshot, ...manifest.snapshots];
manifest.activeMilestoneId = snapshot.id;
manifest.activePublishedId = snapshot.id;
setActivePublishedId(snapshot.id);
saveHistoryManifest(manifest);
syncDraftWithPublished(canvases, contentOverrides);

return {
  success: true,
  snapshot,
  localSaved: true,
  cloudSynced: publishData.cloudSynced === true,
  edgeDeployed: publishData.edgeDeployed === true,
};
```
