## 🎯 Purpose & Scope

Build the Google Drive PDF folder synchronization service (`src/services/driveDocumentSyncService.ts`) and reactive React 19 hook (`src/hooks/useDriveDocumentSync.ts`), directly mirroring `drivePhotoSyncService.ts` and `useDrivePhotoSync.ts`:
1. **`driveDocumentSyncService.ts`**:
   - Queries Google Drive REST API v3 (`files.list`) for `application/pdf` files inside a public Google Drive folder (including 1st-level subfolders, Shared Drives `supportsAllDrives=true`, and `X-Goog-Drive-Resource-Keys` support).
   - Cleans raw PDF filenames into readable editorial titles (`cleanDriveDocumentName`, e.g., `"01_Division_Memo_2026.pdf"` → `"Division Memo 2026"`).
   - Sorts PDFs using natural numeric filename collation (`compareNaturalFilenames` from `drivePhotoSyncService.ts`).
   - Performs O(1) Map differential reconciliation (`reconcileDriveDocuments`), preserving existing `SyncedDocumentItem` IDs, custom coordinator titles (`isCustomTitle: true`), and custom captions while pruning deleted Drive files and computing `{ added, removed, retained, total, hasChanged }` stats.
   - Formats `previewUrl` (`https://drive.google.com/file/d/{id}/preview`) and `viewUrl` (`https://drive.google.com/file/d/{id}/view`) using `buildDrivePreviewUrl` and `buildDriveViewUrl` from `src/utils/mediaUrl.ts`.
2. **`useDriveDocumentSync.ts`**:
   - Non-blocking React 19 hook implementing the deterministic 5-state lifecycle (`never_synced` | `syncing` | `synced_success` | `synced_empty` | `sync_error`).
   - Reads `syncedDocuments` strictly from `DocumentsElement.syncedDocuments` in the Canvas AST and persists reconciled documents back to the AST via `onPersistDocuments` (`PUT /api/draft`).

### Explicit Non-Goals
- Do **not** mix `application/pdf` files into `fetchDriveFolderImages` or `GalleryElement.syncedPhotos`—photo galleries (`SourceGallery`) and PDF document folders (`SourceDocuments`) are strictly separate element types.
- Do **not** duplicate `extractDriveFolderId`, `extractResourceKey`, or `compareNaturalFilenames`; import and reuse them from `driveVerificationService.ts` and `drivePhotoSyncService.ts`.

## 📐 Service & Hook Contracts

### 1. `src/services/driveDocumentSyncService.ts`
```ts
import type {
  DriveDocumentFile,
  SyncedDocumentItem,
  DriveDocumentReconciliationResult,
  SyncFolderDocumentsResult,
} from '../types/source';

/**
 * Strips .pdf extension, machine prefixes (DOC_, PDF_, numeric prefixes),
 * and underscores/hyphens into a clean editorial document title.
 */
export function cleanDriveDocumentName(rawName: string): string;

/**
 * Pure O(1) Map Differential Reconciliation Engine for Google Drive PDF files.
 * Preserves existing custom titles (isCustomTitle: true) and captions.
 */
export function reconcileDriveDocuments(
  existingItems: SyncedDocumentItem[],
  incomingFiles: DriveDocumentFile[],
  pointId: string
): DriveDocumentReconciliationResult;

/**
 * Queries Google Drive REST API v3 to list PDF files (mimeType === 'application/pdf'
 * or /\.pdf$/i) within a public Drive folder and its 1st-level subfolders.
 */
export async function fetchDriveFolderPdfs(
  folderUrlOrId: string
): Promise<DriveDocumentFile[]>;

/**
 * High-level orchestration function for syncing a DocumentsElement's Google Drive folder.
 */
export async function syncFolderDocuments(
  pointId: string,
  folderUrl: string,
  existingDocuments?: SyncedDocumentItem[]
): Promise<SyncFolderDocumentsResult>;
```

## 🧪 TDD & Verification Criteria

1. **Write Unit Tests First (`tests/services/drive-document-sync.test.ts`)**:
   - **`cleanDriveDocumentName`**:
     - `"01_Annual_Procurement_Plan_2026.pdf"` → `"Annual Procurement Plan 2026"`
     - `"DOC_20261118_Signed_MOA.PDF"` → `"Signed MOA"`
     - `""` → `"Official Document"`
   - **`reconcileDriveDocuments`**:
     - Empty existing + 3 incoming PDFs → `added: 3, removed: 0, retained: 0, total: 3, hasChanged: true`, sorted in natural numeric order with `previewUrl` (`/file/d/{id}/preview`) and `viewUrl` (`/file/d/{id}/view`).
     - Existing item with `isCustomTitle: true, title: "Board Resolution No. 5"` retains its custom title when re-synced.
     - File removed from Drive is pruned (`removed: 1, hasChanged: true`).
     - Re-syncing identical files yields `added: 0, removed: 0, retained: 3, hasChanged: false`.
   - **`fetchDriveFolderPdfs`**:
     - Filters strictly for PDF files (`mimeType === 'application/pdf'` or `.pdf` extension), ignoring `.jpg`/`.png` images in the same folder.
     - Scans 1st-level subfolders (`application/vnd.google-apps.folder`) and aggregates PDFs.
     - Surfaces clear diagnostic error messages on HTTP 403 (restricted folder vs. API key referrer block) and HTTP 404.
   - **`useDriveDocumentSync`**:
     - Transitions accurately through `never_synced` → `syncing` → `synced_success` / `synced_empty` / `sync_error`, and invokes `onPersistDocuments` on completion.
2. **Quality Gates**:
   - `npx tsc --noEmit` and `npm test` pass with zero errors.
