## 🎯 Purpose & Scope

Enforce the **1:1 Card-to-Subpage Deletion Lifecycle** (`13-PRD.md` Decision #5) so deleting any Page Link card atomically purges the card, its `PageNode` subtree, and all purged canvases (guaranteeing zero ghost/orphan pages), with strong Evaluative Ease friction against accidental subtree wipes:
1. Extend `CanvasDeleteConfirmModal.tsx` (which Epic 12 already upgraded to canonical `Modal` `footer` + `ModalActions`, `Button` `variant="danger"`, and `InlineAlert` `variant="warning"`) — reusing `InlineAlert` (`variant="error"`), `FormField`, and `Input` from `src/components/ui/`:
   - **Leaf subpage (0 nested subpages)**: Standard confirmation (`"Delete subpage \"<Title>\" and its contents?"`).
   - **Branch subpage (1+ nested subpages)**: Displays the **exact count** of nested subpages inside Epic 12's canonical `<InlineAlert variant="error">` (Evaluative Ease per `ux-psychology.md`, e.g., `"This will delete 3 nested subpages and all of their contents."` — singular `"1 nested subpage"` vs plural `"N nested subpages"`) and keeps the destructive `<Button variant="danger">` **disabled** (and blocks `Ctrl+Enter` `onConfirm`) until the editor types the exact confirmation phrase: **`DELETE ALL SUBPAGES`**.
2. On confirm: execute **one atomic `PUT /api/draft` transaction** that:
   - Removes the `PageLinkElement` from the parent canvas (and re-syncs remaining siblings' `order`),
   - Prunes the target `PageNode` and all descendant `PageNode`s from `draft.pages` via `cascadeDeleteSubtree`,
   - Sends `deletedPageIds: [targetPageId, ...descendantIds]` to purge all deleted subpages' keys from `draft.canvases`!
3. Capture all purged subpage canvases beforehand (fetching current `draft.canvases` via `getDraftWorkspace(lockToken)` before mutating!) so **one reversible workspace-level undo command** (`type: 'page_delete_subtree'`) restores the Page Link card, the **entire `PageNode` subtree**, and **every purged canvas** cleanly on `Cmd+Z`!

### Step-by-Step Implementation Blueprint

1. **Extend `CanvasDeleteConfirmModal.tsx` (lines 1–99) & `CanvasItemControls.tsx` (lines 9–25, 217–225)**
   - Export constant `BRANCH_DELETE_CONFIRM_PHRASE = 'DELETE ALL SUBPAGES'`.
   - Extend `CanvasDeleteConfirmModalProps` (line 8):
     ```ts
     /** Title of the target page when itemType === 'page-link' */
     targetPageTitle?: string;
     /** Exact count of nested descendant subpages (computed via pageTreeService.countDescendantPages) */
     descendantPageCount?: number;
     ```
   - Update `getItemTypeLabel` (line 16): add `case 'page-link': return { title: 'Delete Subpage', noun: 'subpage' };`.
   - Inside `CanvasDeleteConfirmModal`:
     - Manage `confirmInput` state (reset to `''` whenever `isOpen` changes).
     - `const requiresTypedConfirmation = (itemType === 'page-link' || (descendantPageCount ?? 0) > 0) && (descendantPageCount ?? 0) > 0;` *(covers both branch `page-link` cards AND sections/subsections containing `page-link` cards!)*.
     - `const isConfirmEnabled = !requiresTypedConfirmation || confirmInput.trim() === BRANCH_DELETE_CONFIRM_PHRASE;`
     - Pass `onConfirm={isConfirmEnabled ? onConfirm : undefined}` to `<Modal role="alertdialog" ...>` so pressing `Ctrl+Enter` CANNOT bypass the typed-phrase gate!
     - **Leaf subpage (`itemType === 'page-link' && (descendantPageCount ?? 0) === 0`)**:
       - Copy: `Delete subpage "${targetPageTitle || 'Untitled'}" and its contents?`
       - Calm reassurance caption: `"You can reverse this action with Undo during your active session."`
     - **Branch subpage (`(descendantPageCount ?? 0) > 0`)**:
       - Copy: `Delete subpage "${targetPageTitle || 'Untitled'}" and its nested subpages?` (or section/subsection equivalent when deleting a container with subpages).
       - Exact-count warning block using Epic 12's canonical **`<InlineAlert variant="error">`** (which already renders `--color-danger-tint`, `--color-danger-dark`, `--color-danger-border` with `role="alert"` — zero ad-hoc `.branchDangerBox` CSS needed!):
         `This will delete ${descendantPageCount} nested ${descendantPageCount === 1 ? 'subpage' : 'subpages'} and all of their contents.`
       - Canonical `<FormField id="confirm-branch-delete" label={\`Type \${BRANCH_DELETE_CONFIRM_PHRASE} to confirm\`} required>` wrapping canonical `<Input id="confirm-branch-delete" monospace value={confirmInput} onChange={(e) => setConfirmInput(e.target.value)} placeholder={BRANCH_DELETE_CONFIRM_PHRASE} autoComplete="off" />`.
     - Preserve Epic 12's canonical `Modal` `footer` slot with `<ModalActions>`:
       - `<Button variant="ghost" size="sm" onClick={onClose}>Cancel</Button>`
       - `<Button variant="danger" size="sm" disabled={!isConfirmEnabled} onClick={onConfirm}>Delete</Button>` (note: drop legacy `.modalDeleteButton` `!important` override so `<Button variant="danger" disabled>` renders canonical disabled danger tokens cleanly).
   - Extend `CanvasItemControlsProps` (lines 9–25) with optional `targetPageTitle?: string;` and `descendantPageCount?: number;` forwarded directly into `<CanvasDeleteConfirmModal />` (lines 217–225).

2. **Wire Atomic Cascade Delete & Full-Subtree Undo in `src/components/canvas/DocumentCanvas.tsx`**
   - On every `<CanvasItemControls>` wrapping a leaf where `leaf.type === 'page-link'`:
     - Compute `targetPage = portalChrome?.pages?.[leaf.targetPageId]`.
     - Pass `targetPageTitle={targetPage?.title}` and `descendantPageCount={targetPage ? countDescendantPages(portalChrome?.pages ?? {}, targetPage.id) : 0}`.
   - Inside `handleDeleteLeaf` (line 259):
     - **If `leaf.type === 'page-link'`**:
       - Handle both normal targets and broken/missing targets cleanly:
         - If `targetPage` does NOT exist in `pages` (broken dev-mode recovery card): simply call `removeItem(leaf.id, subsectionId || sectionId)` to clean up the card.
         - If `targetPage` exists:
           1. Capture `beforeParentCanvas = document` and `beforePages = portalChrome.pages`.
           2. Compute `{ pages: prunedPages, deletedIds } = cascadeDeleteSubtree(beforePages, targetPage.id)`.
           3. Read current `draftWorkspace = await getDraftWorkspace(lockToken)` to snapshot `purgedCanvases: Record<string, NodeCanvasDocument>` for every `id` in `deletedIds` (so Undo can restore 100% of every deleted subpage's sections/charts/photos!).
           4. Compute `nextParentCanvas = removeCanvasItem(beforeParentCanvas, leaf.id, subsectionId || sectionId)`.
           5. Re-sync remaining sibling order via `deriveSubpageOrderFromCanvas(prunedPages, nodeId, nextParentCanvas)` -> `finalPages`.
           6. Commit **one atomic `PUT /api/draft`** via `portalChrome.commitWorkspaceMutation({ canvases: { [nodeId]: nextParentCanvas }, pages: finalPages, deletedPageIds: deletedIds })`.
           7. Broadcast `EVENT_DRAFT_CANVAS_CHANGE` for `nodeId` so parent canvas removes the card immediately, and show Undo toast (`"Subpage deleted"`).
           8. Push **one workspace undo command** via `createWorkspaceUndoAction`:
              - `type: 'page_delete_subtree'`
              - `description: deletedIds.length > 1 ? \`Delete "${targetPage.title}" and ${deletedIds.length - 1} nested subpages\` : \`Delete subpage "${targetPage.title}"\``
              - `before: { canvases: { [nodeId]: beforeParentCanvas, ...purgedCanvases }, pages: beforePages }`
              - `after: { canvases: { [nodeId]: nextParentCanvas }, pages: finalPages, deletedPageIds: deletedIds }`
           9. Verify: If the editor later navigates into one of the restored subpages and presses `Cmd+Shift+Z` (Redo delete), `EVENT_WORKSPACE_UNDO_RECONCILE` from `13.9` sees `deletedPageIds` contains `activePageId` and automatically navigates the editor cleanly up to the parent page!

3. **Edge Case: Deleting a Section or Subsection that Contains `PageLinkElement` Cards**
   - Audit `handleDeleteSection` and `handleDeleteSubsection` in `DocumentCanvas.tsx`!
   - If a Section or Subsection being deleted contains one or more `PageLinkElement` cards, collect all referenced `targetPageId`s inside it; if any exist, compute total affected pages (cards + their descendants), require the same typed confirmation phrase (`DELETE ALL SUBPAGES`) in `CanvasDeleteConfirmModal`, and include all of their `deletedIds` in `deletedPageIds` + `cascadeDeleteSubtree` so deleting a Section can **NEVER** create ghost/orphan subpages!

## 🛡️ Architectural & UI/UX Guardrails

- **Evaluative Ease (`ux-psychology.md`)**: Always display the **exact integer count** of nested subpages (`1 nested subpage` / `N nested subpages`) — never vague ranges like `"several subpages"`.
- **Zero Orphan Guarantee**: Neither deleting a Page Link card NOR deleting a Section/Subsection containing Page Link cards may ever leave an unreachable `PageNode` in `draft.pages` or orphaned canvas in `draft.canvases`.
- **Canonical UI Enforcement**: Zero raw `<input>` or `<button>` in `CanvasDeleteConfirmModal.tsx`; consume `Modal` (`footer`), `ModalActions`, `InlineAlert` (`variant="error"`), `Button` (`variant="danger"`), `FormField`, and `Input` from `src/components/ui/` (`tests/canonical-ui-enforcement.test.ts` passes).
- **Ctrl+Enter Safety**: When typed confirmation is required, `Ctrl+Enter` MUST NOT bypass the disabled Delete button.
