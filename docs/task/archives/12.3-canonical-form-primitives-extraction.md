## 🎯 Purpose & Scope

Eliminate the root cause of **89** raw `<input>`/`<textarea>`/`<select>` elements and **17+** ad-hoc checkboxes by establishing Folio Engine's canonical form primitive suite in `src/components/ui/`:
- `FormField` — label (+ optional required indicator, `DevHelpTooltip`, right-aligned `labelAction` slot), control slot, hint text, and error message with automatic `aria-describedby` wiring.
- `Input` — token-styled native text/url/number input with `invalid` / `valid` states and forwarded `ref`.
- `Textarea` — token-styled native textarea with `invalid` state and forwarded `ref`.
- `Select` — token-styled native select with consistent chevron/padding and `invalid` state.
- `Checkbox` — generalized from `ValueLabelToggle.tsx` (label, optional `hint`, optional `tooltip`, disabled state); `ValueLabelToggle` becomes a thin deprecated alias or delegates directly to `Checkbox`.
- `SegmentedControl<T extends string>` — accessible `role="radiogroup"` + `role="radio"` + `aria-checked` control unifying `CanvasAddModal` and `UniversalEditModal`.

## 🏛️ Karpathy & Superpowers Discipline

1. **Design System Token Gate First**:
   - Audit `src/styles/tokens.css` for form surface, border, focus, invalid, valid, placeholder, and disabled tokens; add any missing semantic tokens before scaffolding CSS modules.
2. **TDD First**:
   - Write `tests/components/ui-form-primitives.test.tsx` first verifying:
     - `FormField` links `<label htmlFor>` and hint/error IDs cleanly.
     - `Input`, `Textarea`, `Select` forward refs, set `aria-invalid`, and honor `disabled`.
     - `Checkbox` toggles `checked` via label click and keyboard Space.
     - `SegmentedControl` updates `aria-checked` and invokes `onChange` cleanly.
3. **Minimal, Composable APIs**:
   - Keep each primitive single-purpose with scoped `[Component].module.css`, full 4-state interactive matrix, and `outline: none` (Universal Zero Outline Policy).
4. **Verify Everything**:
   - Run `npm run test:tokens`, `npx tsc --noEmit`, and `npm test`.
