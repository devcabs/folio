## 🛡️ Architectural & UI/UX Guardrails

- **Token Purity (`design-system-first.md`)**: Every color, shadow, radius, spacing, and transition in Epic 13 CSS modules MUST consume `var(--...)` from `src/styles/tokens.css`. Zero raw hex/rgb/rgba/hsl/hsla values in any `*.module.css` (enforced statically by `tests/canonical-ui-enforcement.test.ts`).
- **Universal Zero Outline Policy (`ui-standards.md`)**: All focus/active selectors MUST declare `outline: none; outline: 0;` and communicate focus strictly via calm surface/border/typography contrast shifts.
- **4-State Interactive Matrix**: Every interactive primitive (`Input`, `Button[variant="danger"]`, `IconButton`) MUST style Default, Hover, Active/Pressed, Focus-Visible, and Disabled states.
- **Zero Glass-on-Glass**: `--nav-dropdown-bg` MUST resolve to solid `var(--folio-bg-surface)` (`#ffffff`), never `--bg-surface-glass`.
