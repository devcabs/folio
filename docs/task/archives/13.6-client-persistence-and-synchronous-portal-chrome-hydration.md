## 🎯 Purpose & Scope

Connect the browser client layer to the dynamic `pages` tree and Edge-injected `window.__FOLIO_MANIFEST__`:
1. Extend `src/services/draftService.ts` and `src/services/historyService.ts` so atomic workspace saves support `pages` + `deletedPageIds`, and publishing bundles `draftWorkspace.pages` + subpage metrics.
2. Extend `src/utils/contentDb.ts` with helpers to read Edge-injected `window.__FOLIO_MANIFEST__` synchronously and return both `contentOverrides` and `pages` from `GET /api/public/manifest` and `GET /api/draft`.
3. Upgrade `src/context/PortalChromeContext.tsx` so Public Mode hydrates `pages` and `contentOverrides` **synchronously at 0ms** when `window.__FOLIO_MANIFEST__` is present (falling back cleanly to `GET /api/public/manifest` in local dev), Dev Mode hydrates `pages` from `GET /api/draft`, and exposes reactive `pages` + serialized `mutateWorkspacePages` / `saveWorkspaceTransaction` helpers synchronized on `EVENT_DRAFT_CONTENT_CHANGE` and `EVENT_LIVE_CONTENT_CHANGE`.

### Step-by-Step Implementation Blueprint

1. **Extend `src/services/draftService.ts`**
   - Update `saveDraftWorkspace` (line 236) signature to accept `workspace: Partial<DraftWorkspacePayload> & { deletedPageIds?: string[] }`:
     - Forward `pages` and `deletedPageIds` in the `PUT /api/draft` JSON body alongside `canvases`, `contentOverrides`, `expectedRevision`, `expectedUpdatedAt`.
     - After a successful `PUT /api/draft`, call `dispatchDraftUpdatedAtSync(updated.updatedAt)` so all mounted surfaces (`PortalChromeContext`, `useDocumentCanvas`) stay in lockstep on `expectedUpdatedAt`.
   - Export `EVENT_DRAFT_PAGES_CHANGE = 'engine-draft-pages-change'` (or dispatch detail `{ pages: updated.pages }` on `EVENT_DRAFT_CONTENT_CHANGE` AND `dispatchDraftPagesSync(pages: PageRegistry)`) so `PortalChromeContext` can update `pages` reactively without an extra `GET /api/draft` round-trip when local mutations commit!
   - Export a clean serialized workspace transaction helper `commitDraftWorkspaceTransaction(payload: { canvases?: Record<string, NodeCanvasDocument>; pages?: PageRegistry; contentOverrides?: Record<string, string>; deletedPageIds?: string[] }, options: { lockToken?: string | null; expectedUpdatedAt?: string | null }): Promise<DraftWorkspacePayload>` wrapped inside `enqueueDraftMutation(...)` that calls `saveDraftWorkspace`, dispatches `EVENT_DRAFT_CANVAS_CHANGE` for each updated canvas (and `EVENT_DRAFT_UPDATED_AT_SYNC`), and returns the authoritative KV `DraftWorkspacePayload`.

2. **Extend `src/services/historyService.ts`**
   - Update `computeMetricsSummary(canvases, _legacyContentOverrides?, pages?)` (line 36):
     - Count `totalPageLinkElements` when encountering `leaf.type === 'page-link'`.
     - Set `totalSubpages: pages ? Object.keys(pages).length : 0`.
   - Update `publishNewSnapshot` (line 220):
     - Read `const pages = draftWorkspace.pages || {};` from `getDraftWorkspace(lockToken)` (line 244).
     - Pass `pages` into `computeMetricsSummary(canvases, contentOverrides, pages)` and attach `pages` onto the `PublishedSnapshot` payload sent to `POST /api/publish` (line 262).
   - Confirm `restoreSnapshotToDraft` (line 187) triggers `dispatchDraftChange` + `dispatchAggregateCanvasChange` so `PortalChromeContext` re-hydrates restored `pages` immediately.

3. **Extend `src/utils/contentDb.ts`**
   - Export `readInjectedPortalManifest(): PublicPortalManifestPayload | null`:
     - SSR-safe (`typeof window !== 'undefined'`). Checks `window.__FOLIO_MANIFEST__`; validates basic shape (`activeSnapshotId` string & `nodeIds` array) and returns a safe copy or `null`.
   - Export `fetchPublicManifestChrome(): Promise<{ contentOverrides: Record<string, string>; pages: PageRegistry }>`:
     - Calls `GET /api/public/manifest` with `assertJsonContentType`, returning `{ contentOverrides: manifest.contentOverrides ? { ...manifest.contentOverrides } : {}, pages: manifest.pages ? { ...manifest.pages } : {} }`.
     - Keep `fetchPublicManifestOverrides()` delegating to it for 100% backward compatibility.
   - Export `fetchDraftWorkspaceChrome(lockToken?: string | null): Promise<{ contentOverrides: Record<string, string>; pages: PageRegistry; canvases: Record<string, NodeCanvasDocument>; updatedAt: string | null }>`:
     - Calls `GET /api/draft` with Bearer `lockToken` and `assertJsonContentType`, returning `contentOverrides`, `pages`, `canvases`, and `updatedAt`.
     - Keep `fetchDraftWorkspaceOverrides()` delegating to it for 100% backward compatibility.

4. **Upgrade `src/context/PortalChromeContext.tsx`**
   - Extend `PortalChromeContextValue` (line 32) with:
     - `pages: PageRegistry;` (authoritative active page registry: published `portal:manifest.pages` in Public Mode, `draft:workspace.pages` in Dev Mode)
     - `publishedPages: PageRegistry;` (the last known published `pages` map from `window.__FOLIO_MANIFEST__` or public manifest fetch — used by `13.7` Dev Mode exit guard to know whether the active subpage is published or draft-only!)
     - `commitWorkspaceMutation: (mutation: { canvases?: Record<string, NodeCanvasDocument>; pages?: PageRegistry; contentOverrides?: Record<string, string>; deletedPageIds?: string[] }) => Promise<DraftWorkspacePayload>;` (serialized through `enqueueDraftMutation`, automatically attaching `lockToken` and latest `draftUpdatedAtRef.current`, updating `pages`, `contentOverrides`, and `draftUpdatedAtRef.current` in React state on commit).
   - **Zero-Wait Synchronous Initial State (Public Mode)**:
     - On mount when `!isDevMode`: invoke `readInjectedPortalManifest()` inside lazy `useState` initializers!
     - If injected manifest is present:
       - Initialize `contentOverrides` from `injected.contentOverrides || {}`
       - Initialize `pages` and `publishedPages` from `injected.pages || {}`
       - Initialize `hasHydrated = true` and `isHydrating = false` immediately on first render (**0ms boot, zero wireframe flash!**).
       - Skip the redundant initial `GET /api/public/manifest` fetch unless `retryCount > 0` or `EVENT_LIVE_CONTENT_CHANGE` fires (or `isDevMode` toggles to `true`).
     - If injected manifest is absent (local Vite dev / tests without Edge worker): preserve exact existing async hydration (`isHydrating = true`, `hasHydrated = false`) calling `fetchPublicManifestChrome()`.
   - **Dev Mode Hydration**:
     - When `isDevMode` becomes `true`, call `fetchDraftWorkspaceChrome(lockToken)`, updating `contentOverrides`, `pages`, and `draftUpdatedAt`.
     - Listen for `EVENT_DRAFT_CONTENT_CHANGE` / `EVENT_DRAFT_PAGES_CHANGE` (if detail carries `{ pages }`, apply synchronously to avoid unnecessary refetch flicker; otherwise `retry()`).

## 🛡️ Architectural & UI/UX Guardrails

- **Zero Browser Storage Pollution**: Never read or write `localStorage`, `sessionStorage`, or `indexedDB` for `pages` or `window.__FOLIO_MANIFEST__`.
- **Fail-Stop KV Concurrency**: Every `commitWorkspaceMutation` call MUST run inside `enqueueDraftMutation` with `expectedUpdatedAt` so rapid page creates/renames/edits never race into HTTP `409`.
- **No Unnecessary Re-fetches on 0ms Boot**: When `window.__FOLIO_MANIFEST__` satisfies initial Public Mode boot, do not flash `HeroWelcomeGhostWireframe` or double-fetch `/api/public/manifest`.
