## 🎯 Purpose & Scope

Deliver calm, uncluttered in-page reader orientation at arbitrary nesting depth across three cohesive surfaces:
1. **Collapsed Deep `Breadcrumb` (`src/components/ui/Breadcrumb.tsx`)**: When `items.length > 4` (configurable `maxItems = 4`), collapse middle ancestor segments into a **purely visual, non-interactive `…` ellipsis** (`<span>`, non-clickable, zero popover, zero dropdown) showing `First / Second / … / Parent / Current` (e.g., `Overview / Chapter 1 / … / Research / 2026 Notes`).
2. **Contextual `EditorialSidebar` Sticky Back-Link (`src/components/layout/EditorialSidebar.tsx`)**: Keep `EditorialSidebar` **100% dedicated to the current page's Sections & Subsections** (never a nested page tree), while replacing its hardcoded `"Roadmap"` sticky top back button (lines 146–167) with a dynamic `backLabel` prop (`< <Parent Page Title>` on subpages stepping up 1 level; `< Roadmap` on root chapters), clean ellipsis truncation for long parent titles, and canonical `<Button variant="ghost">` compliance.
3. **Subpage Shell Rendering in `src/App.tsx`**: Wire `route === 'hydrating'` (calm `<CanvasGhostWireframe />` without flashing 404), resolve either a root `NodeItem` OR a dynamic `PageNode` on `isNodeRoute`, inherit `accentColor` from the root chapter, build the full ancestor trail for `<Breadcrumb>`, pass parent `backLabel` + `onBack` to `<EditorialSidebar>`, and pass `activePageId` into `<DocumentCanvas>`.

### Step-by-Step Implementation Blueprint

1. **Extend Canonical `src/components/ui/Breadcrumb.tsx` & `Breadcrumb.module.css`**
   - Add optional `maxItems?: number` (default `4`) to `BreadcrumbProps` (line 14).
   - Collapse algorithm (pure helper `collapseBreadcrumbItems(items, maxItems)`):
     - If `items.length <= maxItems` (default `<= 4`), render all items unchanged.
     - If `items.length > maxItems` (e.g., 5+ items `[Overview, Chapter 1, Level 2, Level 3, Current]`):
       - Keep the first 2 items (`items[0]`, `items[1]` — e.g. `Overview`, `Chapter 1`), insert one synthetic non-interactive ellipsis entry `{ isEllipsis: true }`, and keep the last 2 items (`items[items.length - 2]`, `items[items.length - 1]` — Parent and Current Page).
       - Result for 5+ items: `Overview / Chapter 1 / … / Parent / Current Page`.
   - Render the ellipsis entry strictly as a non-interactive `<span className={styles.ellipsis} aria-hidden="true">…</span>` inside `<li className={styles.item}>` (with separator before it). **MUST NOT** be a `<button>`, `<a>`, or have `onClick` / `tabIndex` / popover!
   - Style `.ellipsis` in `Breadcrumb.module.css` using `color: var(--breadcrumb-ellipsis-color); user-select: none; cursor: default; padding: 0 var(--space-1);` (zero hardcoded colors).
   - Ensure visible ancestor links/buttons preserve 4-state matrix and Universal Zero Outline Policy (`outline: none;`).

2. **Extend `src/components/layout/EditorialSidebar.tsx` & `EditorialSidebar.module.css`**
   - Add `backLabel?: string` (defaults to `'Roadmap'`) to `EditorialSidebarProps` (line 6).
   - Update sticky back button (lines 146–167):
     - Migrate the raw `<button className={styles.breadcrumbBackBtn}>` to canonical `<Button variant="ghost" size="xs" className={styles.breadcrumbBackBtn} ...>` from `../ui/Button`.
     - Remove `'src/components/layout/EditorialSidebar.tsx': new Set(['button'])` from `RAW_CONTROL_EXEMPTIONS` in `tests/canonical-ui-enforcement.test.ts` (line 53) so the Epic 12 static guardrail enforces zero raw buttons in `EditorialSidebar.tsx`.
     - Set `aria-label={`Return to ${backLabel}`}` and `title={`Return to ${backLabel}`}` (for long truncated parent titles).
     - Render `<span className={styles.backLabelText}>{backLabel}</span>` with `overflow: hidden; text-overflow: ellipsis; white-space: nowrap; max-width: 100%;` in `EditorialSidebar.module.css` so long parent page titles never wrap awkwardly or overflow the sidebar column.
   - Verify `EditorialSidebar` renders **only** `items` (current page's Sections & Subsections from `useAutoTableOfContents`) — zero nested page tree UI.

3. **Wire Subpage Shell & Hydrating State in `src/App.tsx`**
   - Pass `pages: portalChrome?.pages`, `publishedPages: portalChrome?.publishedPages`, `isHydrating: portalChrome?.isHydrating`, `isDevMode`, and `onDraftExitRedirect` into `useHashRoute(...)` (line 45).
   - Resolve active view target:
     - `activeRootNode = rootNodeId ? nodes.find((n) => n.id === rootNodeId) : null`
     - `isSubpage = Boolean(pageNode)`
     - `effectivePageId = activePageId || activeRootNode?.id || null`
     - `effectiveAccentColor = activeRootNode?.accentColor` (root chapter `accentColor` inherited at all depths!)
     - `effectivePageTitle = pageNode ? pageNode.title : resolvedNodeTitle`
   - **Hydrating Route Guard**: When `route === 'hydrating'`, render the node layout shell with `<CanvasGhostWireframe nodeId={rootNodeId || 'hydrating'} />` (and `<AppHeader />` + `<AppFooter />`) — never flash `<PageNotFound />` while `portalChrome.isHydrating` is true!
   - **Dynamic Breadcrumb Trail (lines 252–258)**:
     - On root chapters: `[Overview, Milestones (scrolls to stage), <Root Chapter Title (current)>]` (3 items — preserves existing behavior).
     - On subpages (2+ levels): `[Overview, ...ancestors.map((a, idx) => ({ id: a.id, label: a.isRootChapter ? resolvedNodeTitle : a.title, isCurrent: idx === ancestors.length - 1, onClick: idx < ancestors.length - 1 ? () => navigateToPage(a.id) : undefined }))]`.
       - Level 2 subpage -> 3 items (`Overview / Chapter 1 / Research`).
       - Level 3 subpage -> 4 items (`Overview / Chapter 1 / Research / Interviews`).
       - Level 4+ subpage -> 5+ items -> automatically collapsed by `Breadcrumb` to `Overview / Chapter 1 / … / Interviews / 2026 Notes`!
   - **Contextual `EditorialSidebar` Props (lines 264–271)**:
     - Compute `parentAncestor = ancestors.length >= 2 ? ancestors[ancestors.length - 2] : null`.
     - If `isSubpage && parentAncestor`:
       - `backLabel = parentAncestor.isRootChapter ? resolvedNodeTitle : parentAncestor.title`
       - `onBack = () => navigateToPage(parentAncestor.id)`
     - Else (root chapter):
       - `backLabel = 'Roadmap'`
       - `onBack = handleBackFromNode`
   - **DocumentCanvas Binding (lines 290–294)**:
     - Pass `nodeId={effectivePageId}`, `nodeTitle={effectivePageTitle}`, `accentColor={effectiveAccentColor}`, and `onNavigateToPage={navigateToPage}` (prepared for `13.12`).

- **Sidebar Restraint**: `EditorialSidebar` MUST remain 100% current-page Sections & Subsections; never render child pages in the sidebar.
- **Canonical UI & Token Purity**: `EditorialSidebar` back control uses canonical `<Button>` (and is pruned from `RAW_CONTROL_EXEMPTIONS` in `tests/canonical-ui-enforcement.test.ts`); `Breadcrumb.module.css` and `EditorialSidebar.module.css` use only `src/styles/tokens.css` variables and enforce `outline: none;`.
