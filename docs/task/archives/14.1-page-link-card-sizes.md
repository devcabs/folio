### `sm` — Small Compact Card

- Vertical layout: top thumbnail → title → summary → `Read →` cue.
- Thumbnail height: `calc(var(--space-4) * 14)` ≈ `112px` (token-backed; `var(--space-4)` = `16px`).
- Title: `var(--font-sans)`, `var(--text-body)`, `font-weight: 600`, max 2 lines (`-webkit-line-clamp: 2`).
- Summary: `var(--text-caption)`, `var(--color-text-muted)`, max 2 lines clamped.
- Trailing cue: `Read →`, `var(--text-caption)`, `var(--color-primary)`.
- Mobile: single column (the grid wrapper handles column count — see Phase 4).
- **CSS class:** `.cardSm` on the root card div.

### `md` — Medium (unchanged)

**DO NOT MODIFY.** Existing JSX, CSS, and tests remain exactly as-is.

### `lg` — Large Cinematic Hero

- Vertical layout: huge top cover → title → summary → "Explore →" CTA button.
- Cover height: `clamp(calc(var(--space-4) * 16), 25vw, calc(var(--space-4) * 20))` ≈ `256px–320px`.
  - `var(--space-4)` = `16px` → `16 * 16 = 256px` min, `16 * 20 = 320px` max.
- Title: `var(--font-display)`, `clamp(1.5rem, 3vw, 2.25rem)`, `font-weight: 700`, max 3 lines clamped.
- Summary: `var(--font-body)`, `var(--text-body)`, `var(--color-text-secondary)`, max 4 lines clamped.
- CTA: canonical `<Button variant="primary">Explore →</Button>` from `src/components/ui/Button.tsx`.
  - Navigates to the page (same behavior as the `md` card click). Wire `onClick` from parent or use `<a>` via `Button as="a" href={...}`.
- **CSS class:** `.cardLg` on the root card div.

## Phase 4 — Grid Clustering in `DocumentCanvas.tsx`

**Files touched:** `src/components/canvas/DocumentCanvas.tsx`, `src/components/canvas/CanvasControls.module.css` (or a new `CanvasPageLinkGrid.module.css`)

### Clustering algorithm

In the `validElements.map()` render loop, detect runs of consecutive `page-link` elements where `element.cardSize === 'sm'` and wrap each run in a `<div className={styles.pageLinkGrid}>`.

```tsx
// Pseudo-code for the clustering loop
const clusters: Array<{ type: 'single'; el: CanvasElement } | { type: 'sm-grid'; els: PageLinkElement[] }> = [];

let i = 0;
while (i < validElements.length) {
  const el = validElements[i];
  if (el.type === 'page-link' && (el as PageLinkElement).cardSize === 'sm') {
    // Collect consecutive sm page-links
    const run: PageLinkElement[] = [];
    while (
      i < validElements.length &&
      validElements[i].type === 'page-link' &&
      (validElements[i] as PageLinkElement).cardSize === 'sm'
    ) {
      run.push(validElements[i] as PageLinkElement);
      i++;
    }
    clusters.push({ type: 'sm-grid', els: run });
  } else {
    clusters.push({ type: 'single', el });
    i++;
  }
}

// Render clusters
return clusters.map((cluster) => {
  if (cluster.type === 'sm-grid') {
    return (
      <div key={cluster.els.map(e => e.id).join('-')} className={styles.pageLinkGrid}>
        {cluster.els.map((el) => (
          <CanvasItemControls key={el.id} element={el} isDevMode={isDevMode} onEdit={...} onDelete={...}>
            <CanvasPageLink element={el} page={getPage(el.targetPageId)} isDevMode={isDevMode} />
          </CanvasItemControls>
        ))}
      </div>
    );
  }
  // existing single-element render path
  return renderSingleElement(cluster.el);
});
```

> **Implementation note:** A single `sm` card (not adjacent to another `sm` card) still gets wrapped in `.pageLinkGrid` — it renders as a 1-column single card, visually identical to if no grid existed. No special-casing needed.
