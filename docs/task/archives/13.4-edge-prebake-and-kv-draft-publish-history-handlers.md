## 🎯 Purpose & Scope

Wire the dynamic `pages: Record<string, PageNode>` registry and `deletedPageIds` atomic canvas purge through Folio Engine's entire Cloudflare Edge KV persistence, pre-baking, two-phase publishing, and snapshot rollback pipeline—strictly inside `src/services/edgePreBakeService.ts` and `src/edge/handlers/*` (zero consumer route duplication).

### Step-by-Step Implementation Blueprint

1. **Update `src/services/edgePreBakeService.ts`**
   - **`transformLeafElement` (line 157)**: explicitly preserve `PageLinkElement` (`if (isPageLinkElement(leaf)) return leaf;`) cleanly through `transformCanvasAst` without stripping `targetPageId`.
   - **`compilePortalManifest` (line 244)**:
     - Include `pages: snapshot.pages ? JSON.parse(JSON.stringify(snapshot.pages)) : {}` in the compiled `PublicPortalManifestPayload`.
     - Ensure `activeNodeIds` encompasses all keys present in `snapshot.canvases` (both root chapter IDs and dynamic `page-*` subpage IDs) so downstream baseline hydration knows every active canvas.
     - Validate via `PublicPortalManifestPayloadSchema.parse(manifest)`.
   - **`compilePublicNodePayload` (line 216)**: verify it compiles any dynamic `page-*` ID stored in `snapshot.canvases[pageId]` and passes `PublicNodePayloadSchema.parse(payload)` when `canvas` contains `PageLinkElement` blocks.

2. **Update `src/edge/handlers/draftHandler.ts`**
   - **`buildBaselineDraftWorkspace` (line 101)**:
     - When `manifest !== null`:
       - Resolve `livePages = manifest.pages && Object.keys(manifest.pages).length > 0 ? JSON.parse(JSON.stringify(manifest.pages)) : (activeSnapshot?.pages ? JSON.parse(JSON.stringify(activeSnapshot.pages)) : {})`.
       - Collect `pageIds = Object.keys(livePages)`.
       - Build `targetNodeIds = Array.from(new Set([...manifestNodeIds, ...requestedNodeIds, ...pageIds]))` so **all published subpage canvases** are hydrated into `draft.canvases` alongside root chapters.
       - For any `pageId` in `livePages` that is also in `manifestNodeIds`, keep fail-stop HTTP 502 if its KV node key is missing; if missing only from `requestedNodeIds` (newly added chapter), initialize with `createDefaultCanvasDocument(nodeId)`.
       - Return `pages: livePages` on the baseline `DraftWorkspacePayload`.
     - When `manifest === null && historyIndex === null` (cold boot): include `pages: {}` on the returned `DraftWorkspacePayload`.
   - **`handlePutDraft` (line 253)**:
     - Accept optional `pages?: unknown` and `deletedPageIds?: unknown` in request JSON body.
     - Validate `pages` if provided: if present, validate with `PageRegistrySchema.safeParse(body.pages)` — return HTTP `400` with descriptive error if invalid!
     - Validate `deletedPageIds` if provided: must be an array of non-empty strings (return HTTP `400` otherwise).
     - Merge/replace logic under optimistic concurrency (`expectedUpdatedAt` / `expectedRevision`, preserving HTTP `409` conflict response with `latestWorkspace`):
       - Start with `mergedCanvases = body.canvases ? { ...existing.canvases, ...(body.canvases as Record<string, NodeCanvasDocument>) } : { ...existing.canvases }`.
       - Start with `nextPages = body.pages ? { ...(body.pages as Record<string, PageNode>) } : { ...(existing.pages || {}) }` *(full map replacement when `body.pages` is supplied, matching `contentOverrides` semantics so deletions/renames are authoritative)*.
       - **Atomic `deletedPageIds` purge**: for each `delId` in `deletedPageIds`:
         - `delete mergedCanvases[delId];`
         - `delete nextPages[delId];`
       - Persist updated `DraftWorkspacePayload` (including `pages: nextPages`) to `KV_DRAFT_WORKSPACE_KEY` (`draft:workspace`) and return HTTP `200`.

3. **Update `src/edge/handlers/publishHandler.ts`**
   - **Phase A (lines 120–136)**:
     - Validate `snapshot.pages` if provided using `PageRegistrySchema.safeParse` (return HTTP `400` if malformed).
     - `targetNodes = Array.from(new Set([...Object.keys(snapshot.canvases), ...Object.keys(snapshot.pages || {})]))` — ensure every `pageId` in `snapshot.pages` has a canvas (defaulting safely or requiring presence in `snapshot.canvases`) and stage both `node:${snapshot.id}:${nodeId}` and `node:${nodeId}` for every root chapter AND every dynamic subpage.
     - Persist full `snapshot` (including `pages: snapshot.pages || {}`) to `history:snapshot:${snapshot.id}`.
   - **Phase B (lines 140–179)**:
     - Compile `manifestPayload = compilePortalManifest(snapshot, targetNodes)` (which includes `pages`) and write `portal:manifest`.
     - Reset `draft:workspace` anchored to the newly published snapshot, including `pages: JSON.parse(JSON.stringify(snapshot.pages || {}))`.

4. **Update `src/edge/handlers/historyHandler.ts`**
   - **`GET /api/history` fallback entry (line 73)**: include `pages: {}` on fallback stub snapshots.
   - **`POST /api/history/restore` (line 136)**:
     - When `snapshotId === SYSTEM_BASELINE_SNAPSHOT_ID`:
       - Only reset root chapter IDs (if `body.nodeIds` provided, use those; else filter out `page-*` dynamic keys or fall back to `VALID_NODES`).
       - Set `pages: {}` on `restoredWorkspace` so baseline reset cleanly removes dynamic subpages.
     - When restoring a named `PublishedSnapshot`:
       - Deep-clone `pages: JSON.parse(JSON.stringify(snapshot.pages || {}))` onto `restoredWorkspace` alongside `clonedCanvases` and `clonedOverrides`.

5. **Verify `src/edge/handlers/publicHandler.ts`**
   - Confirm `NODE_ID_REGEX = /^[a-z0-9_-]{1,64}$/` (line 14) accepts `page-<ts>-<rand>` IDs.
   - Confirm lines 122–136 return HTTP `404` for a deleted subpage `page-old` after a new snapshot `snap-2` is published (because `node:snap-2:page-old` does not exist and legacy `node:page-old` has `snapshotId === 'snap-1' !== 'snap-2'`). Add explicit test coverage proving this!

## 🛡️ Architectural & UI/UX Guardrails

- **Zero Split-Brain Two-Phase Publish**: Always write `history:snapshot:*` and all `node:${id}:*` / `node:*` keys (Phase A) *before* flipping `portal:manifest` and `history:index` (Phase B).
- **Zero-Leak Security**: `transformCanvasAst` MUST continue stripping `ChartElement.config.sheetUrl` on subpage canvases identically to root chapter canvases.
- **No Unauthenticated Writes**: Every mutation in `draftHandler`, `publishHandler`, and `historyHandler` (`/restore`) MUST continue enforcing `verifyLockToken(request, kv)`.
- **Zero Consumer Duplication**: All logic lives inside `src/edge/` and `src/services/edgePreBakeService.ts`.
