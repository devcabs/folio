## 🎯 Purpose & Scope

Ensure that dynamically authored charts, linked evidence sources, and portal chrome text overrides actually reach public visitors with zero storage pollution:
1. **Bundle Charts & Sources into `PublishedSnapshot`:** Include active chart configurations (`chartSourceService.ts`) and linked source folder metadata (`sourceService.ts`) in the published snapshot.
2. **Pre-bake Dynamic Data into Public Node Payloads:** Ensure `compilePublicNodePayload` consumes `snapshot.chartConfigs` (compiling `SheetChartConfig` into typed `ChartDataset` via `parseTabularDataset`) and `snapshot.sourceMetadata` so that `nodePayload` contains live authored data rather than ancient static mock JSON.
3. **Portal Chrome Edge Pre-Bake & In-Memory Hydration:** Pre-bake `contentOverrides` into `portal:manifest` at `/api/public/manifest`. In public mode, hydrate into memory directly using `setLiveContentOverrides(overrides, { memoryOnly: true })` in `contentDb.ts` (0 `localStorage` writes) and render `HeroWelcomeGhostWireframe` while the manifest is fetching to eliminate Cumulative Layout Shift (CLS).

---

## 🔍 Problem Statement

1. **The Stranded Chart Problem:** When an author syncs a Google Sheet or edits chart titles, `saveChartConfigDetailed()` saves to Supabase `chart_sources` and local storage. But when clicking "Publish", `publishNewSnapshot()` packages only `canvases` and `contentOverrides`. `compilePublicNodePayload()` falls back to compiling static compile-time baseline charts (`data/baked-charts.json`). Public visitors never see the authored charts.
2. **The Stranded Evidence Source Problem:** When an author links Google Drive evidence folders, updates are saved to `sourceService.ts` and `_evidence_cache_v2`. But `publishNewSnapshot()` omits source registries, causing `gatherSourceMetadata()` on the edge to fall back to static `data/source-sources.json`.
3. **The Stranded Portal Chrome Problem:** `snapshot.contentOverrides` is not included in `compilePortalManifest()`. Furthermore, no public visitor hook fetches `/api/public/manifest`. Public visitors either see the hardcoded factory title (`"Autonomous *Multi-Stage* Sequence Platform"`) or experience jarring layout shifts.
4. **The Public Storage Pollution Problem:** Existing `contentDb.ts` writers mutate `localStorage` unconditionally, risking `QuotaExceededError` in private browsing or iOS Safari private tabs for read-only public visitors.

## 🏛️ Karpathy Heuristics & Rules

1. **Think Before Coding:**
   - A snapshot must be a complete self-contained package of the portal state: canvases, content overrides, chart configs, and source metadata.
   - Public node payloads should already bundle their charts and evidence metadata so public clients don't need to fire multiple separate network requests for individual charts or PostgREST tables.
   - Public visitors are read-only readers: they must never execute `localStorage.setItem()`.
2. **Make Surgical Changes:**
   - Extend `PublishedSnapshot` and `UnifiedPortalSnapshot` contracts in `src/types/history.ts`.
   - Update `publishNewSnapshot()` in `src/services/historyService.ts` to collect active chart configs and sources.
   - Update `compilePublicNodePayload` in `src/services/edgePreBakeService.ts` to transform `SheetChartConfig` into `ChartDataset` via `parseTabularDataset` and bundle `sourceMetadata`.
   - Update `compilePortalManifest` in `src/services/edgePreBakeService.ts` to include `snapshot.contentOverrides`.
   - Extend `setLiveContentOverrides` in `src/utils/contentDb.ts` to support `{ memoryOnly?: boolean }`.
   - Create `src/hooks/usePortalChromeHydration.ts` to fetch `/api/public/manifest` and warm `contentDb` in memory only.
   - Create `src/components/layout/HeroWelcomeGhostWireframe.tsx` to gate rendering in `HeroWelcome.tsx` with 0 CLS.

### Step 3: Pre-Bake Dynamic Charts & Sources into Public Node Payload

```ts
// In src/services/edgePreBakeService.ts:
import { parseTabularDataset } from './sheetsDataService';

export function compilePublicNodePayload(
  nodeId: string,
  snapshot: PublishedSnapshot,
  options?: PreBakeCompileOptions
): PublicNodePayload {
  const rawCanvas = snapshot.canvases?.[nodeId] || {
    nodeId,
    version: snapshot.schemaVersion || 1,
    sections: [],
    updatedAt: snapshot.createdAt,
  };

  const transformedCanvas = transformCanvasAst(rawCanvas);

  // Compile dynamic chart datasets from snapshot.chartConfigs
  const dynamicCharts: Record<string, CachedIndicatorDataset> = {};
  if (snapshot.chartConfigs) {
    for (const [chartId, cfg] of Object.entries(snapshot.chartConfigs)) {
      if (!cfg.nodeId || cfg.nodeId.toLowerCase() === nodeId.toLowerCase()) {
        if (cfg.cachedDataset && cfg.cachedDataset.length > 0) {
          dynamicCharts[chartId] = parseTabularDataset({
            chartId,
            title: cfg.titleOverride || '',
            subtitle: cfg.subtitleOverride,
            unit: cfg.unitOverride,
            chartType: cfg.defaultType,
            nodeId: cfg.nodeId,
            visualConfig: cfg.visualConfig,
            rawMatrix: cfg.cachedDataset.map(row => 
              Array.isArray(row) ? row.map(c => c === null || c === undefined ? '' : String(c)) : []
            ),
          });
        }
      }
    }
  }

  const chartDatasets = gatherIndicatorDatasets(nodeId, {
    ...dynamicCharts,
    ...(options?.chartDatasets || {}),
  });

  const sourceMetadata = gatherSourceMetadata(
    nodeId,
    snapshot.sourceMetadata || options?.sourceMetadata
  );

  const payload: PublicNodePayload = {
    nodeId,
    snapshotId: snapshot.id,
    version: snapshot.schemaVersion || 1,
    updatedAt: snapshot.createdAt,
    canvas: transformedCanvas,
    chartDatasets,
    sourceMetadata,
  };

  PublicNodePayloadSchema.parse(payload);
  return payload;
}

export function compilePortalManifest(
  snapshot: PublishedSnapshot,
  nodeIds?: string[]
): PublicPortalManifestPayload {
  const activeNodeIds = nodeIds && nodeIds.length > 0
    ? nodeIds
    : (snapshot.canvases && Object.keys(snapshot.canvases).length > 0
      ? Object.keys(snapshot.canvases)
      : [...VALID_NODES]);

  const manifest: PublicPortalManifestPayload = {
    activeSnapshotId: snapshot.id,
    publishedAt: snapshot.createdAt,
    nodeIds: activeNodeIds,
    schemaVersion: snapshot.schemaVersion || 1,
    contentOverrides: snapshot.contentOverrides || {},
  };

  PublicPortalManifestPayloadSchema.parse(manifest);
  return manifest;
}
```

### Step 5: Public Chrome Hydration Hook & Zero-CLS Layout Gate

```ts
// src/hooks/usePortalChromeHydration.ts
import { useState, useEffect } from 'react';
import { useDeveloperMode } from './useDeveloperMode';
import { setLiveContentOverrides } from '../utils/contentDb';
import type { PublicPortalManifestPayload } from '../types/edge';

export function usePortalChromeHydration(): { isHydrating: boolean } {
  const { isDevMode } = useDeveloperMode();
  const [isHydrating, setIsHydrating] = useState<boolean>(
    () => !isDevMode && typeof window !== 'undefined'
  );

  useEffect(() => {
    if (isDevMode) {
      setIsHydrating(false);
      return;
    }

    let isCancelled = false;
    fetch('/api/public/manifest')
      .then((res) => (res.ok ? (res.json() as Promise<PublicPortalManifestPayload>) : null))
      .then((manifest) => {
        if (isCancelled || !manifest) return;
        if (manifest.contentOverrides && Object.keys(manifest.contentOverrides).length > 0) {
          // Ingest strictly into memory cache; zero localStorage writes
          setLiveContentOverrides(manifest.contentOverrides, { memoryOnly: true });
        }
      })
      .catch(() => {
        // Graceful fallback to default text
      })
      .finally(() => {
        if (!isCancelled) setIsHydrating(false);
      });

    return () => {
      isCancelled = true;
    };
  }, [isDevMode]);

  return { isHydrating };
}
```
