## 🎯 Purpose & Scope

Ensure the publishing pipeline deterministically awaits the Edge KV deployment and accurately reports a 3-tier status (`Local ✔`, `Supabase ✔`, `Edge ✔`). Currently, `compileAndDeployToEdgeKV()` is executed as a fire-and-forget promise with a simple `.catch()`. If the Cloudflare KV upload fails or times out, the coordinator is told "Published successfully," while public visitors continue seeing stale, un-updated content.

This task refactors `publishNewSnapshot()` to await edge deployment, catch errors at each tier, and return a comprehensive status contract.

---

## 🔍 Problem Statement

In `src/services/historyService.ts`:
1. Lines 1144–1151 in `publishNewSnapshot()`:
   ```ts
   try {
     compileAndDeployToEdgeKV(snapshot).catch((edgeErr) => {
       console.warn('[historyService] Non-blocking Edge KV pre-bake warning:', edgeErr);
     });
   } catch (edgeDispatchErr) { ... }
   ```
2. The function returns `{ success: true, snapshot, cloudSynced, error: cloudError }` before Edge KV has even received the payload!
3. If the Cloudflare KV token is expired, network drops, or rate limits occur, the coordinator receives a success toast and closes Developer Mode, completely unaware that public visitors are seeing stale content.
4. Also, in lines 1118–1134, the Supabase active flag demotion (`PATCH is_active = false`) is executed inside an un-awaited block.

### Step 2: Await Edge KV in `publishNewSnapshot`

In `src/services/historyService.ts`:
```ts
  // Step 5: Cloud Persistence Bridge (Supabase)
  let cloudSynced = false;
  let cloudError: string | undefined;

  const config = getSupabaseConfig();
  if (config) {
    try {
      ...
      if (insertRes.ok) {
        cloudSynced = true;
        markTableAvailable('engine_history');
        // Await demotion PATCH
        try {
          const patchRes = await fetch(
            `${config.url}/rest/v1/engine_history?is_active=eq.true&id=neq.${snapshot.id}`,
            {
              method: 'PATCH',
              headers: {
                apikey: config.anonKey,
                Authorization: `Bearer ${config.anonKey}`,
                'Content-Type': 'application/json',
                Prefer: 'return=minimal',
              },
              body: JSON.stringify({ is_active: false }),
            }
          );
          if (!patchRes.ok) {
            console.warn(`[historyService] Demoting previous active snapshots returned HTTP ${patchRes.status}`);
          }
        } catch (patchErr) {
          console.warn('[historyService] Failed to demote previous active snapshots in Supabase:', patchErr);
        }
      } else {
        cloudError = `Cloud sync failed with HTTP ${insertRes.status}`;
      }
    } catch (err: unknown) {
      cloudError = err instanceof Error ? err.message : 'Network error during cloud publish';
    }
  }

  // Step 6: Await Edge Pre-Bake & KV Synchronization
  let edgeDeployed = false;
  let edgeError: string | undefined;

  try {
    const edgeResult = await compileAndDeployToEdgeKV(snapshot);
    edgeDeployed = edgeResult.success;
    if (!edgeResult.success) {
      edgeError = edgeResult.deployResult?.error || 'Edge KV deployment was rejected';
    }
  } catch (edgeDispatchErr: unknown) {
    edgeError = edgeDispatchErr instanceof Error ? edgeDispatchErr.message : 'Edge KV deployment network error';
    console.warn('[historyService] Edge KV pre-bake dispatch error:', edgeError);
  }

  // Primary success requires localSaved = true. If cloud or edge failed, success is still true
  // for the snapshot creation, but the partial failure is surfaced in the result contract.
  return {
    success: true,
    snapshot,
    localSaved: true,
    cloudSynced,
    edgeDeployed,
    cloudError,
    edgeError,
    error: cloudError || edgeError,
  };
```
