## 🎯 Purpose & Scope

Establish Cloudflare Edge KV (`/api/public/node/:nodeId`) as the **unconditional single source of truth** for public readers, stripping all synchronous `localStorage` reading and silent caching during public page visits.

Currently, public visitors load their initial canvas state synchronously from `localStorage` (`folio_live_canvas_[nodeId]`) on component mount. On cold reloads, this either flashes yesterday's stale cached version or triggers an abrupt layout pop (Cumulative Layout Shift) when the Edge KV fetch resolves 40ms later. Furthermore, when Edge KV resolves, the hook executes `saveLiveNodeCanvas(edgeData.canvas)` into `localStorage`, bloating client storage and risking 5MB `QuotaExceededError` crashes.

This task enforces an Edge-Only read model for public visitors with deterministic 3-state progression:
1. **Hydrating:** Calm ghost skeleton wireframe (`CanvasGhostWireframe`).
2. **Hydrated (Success):** Edge KV verified canvas document.
3. **Empty/Failed:** Dignified notice or graceful fallback.

---

## 🔍 Problem Statement

In `src/hooks/useDocumentCanvas.ts` and `src/services/canvasLayoutService.ts`:
1. `useDocumentCanvas(nodeId)` initializes document state via:
   ```ts
   const [document, setDocument] = useState<NodeCanvasDocument>(() => getNodeCanvas(nodeId, isDevMode));
   ```
2. For public visitors (`isDevMode = false`), `getNodeCanvas(nodeId, false)` synchronously queries `localStorage.getItem('folio_live_canvas_' + nodeId)`.
3. If a visitor has loaded the site previously, `localStorage` contains an outdated snapshot. The component paints the old snapshot immediately.
4. When the background fetch to `/api/public/node/:nodeId` completes:
   ```ts
   if (edgeData.canvas.updatedAt !== documentRef.current.updatedAt || ...) {
     documentRef.current = edgeData.canvas;
     saveLiveNodeCanvas(edgeData.canvas, { silent: true }); // Bloats localStorage!
     startTransition(() => {
       setDocument(edgeData.canvas); // Causes sudden layout jump!
     });
   }
   ```
5. In addition, `useSheetChartData.ts` checks `window.localStorage.getItem(getMatrixCacheKey(chartId))`, mixing stale tabular matrices with fresh cloud configurations.

This multi-tier fallback ladder produces race conditions, visual flashes, and quota exhaustion without delivering real user value.

## 📄 Key Files to Create / Modify

1. **`src/hooks/useDocumentCanvas.ts`** *(Modify)*
   - For public visitors (`!isDevMode`), initialize `document` to a clean empty shell (`createDefaultCanvasDocument(nodeId)`) with `isHydrating = true`.
   - Prevent public visitors from reading `localStorage` synchronously.
   - Remove `saveLiveNodeCanvas(edgeData.canvas)` from the Edge hydration callback to stop write-amplification into `localStorage`.
   - When Edge KV resolves, transition directly into the verified document without intermediate flashes.

2. **`src/services/canvasLayoutService.ts`** *(Modify)*
   - Update `getNodeCanvas(nodeId, isDevMode)`:
     - When `isDevMode === true`: Read in-memory draft session first, then draft storage.

   - Deprecate automatic module-level `migrateCanvasOverridesIntoAst('live')` for public visitors.

3. **`src/hooks/useSheetChartData.ts`** *(Modify)*
   - In public visitor mode (`!isDevMode`), do not read tabular matrices from `localStorage`. Rely strictly on Edge KV pre-baked datasets or cloud config.

### Step 3: Guard `getNodeCanvas` in `src/services/canvasLayoutService.ts`

```ts
export function getNodeCanvas(nodeId: string, isDevMode = false): NodeCanvasDocument {
  // Developer Mode: Read in-memory draft channel
  if (isDevMode) {
    const memoryDraft = getInMemoryDraftCanvas(nodeId);
    if (memoryDraft && isValidCanvasDocument(memoryDraft, nodeId)) {
      return {
        ...memoryDraft,
        sections: renumberSections(memoryDraft.sections),
      };
    }
    const storage = getStorage();
    if (storage) {
      try {
        const rawDraft = storage.getItem(getDraftCanvasKey(nodeId));
        if (rawDraft) {
          const parsedDraft = JSON.parse(rawDraft);
          if (isValidCanvasDocument(parsedDraft, nodeId)) {
            return {
              ...parsedDraft,
              sections: renumberSections(parsedDraft.sections),
            };
          }
        }
      } catch {
        // Fall through
      }
    }
    return getLiveNodeCanvas(nodeId);
  }

  // Public Mode: Return baseline shell; Edge KV is the sole authority
  return createDefaultCanvasDocument(nodeId);
}
```
