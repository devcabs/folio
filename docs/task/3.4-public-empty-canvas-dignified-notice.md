## 🎯 Purpose & Scope

Replace the dead `return null;` in `src/components/canvas/DocumentCanvas.tsx` with a calm, dignified public empty notice (`CanvasEmptyNotice`) when a published node contains no sections.

Currently, if a school or institution has published a portal where a specific strategic domain (e.g. "Resiliency" or "Governance") has not yet had narrative sections authored, the public canvas component returns `null`. This results in an empty, abrupt white space underneath the node header, causing visitors to wonder whether the page crashed or failed to load.

This task introduces a tokenized, respectful notice explaining that documentation and milestones for the selected domain are actively being compiled by the administration.

---

## 🔍 Problem Statement

In `src/components/canvas/DocumentCanvas.tsx` (lines 554–557):
```tsx
  // Empty state: In public mode render nothing once hydrated
  if ((!document || document.sections.length === 0) && !isAuthoringActive) {
    return null;
  }
```

### UX Impact:
1. When visitors navigate to an empty domain, the viewport collapses below the hero header.
2. There is no feedback confirming that the page has finished loading.
3. Visitors repeatedly click navigation links or reload the page assuming a network failure.
4. The empty page fails accessibility audits (lacking landmark content within the main document region).

## 🛠️ Step-by-Step Implementation Instructions

### Step 1: Create `src/components/canvas/CanvasEmptyNotice.tsx`

```tsx
import React, { memo } from 'react';
import { ParametricShape } from '../ui/ParametricShape';
import styles from './CanvasEmptyNotice.module.css';

export interface CanvasEmptyNoticeProps {
  nodeTitle: string;
  accentColor?: string;
  className?: string;
}

export const CanvasEmptyNotice: React.FC<CanvasEmptyNoticeProps> = memo(({
  nodeTitle,
  accentColor = 'var(--folio-primary)',
  className,
}) => {
  return (
    <section
      className={`${styles.container} ${className || ''}`.trim()}
      aria-label={`${nodeTitle} Documentation Notice`}
      tabIndex={-1}
    >
      <div className={styles.innerWrapper}>
        <div className={styles.markWrapper}>
          <ParametricShape
            sides={8}
            waviness={0.12}
            radius={22}
            fill={accentColor}
          />
        </div>

        <div className={styles.kicker}>
          {nodeTitle} Domain Documentation
        </div>

        <h3 className={styles.title}>
          Initiatives in Preparation
        </h3>

        <p className={styles.description}>
          The designated institutional coordinators are actively curating verified milestones, 
          operational narratives, and metric records for this domain. Published evidence and verified 
          receipts will appear here as entries are ratified.
        </p>

        <div className={styles.badgeRow}>
          <span className={styles.statusBadge}>
            Status: Drafting in Progress
          </span>
        </div>
      </div>
    </section>
  );
});

CanvasEmptyNotice.displayName = 'CanvasEmptyNotice';
export default CanvasEmptyNotice;
```
