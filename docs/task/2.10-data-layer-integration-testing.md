## 🛠️ Step-by-Step Implementation Instructions

### Step 1: Create `tests/data-layer-integrity.test.ts`

Cover the following test scenarios:

1. **Tombstone Content Isolation**:
   - Set live override `portal.title = "Old Live Title"`.
   - In dev mode, call `resetContent("portal.title", true)`.
   - Call `getAllContentOverrides(true)`.
   - Assert `"portal.title"` is undefined/omitted from the draft bundle.

2. **Drive Photo Sync Pagination**:
   - Mock `fetch` returning page 1 (100 items with `nextPageToken`) and page 2 (15 items without token).
   - Call `fetchDriveFolderImages("https://drive.google.com/drive/folders/test")`.
   - Assert 115 total items returned with clean titles.

3. **Google Sheets 0-Row Guard**:
   - Mock `fetchLiveSheetMatrix` returning `[]`.
   - Call `syncLiveSheet()`.
   - Assert it throws `'Google Sheet returned 0 valid data rows. Previous chart data preserved.'` and leaves existing `dataset` untouched.

4. **IndexedDB Error Observability**:
   - Simulate failing `saveToIndexedDB`.
   - Assert `EVENT_INDEXEDDB_ERROR` is fired with the error payload.

5. **Publish Pipeline Edge Await & Retry**:
   - Mock `compileAndDeployToEdgeKV` failing with `{ success: false, deployResult: { error: 'KV rate limited' } }`.
   - Call `publishNewSnapshot("Changelog test")`.
   - Assert result has `success: true`, `localSaved: true`, `cloudSynced: true`, `edgeDeployed: false`, `edgeError: 'KV rate limited'`.
   - Call `compileAndDeployToEdgeKV` again with mock success.
   - Assert retry succeeds without creating a second milestone.

6. **Restore Canvas Event Dispatch**:
   - Call `restoreUnifiedSnapshot(id)`.
   - Assert `EVENT_LIVE_CANVAS_CHANGE` was dispatched.
