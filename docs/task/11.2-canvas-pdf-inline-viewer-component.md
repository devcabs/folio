## 🎯 Purpose & Scope

Build the canonical `<CanvasPdf>` leaf component (`src/components/canvas/CanvasPdf.tsx` + `src/components/canvas/CanvasPdf.module.css`) mirroring `<CanvasPhoto>`'s mental model:
- Renders a single Google Drive PDF document inline on the canvas using an embedded `<iframe src="https://drive.google.com/file/d/{fileId}/preview">`.
- Displays a quiet, clean editorial header bar with the document title (or fallback label) and an accessible `"Open in New Tab ↗"` link (`https://drive.google.com/file/d/{fileId}/view`) so visitors and mobile readers always have a zero-friction escape hatch.
- Displays an optional editorial caption below the embedded viewer (suppressing unedited factory authoring placeholders in Public Mode).
- Renders a calm, token-styled fallback card (mirroring `CanvasPhoto`'s fallback card) when `src`/`driveUrl` is empty or cannot be resolved to a valid Google Drive file ID, with a `✎ Re-link Document` trigger in Developer Mode.
- Renders the canonical administrative side `✎ Edit` button (`sideEditWrapper` with strictly `✎ Edit` per [editorial-restraint.md](file:///Users/francisdave/Documents/folio/.agents/rules/editorial-restraint.md)) in Developer Mode (`isDevMode && isDesktop`), highlighting the card on hover (`highlightedPdf`).

### Explicit Non-Goals
- Do **not** use `pdfjs-dist`, `<object>`, or `<embed>` tags that trigger involuntary browser file downloads on mobile Safari/Chrome; strictly use the Google Drive `/preview` `<iframe>` plus the `"Open in New Tab ↗"` anchor.
- Do **not** add horizontal dividing lines (`border-bottom`, `border-top`, `<hr>`) inside the card (`editorial-restraint.md` Section 6).
- Do **not** use custom labels on the side edit button (must strictly be `✎ Edit`).

## 📐 Component & Styling Contracts

### 1. `<CanvasPdf>` Props Contract (`src/components/canvas/CanvasPdf.tsx`)
```tsx
import type { PdfElement } from '../../types/canvas';

export interface CanvasPdfProps {
  element: PdfElement;
  nodeId: string;
  accentColor?: string;
  isDevMode?: boolean;
  className?: string;
  onEdit?: () => void;
}
```

### 2. URL Resolution & Rendering Behavior
- Extract the Google Drive file ID using `extractDriveFileId(element.driveFileId || element.src || element.driveUrl || '')` from `src/utils/mediaUrl.ts`.
- Compute:
  - `previewUrl = driveFileId ? buildDrivePreviewUrl(driveFileId) : ''` (`https://drive.google.com/file/d/${driveFileId}/preview`)
  - `viewUrl = driveFileId ? buildDriveViewUrl(driveFileId) : (element.driveUrl || '')` (`https://drive.google.com/file/d/${driveFileId}/view`)
- **Valid State (`Boolean(driveFileId && previewUrl)`)**:
  - Top bar inside `.pdfCard`:
    - Document SVG icon (`aria-hidden="true"`) + document title (`element.title || 'Official PDF Document'`)
    - External link anchor (`href={viewUrl}`, `target="_blank"`, `rel="noopener noreferrer"`, `className={styles.openTabLink}`, `aria-label={`Open PDF document in new tab: ${displayTitle}`}`) displaying `Open in New Tab ↗`.
  - Embedded frame wrapper (`.iframeFrame`):
    - `<iframe src={previewUrl} title={displayTitle} className={styles.pdfIframe} loading="lazy" allow="autoplay" />`
    - Respects `element.aspectRatio` override if provided, defaulting to `var(--pdf-viewer-aspect-ratio)` with `min-height: var(--pdf-viewer-min-height)`.
  - Optional caption (`.pdfCaption`):
    - Shown when `element.caption` is non-empty, `element.showCaption !== false`, and (in Public Mode) `!isAuthoringPlaceholder(element.caption)`.
- **Fallback State (`!driveFileId || !previewUrl`)**:
  - Renders `.pdfFallbackCard` (`role="region"`, `aria-label="PDF Document Unavailable"`):
    - Crisp PDF/Document SVG icon.
    - Title: `element.title || element.caption || 'PDF Document'`.
    - Notice:
      - In Dev Mode (`isDevActive`): `'PDF document link missing or invalid. Paste a Google Drive PDF file link (Anyone with the link can view).'`
      - In Public Mode: `'Official PDF documentation is currently being prepared.'`
    - In Dev Mode (`isDevActive && onEdit`): renders `<button type="button" className={styles.fallbackEditButton} onClick={onEdit}>✎ Re-link Document</button>`.
- **Developer Mode Side Affordance (`isDevActive && onEdit`)**:
  - Alongside `.pdfCardBody` inside `.pdfCardContainer`, render `.sideEditWrapper` containing canonical `<Button variant="admin" size="xs" onClick={onEdit} data-dev-edit-trigger="true" data-canvas-edit-trigger={element.id}>✎ Edit</Button>`.

### 3. Styling & Token Discipline (`src/components/canvas/CanvasPdf.module.css`)
- **100% Token Purity**: Consume only variables from `src/styles/tokens.css` (`--pdf-viewer-aspect-ratio`, `--pdf-viewer-min-height`, `--pdf-frame-bg`, `--bg-surface`, `--bg-surface-muted`, `--border-subtle`, `--folio-primary`, `--brand-primary-tint`, `--text-primary`, `--text-secondary`, `--font-sans`, `--font-mono`, `--radius-lg`, `--radius-pill`, `--duration-fast`, `--ease-out`).
- **4-State Interactive Matrix**: `.openTabLink` and `.fallbackEditButton` implement Default, Hover (`transform: translateY(-1px)` / surface shift), Active (`transform: translateY(1px)`), Focus-Visible (`outline: none`), and Disabled states.
- **Zero Horizontal Lines**: Separate the header bar, iframe viewport, and caption via background surface contrast (`--bg-surface` vs `--pdf-frame-bg`) and padding (`var(--space-3) var(--space-4)`), never `border-bottom` or `border-top`.
