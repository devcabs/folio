## 🎯 Purpose & Scope

Build the complete Phase 2 UI component suite and canvas authoring wiring for the `documents` (PDF Folder) element, mirroring `<CanvasGallery>` and `<SourceGallery>`:
1. **`<PdfPreviewModal>` (`src/components/source/PdfPreviewModal.tsx` & `.module.css`)**:
   - Consumes the canonical `<Modal>` (`src/components/ui/Modal.tsx`) to display a full-height Google Drive PDF preview `<iframe src="https://drive.google.com/file/d/{driveFileId}/preview">` (`height: var(--pdf-modal-frame-height)`).
   - Provides Previous / Next document navigation buttons and keyboard shortcuts (`ArrowLeft` / `ArrowRight`) when the folder contains multiple PDFs, plus an `"Open in New Tab ↗"` button (`https://drive.google.com/file/d/{driveFileId}/view`) and a Dev Mode `✎ Edit` button to edit the active document's title/date/caption.
2. **`<EditDocumentModal>` (`src/components/source/EditDocumentModal.tsx`)**:
   - Clean, token-styled modal (mirroring `EditPhotoModal.tsx`) allowing coordinators in Developer Mode to customize an individual `SyncedDocumentItem`'s title (`isCustomTitle: true`), date stamp, and caption.
3. **`<SourceDocuments>` (`src/components/source/SourceDocuments.tsx` & `.module.css`)**:
   - Dedicated PDF folder list component consuming `useDriveDocumentSync` with the 5-state coexistence switch (`never_synced`, `syncing` skeleton, `synced_success` document rows, `synced_empty` `EmptyState`, `sync_error` `EmptyState`).
   - Renders each `SyncedDocumentItem` as a tactile, token-styled surface card/row (separated by vertical gap `var(--space-3)` with **zero horizontal dividing lines** per `editorial-restraint.md` Section 6), displaying a PDF badge/icon, editorial title, date stamp, `"Open ↗"` external link, and (in Dev Mode) an inline `✎ Edit` button for the document item.
   -Clicking a document row opens `<PdfPreviewModal>` at that document's index.
   - Renders the single canonical `sideEditWrapper` beside the document list in Dev Mode containing `✎ Edit` and `↻ Sync` (no duplicate footer sync button, honoring Epic 9 Subtask 9.3), plus `<SourceFolderAttachment>` in the footer.
4. **`<CanvasDocuments>` (`src/components/canvas/CanvasDocuments.tsx`)**:
   - Thin AST wrapper (mirroring `CanvasGallery.tsx`) binding `DocumentsElement` to `<SourceDocuments>` and forwarding `onUpdateDocuments` and `onEdit`.
5. **`CanvasAddBar.tsx` & `DocumentCanvas.tsx` Wiring**:
   - Upgrade the `Document` palette item in `CanvasAddBar.tsx` to a viewport-aware submenu (mirroring `Photo`):
     - `Single PDF` (`onAddElement('pdf')`)
     - `PDF Folder` (`onAddElement('documents')`)
   - In `DocumentCanvas.tsx`, render `<CanvasDocuments>` for `case 'documents'`, and unify both adding (`mode: 'add'`) and editing (`mode: 'edit'` via floating toolbar `Edit` icon AND side `✎ Edit` button) of `documents` elements onto the canonical `<LinkFolderModal>` (matching Epic 9 Subtask 9.4).

### Explicit Non-Goals
- Do **not** render horizontal divider borders (`border-bottom`, `border-top`, `<hr>`) between document cards in `SourceDocuments.module.css`.
- Do **not** render a second `↻ Sync Documents` button in the footer of `SourceDocuments` (only the single `↻ Sync` button in `sideEditWrapper` is permitted).

```tsx
import type { DocumentsElement } from '../../types/canvas';
import type { SyncedDocumentItem } from '../../types/source';

  driveUrl?: string;
  title?: string;
  subtitle?: string;
  description?: string;
  lastVerified?: string;

export interface CanvasDocumentsProps {
  element: DocumentsElement;
  nodeId: string;
  accentColor?: string;
  className?: string;

  onUpdateDocuments?: (

}
```
