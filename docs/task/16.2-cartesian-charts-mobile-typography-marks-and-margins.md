## Objective

Eliminate unreadable `2.46px–5.58px` SVG text, sub-tappable bars/points, and axis/label collisions on `320px–480px` mobile viewports across all 4 Cartesian visualizers (`BarChart`, `LineChart`, `ScatterPlot`, and `HistogramChart`).

---

## Scope & Exact File Changes

### 1. `BarChart` (`src/components/chart/BarChart.tsx`, `src/components/chart/BarChart.module.css`)
- **Responsive Dimensions:** Wire `useChartContainerWidth` + `useChartPlotArea({ width, height, isCompact })` so SVG coordinates match screen pixels on mobile.
- **Typography Floor:** Remove `@media (max-width: 640px) { .axisText { font-size: 8px; } }` and use tokenized readable mobile font sizes (`>= 10–11px` rendered for `.axisText`, `.axisTextY`, `.axisTextLeft`, `.axisTitle`, `.valueLabel`, `.valueLabelInside`).
- **Bar & Mark Sizing:**
  - Dense vertical clustered charts (`12 cats × 3 series` currently `3.85px` wide at `320px`): enforce a minimum readable bar width (e.g., `>= 10–12px` per bar or horizontal scroll wrapper on `.svgWrapper` when total required width exceeds container width).
  - Vertical stacked charts: ensure `MIN_LABEL_PIXEL_THRESHOLD` is evaluated in actual rendered pixels (`>= 16px` segment height) so tiny `1.49px` segments never collide with inside labels.
  - Horizontal clustered/stacked charts: auto-expand SVG height based on category count and series count (`minBarThickness >= 12–16px`) instead of squeezing 6 categories × 2 series into `4.67px` bars.
- **Margins & Label Truncation:**
  - Use `computeDynamicLeftMargin` for vertical `BarChart` so 6–7 digit Y-ticks (`1,500,000`) never collide with `yLabel`.
  - Align horizontal `dynamicLeftMargin` with `chartDimensions.ts` (resolving the `180` vs `160` mismatch) and ensure truncated category labels (`>16` chars) remain accessible on touch (e.g., included in tapped bar tooltip / accessible title) rather than hover-only `onPointerEnter`.
  - Prevent edge label bleed (`overflow: hidden` or safe right/top padding).

### 2. `LineChart` (`src/components/chart/LineChart.tsx`, `src/components/chart/LineChart.module.css`)
- **Responsive Dimensions & Typography:** Wire `useChartContainerWidth` + `useChartPlotArea`, remove `8px` mobile `.axisText` shrink, keep `.axisText`, `.axisTextY`, `.axisTitle`, and `.pointValueLabel` `>= 10–11px` rendered.
- **Touch Hit-Targets:** Render an invisible transparent `<circle r={18..22} fill="transparent" />` hit-target around each data point (especially critical for `compact` `r=3` and `regular` `r=5` markers which currently measure `1.86px–5.07px` on mobile).
- **Collision Avoidance & Margins:**
  - Use `computeDynamicLeftMargin` so 6–7 digit Y-ticks (`1,000,000`, `2,000,000`) never collide with `yLabel` (`"Amount (PHP)"`).
  - Apply X-tick decimation from `chartDimensions.ts` on compact viewports.
  - Add `showValues` collision avoidance / thinning on compact viewports when adjacent point value labels overlap horizontally.

### 3. `ScatterPlot` (`src/components/chart/ScatterPlot.tsx`, `src/components/chart/ScatterPlot.module.css`)
- **Responsive Dimensions & Typography:** Wire `useChartContainerWidth` + `useChartPlotArea`, remove `8px` mobile `.axisText` shrink.
- **Axis Title Parity (`ScatterPlot.module.css:130-132`):** Stop hiding `.axisTitle` with `display: none` at `<=640px` (render concise readable `10–11px` axis titles so mobile readers don't lose axis units/meaning, and only reserve `xLabel`/`yLabel` margin when the label is actually rendered).
- **Touch Hit-Targets:** Add transparent `r >= 18–22` hit-targets around each scatter point (`compact` `r=3` / `regular` `r=5`).
- **Margins:** Use `computeDynamicLeftMargin` for wide Y-ticks.

### 4. `HistogramChart` (`src/components/chart/HistogramChart.tsx`, `src/components/chart/HistogramChart.module.css`)
- **Responsive Dimensions & Typography:** Wire `useChartContainerWidth` + `useChartPlotArea`, remove `8px` mobile `.axisText` shrink, keep `.axisText`, `.axisTextY`, `.axisTitle`, and `.meanLabel` `>= 10–11px` rendered.
- **Bar & Hit Sizing:** Ensure minimum visual/tappable hit area for short 1-unit frequency bars in skewed distributions (`<9px` height at `320px`) via transparent full-column or min-height hit rect.
- **Margins, Tick Thinning & `.meanLabel` Edge Flip:**
  - Use `computeDynamicLeftMargin` for wide Y-ticks.
  - Decimate dense bin range labels (`x0–x1`) on compact viewports.
  - Flip `.meanLabel` to `text-anchor: end` (`x={meanXPosition - 4}`) when `meanXPosition` is near the right edge of the plot (e.g., `> 80%` of plot width) so right-skewed mean labels never clip off the right edge.
