## 🎯 Purpose & Scope

Implement user-facing Dev Mode notification in consumer applications. When dev mode is activated/unlocked:
1. Fire a prominent sticky Toast: `"⚠️ Folio Engine updated to v0.1.X: N content migration(s) pending"` with action button **`[Review]`**.
2. Show a persistent indicator pill in `DevModeBadge` (`⚠️ N Migrations`).
3. Clicking `[Review]` or the badge pill opens `DevMigrationModal`.

## 📄 Key Files to Create / Modify

1. **`src/components/dev/DevMigrationModal.tsx`** & **`DevMigrationModal.module.css`** *(New)*
   - Accessible modal wrapping canonical `Modal` primitive.
   - Header: Version comparison badge (`v{watermark} ➔ v{engineVersion}`) and summary pill.
   - Body: List of unapplied content migrations:
     - Badge for `REQUIRED` vs `RECOMMENDED`.
     - Affected files/entities list.
     - Description and specific required data shapes.
   - Footer / Actions:
     - **"Copy AI Migration Prompt"**: Copies markdown instructions to clipboard with visual copied feedback.
     - **"Mark as Migrated"**: Calls `setContentVersionWatermark(engineVersion)`, dismisses modal, and shows success toast.
     - **"Dismiss"**: Closes modal while leaving indicator pill visible in `DevModeBadge`.

2. **`src/context/DeveloperModeContext.tsx`** *(Modify)*
   - When `isDevMode` is set to `true` (PIN unlock or valid session):
     - Check `getPendingMigrations()`.
     - If `report.hasPendingContentChanges`, show the sticky action toast:
       ```typescript
       setToastState({
         message: `⚠️ Engine updated to v${report.currentEngineVersion}: ${report.pendingContentChanges.length} content migration(s) pending`,
         type: 'info',
         actionLabel: 'Review',
         onAction: () => setIsMigrationModalOpen(true),
         durationMs: 8000,
       });
       ```

3. **`src/components/dev/DevModeBadge.tsx`** *(Modify)*
   - When pending content migrations exist, render warning badge pill:
     `⚠️ {count} Pending Migration(s)`
   - Clicking opens `DevMigrationModal`.

4. **`src/components/dev/index.ts`** & **`src/App.tsx`** *(Modify)*
   - Export and mount `DevMigrationModal`.
