## Objective

Fix the tiny `73.8px` Donut ring and unreadable center callout on mobile, prevent `reset.css` `button { min-height: 44px; min-width: 44px; }` from inflating `ChartLegend` pills into `244px`-tall stacks and distorting compact buttons, and add `onClick` tap-toggle to `ChartLegend`.

---

## Scope & Exact File Changes

### 1. `DonutChart` (`src/components/chart/DonutChart.tsx`, `src/components/chart/DonutChart.module.css`)
- **Responsive Square-ish Mobile `viewBox`:**
  - Wire `useChartContainerWidth` + responsive `viewBox` dimensions (`isCompact` uses a square-ish coordinate frame, e.g., `width × width` clamped to `220–280px` height instead of `800×360` landscape) so horizontal whitespace isn't wasted and the ring renders at a clear `~160–200px` diameter at `320px`.
- **Readable Typography Floor:**
  - Ensure `.centerTotalText`, `.centerCategoryText`, `.centerMetricText`, and `.sliceValueText` render at `>= 10–11px` actual screen pixels on `320px–480px` (previously `3.38px–8.00px`).
  - Hide or abbreviate `.sliceValueText` on narrow slivers where arc length cannot fit the label cleanly without overlap.
- **`"Others"` Slice Contrast:**
  - Replace `var(--bg-surface-muted)` (`#f7f5f2`, low contrast against white surface) on the long-tail `"Others"` slice with the semantic `--chart-donut-others-fill` token defined in Subtask 16.1.

### 2. `ChartLegend` (`src/components/chart/ChartLegend.tsx`, `src/components/chart/ChartLegend.module.css`)
- **Contain `reset.css` `44×44px` Inflation:**
  - Add `min-height: var(--chart-legend-pill-min-height); min-width: unset;` (or `min-height: unset; min-width: unset;` with compact tokenized padding) on `.legendItem` so a 5-item Donut legend wraps into a compact `~68–96px` block instead of a `244px` tower (`2.20×` SVG height at `320px`).
- **Tap-Toggle Isolation (`ChartLegend.tsx:39-48`):**
  - Add an `onClick` handler to legend item buttons so tapping an unselected item isolates it (`aria-pressed="true"`) and **tapping the same item a second time clears isolation (`aria-pressed="false"`)** on touchscreens.
  - Preserve desktop hover (`onMouseEnter`/`onMouseLeave`) and keyboard (`onFocus`/`onBlur`) without conflict when a series is pinned via click/tap.

### 3. `reset.css` Leakage Containment on Chart UI Buttons
- **[src/components/chart/ChartTableModal.module.css](file:///Users/francisdave/Documents/folio/src/components/chart/ChartTableModal.module.css)** & **[src/components/ui/Modal.module.css](file:///Users/francisdave/Documents/folio/src/components/ui/Modal.module.css)**:
  - Ensure `.closeButton` sets explicit sizing (`min-height: unset; min-width: unset;` or adopts canonical `IconButton` sizing) instead of silently expanding from `28×28px` to `44×44px` via `reset.css`.
- **[src/components/ui/Drawer.module.css](file:///Users/francisdave/Documents/folio/src/components/ui/Drawer.module.css)**:
  - Ensure `.closeButton` (`36×36px`) explicitly controls its `min-width`/`min-height` without unintended `reset.css` override.
- **[src/components/ui/TieredSlider.module.css](file:///Users/francisdave/Documents/folio/src/components/ui/TieredSlider.module.css)**:
  - Override `reset.css` `min-height: 44px; min-width: 44px;` on `.tierBtn` (`Responsive`, `Balanced`, `Broad`) with clean tokenized compact sizing, and ensure the range slider thumb is comfortable to drag on touch (`>= 24–28px` touch area).

## Non-Goals

- Do not remove the global `reset.css` accessibility rule — contain it surgically on components that intentionally define compact pill/icon dimensions.
- Do not change `ChartTooltip` clamping or touch dismiss (Subtask 16.4).
