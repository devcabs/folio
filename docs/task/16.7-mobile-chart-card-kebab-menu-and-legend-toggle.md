# Subtask 16.7: Mobile `ChartCard` Top-Right Kebab Menu, Consolidated Actions & Legend Highlight-View Toggle

## Objective

Declutter `ChartCard` on mobile (`<= 640px`) by consolidating secondary footer actions (`View Table`, `Download Data (CSV)`) into a single top-right `⋮` kebab menu (`IconButton` + accessible `role="menu"` popover), and add an optional **Show Legend** (`role="menuitemcheckbox"`) toggle inside the kebab menu so readers can switch to a distraction-free highlight view on demand while keeping legends visible by default.

---

## Scope & Exact File Changes

### 1. Design Tokens & Canonical Icon
- **[src/styles/tokens.css](file:///Users/francisdave/Documents/folio/src/styles/tokens.css)**:
  - Add `--chart-kebab-menu-min-width: 192px;` and `--chart-kebab-menu-z: 30;` (consuming existing surface, border, shadow, and spacing tokens; zero hardcoded `#hex`/`rgba()`).
- **[src/components/ui/Icons.tsx](file:///Users/francisdave/Documents/folio/src/components/ui/Icons.tsx)** & **[src/components/ui/index.ts](file:///Users/francisdave/Documents/folio/src/components/ui/index.ts)**:
  - Add and export `MoreVerticalIcon` (`⋮` three-dot vertical kebab SVG) so `ChartCard` consumes a canonical UI icon rather than inline `<svg>` markup.

### 2. Optional `showLegend` Prop Across `ChartRouter` & Visualizers
- **[src/components/chart/ChartRouter.tsx](file:///Users/francisdave/Documents/folio/src/components/chart/ChartRouter.tsx)**:
  - Add `showLegend?: boolean` (default `true`) to `ChartRouterProps` and forward it to `BarChart`, `LineChart`, `DonutChart`, `ScatterPlot`, and `HistogramChart`.
- **[src/components/chart/BarChart.tsx](file:///Users/francisdave/Documents/folio/src/components/chart/BarChart.tsx)**, **[LineChart.tsx](file:///Users/francisdave/Documents/folio/src/components/chart/LineChart.tsx)**, **[DonutChart.tsx](file:///Users/francisdave/Documents/folio/src/components/chart/DonutChart.tsx)**, **[ScatterPlot.tsx](file:///Users/francisdave/Documents/folio/src/components/chart/ScatterPlot.tsx)**, **[HistogramChart.tsx](file:///Users/francisdave/Documents/folio/src/components/chart/HistogramChart.tsx)**:
  - Accept optional `showLegend?: boolean` (default `true`); when `showLegend === false`, omit `<ChartLegend />` so the chart renders in a clean highlight view.

### 3. `ChartCard` Mobile Kebab Menu & Footer Consolidation
- **[src/components/chart/ChartCard.tsx](file:///Users/francisdave/Documents/folio/src/components/chart/ChartCard.tsx)** & **[src/components/chart/ChartCard.module.css](file:///Users/francisdave/Documents/folio/src/components/chart/ChartCard.module.css)**:
  - Add a top-right `IconButton` (`MoreVerticalIcon`, `aria-label="Chart actions"`, `aria-haspopup="menu"`, `aria-expanded={isKebabOpen}`) in `.header` when `hasData` is true, shown at `<= 640px` and hidden on desktop (`> 640px`).
  - Render an anchored `role="menu"` popover containing:
    1. **View Table** (`role="menuitem"`) — opens `ChartTableModal` and closes the menu.
    2. **Download Data (CSV)** (`role="menuitem"`) — triggers `handleDownloadCsv` and closes the menu.
    3. **Show Legend** (`role="menuitemcheckbox"`, `aria-checked={showLegend}`) — toggles `showLegend` state (default `true`) for optional highlight-view mode.
  - Dismiss the menu on `Escape` keydown or outside `pointerdown`.
  - On `<= 640px`, hide `.footerActions` in `.footer` (avoiding duplicate action buttons) while preserving `.asOfCaption` and desktop (`> 640px`) footer layout.
  - Ensure `ChartCard` uses canonical `IconButton` / `Button` primitives (`0` raw `<button>` elements) and enforces the 4-state interactive matrix + Universal Zero Outline Policy (`outline: none;`).

---

## Non-Goals

- Do not hide legends by default on mobile (`showLegend` defaults to `true` so color-encoded charts remain self-contained at a glance).
- Do not change desktop (`> 640px`) `ChartCard` header/footer layout.
