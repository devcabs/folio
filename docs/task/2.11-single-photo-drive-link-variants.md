## 🎯 Purpose & Scope

Enable coordinators to paste **any valid Google Drive single-photo link variant** into the Photo edit modal or canvas photo element and have it resolve instantaneously into a crisp, renderable high-resolution image. 

> [!IMPORTANT]
> **Strict Single-Photo Scope:** This parsing engine operates **ONLY for single photos** (Photo elements, hero images, and thumbnail overrides). It must **explicitly reject or disallow folder links** (`/folders/`), which belong exclusively to Galleries and Source photo synchronization.

## 🔍 Problem Statement

In `src/utils/mediaUrl.ts` and `src/components/dev/UniversalEditModal.tsx`:
1. `extractDriveFileId` in `src/utils/mediaUrl.ts`:
   ```ts

   ```
   This conflated folder IDs with file IDs. If a user pasted a folder link into a photo box, it attempted to render a folder as an image, causing broken image icons.
2. In `UniversalEditModal.tsx` (lines 702–722):

The modal's `<img src={canvasDraft.src} />` attempts to load an HTML web page as an image binary, displaying a broken image preview!
3. Coordinators paste many different variants from desktop browsers, Google Drive mobile apps, and multi-account Google Workspace profiles:
   - `/file/d/:id/view?usp=sharing` (standard web share)
   - `/file/d/:id/preview` (embedded preview)
   - `/file/d/:id` (bare path without `/view`)
   - `/open?id=:id` (open link)
   - `/uc?id=:id` or `/uc?export=view&id=:id` (direct stream endpoint)
   - `/thumbnail?id=:id&sz=w1600` (permanent thumbnail link)
   - `https://lh3.googleusercontent.com/d/:id` or `=s1600` (Google user content direct CDN)
   - `https://lh3.googleusercontent.com/drive-viewer/:id` (Drive viewer mobile web asset)
   - `https://drive.google.com/u/1/file/d/:id/...` (multi-account URL prefixes)
   - Raw 28–44 character alphanumeric file IDs (direct ID paste)
   - URLs wrapped in angle brackets or quotes (e.g. `<https://...>` or `"https://..."`)

## 🛠️ Step-by-Step Implementation Instructions

### Step 1: Upgrade `extractDriveFileId` in `src/utils/mediaUrl.ts`

Replace `extractDriveFileId` with the multi-variant extractor (strictly excluding folders):
```ts
const DRIVE_FILE_ID_REGEX = /^[a-zA-Z0-9_-]{10,64}$/;

/**
 * Extracts a Google Drive alphanumeric file ID specifically for SINGLE PHOTOS.
 * Strictly ignores and rejects folder URLs (/folders/).
 */
export function extractDriveFileId(input: string): string | null {
  if (!input || typeof input !== 'string') return null;

  // 1. Sanitize input (strip surrounding whitespace, angle brackets, and quotes)
  const trimmed = input.trim().replace(/^<|>$/g, '').replace(/^["']|["']$/g, '').trim();
  if (!trimmed) return null;

  // 2. Reject folder links explicitly (Single Photos ONLY)
  if (trimmed.includes('/folders/') || trimmed.includes('drive.google.com/drive/u/')) {
    if (trimmed.includes('/folders/')) {
      return null;
    }
  }

  // 3. Direct alphanumeric file ID
  if (DRIVE_FILE_ID_REGEX.test(trimmed)) {
    return trimmed;
  }

  // 4. Query param ?id=... or &id=... (covers /open?id=, /uc?id=, /thumbnail?id=)
  const queryMatch = trimmed.match(/[?&]id=([a-zA-Z0-9_-]{10,64})/);
  if (queryMatch?.[1] && DRIVE_FILE_ID_REGEX.test(queryMatch[1])) {
    return queryMatch[1];
  }

  // 5. Standard path /d/FILE_ID or /d/FILE_ID/view or /d/FILE_ID/preview
  // Handles multi-account prefixes like /u/0/file/d/..., /u/1/d/...
  const dPathMatch = trimmed.match(/\/d\/([a-zA-Z0-9_-]{10,64})/);
  if (dPathMatch?.[1] && DRIVE_FILE_ID_REGEX.test(dPathMatch[1])) {
    return dPathMatch[1];
  }

  // 6. Google User Content CDN: lh3.googleusercontent.com/d/FILE_ID or drive-viewer/FILE_ID
  const lhMatch = trimmed.match(/googleusercontent\.com\/(?:d|drive-viewer)\/([a-zA-Z0-9_-]{10,64})/);
  if (lhMatch?.[1] && DRIVE_FILE_ID_REGEX.test(lhMatch[1])) {
    return lhMatch[1];
  }

  // 7. Direct file view path: /file/d/FILE_ID
  const fileDMatch = trimmed.match(/\/file\/d\/([a-zA-Z0-9_-]{10,64})/);
  if (fileDMatch?.[1] && DRIVE_FILE_ID_REGEX.test(fileDMatch[1])) {
    return fileDMatch[1];
  }

  return null;
}
```

### Step 2: Add `resolveSingleDrivePhotoUrl` in `src/utils/mediaUrl.ts`

```ts
export interface ResolvedSinglePhoto {
  fileId: string;
  displayUrl: string;
  thumbnailUrl: string;
  rawUrl: string;
}

/**
 * Resolves any valid Google Drive single-photo link variant into permanent,
 * renderable image URLs suitable for <img> tags and canvas AST persistence.
 * Returns null if the URL is invalid or is a folder URL.
 */
export function resolveSingleDrivePhotoUrl(input: string): ResolvedSinglePhoto | null {
  const fileId = extractDriveFileId(input);
  if (!fileId) return null;

  return {
    fileId,
    displayUrl: `https://drive.google.com/thumbnail?id=${encodeURIComponent(fileId)}&sz=w1600`,
    thumbnailUrl: `https://drive.google.com/thumbnail?id=${encodeURIComponent(fileId)}&sz=w320`,
    rawUrl: input.trim(),
  };
}
```
