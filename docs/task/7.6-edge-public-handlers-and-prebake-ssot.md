## 🎯 Purpose & Scope

Eliminate synthetic HTTP 200 cold-miss fallbacks, sidecar `/api/public/chart/:chartId` routes, static JSON merging during pre-baking, and duplicate edge utilities/KV bindings across `src/edge/handlers/publicHandler.ts`, `src/services/edgePreBakeService.ts`, `src/edge/router.ts`, and `functions/api/`:
1. **Fail-Stop on KV Cold Miss or Missing Binding (`src/edge/handlers/publicHandler.ts`)**:
   - In `handlePublicNodeRoute()` and `handlePublicManifestRoute()`:
     - If `!kv`, return `HTTP 503 Service Unavailable` with `{ error: 'KV namespace binding not configured' }`.
     - If `await kv.get(kvKey)` returns `null`, return `HTTP 404 Not Found` with `{ error: 'Resource not found in Edge KV' }`—**never** return `HTTP 200` with fabricated `SUPABASE_FALLBACK` empty canvases/manifests.
   - Remove `handlePublicChartRoute()` (`/api/public/chart/:chartId` and `STATIC_FALLBACK` to `baked-charts.json`) because all chart configurations and datasets are embedded directly inside `ChartElement` in the `NodeCanvasDocument` AST served by `GET /api/public/node/:nodeId`.
2. **Self-Contained AST Pre-Bake Compiler (`src/services/edgePreBakeService.ts`)**:
   - Remove `import bakedChartsData from '../data/baked-charts.json'` and `import baselineSourcesRaw from '../data/source-sources.json'` from `edgePreBakeService.ts`.
   - Remove `gatherIndicatorDatasets()` and `gatherSourceMetadata()` sidecar map builders.
   - `compilePublicNodePayload(nodeId, snapshot)` must validate that `snapshot.canvases[nodeId]` exists (throwing an explicit `Error` if missing), pre-bake responsive image `srcSet`/`sizes` on `PhotoElement` and `GalleryElement.syncedPhotos` items, and validate that every `ChartElement` in the AST carries its self-contained `dataset` and `config`.
3. **Deduplicate Edge Shared Utilities & KV Binding Resolution (`functions/api/public/_shared.ts`, `src/edge/router.ts`, `functions/api/**/*.ts`)**:
   - Re-export `createEdgeJsonResponse`, `checkConditionalGet`, `CACHE_CONTROL_EDGE`, and `CACHE_CONTROL_FALLBACK` in `functions/api/public/_shared.ts` directly from `src/edge/handlers/publicHandler.ts`.
   - Resolve the KV namespace strictly via `resolveKVNamespace()` from `src/edge/router.ts` (`env.KV_ENGINE_PUBLIC`), removing the legacy `env.KV_MASID_PUBLIC` fallback across `router.ts` and `functions/api/**/*.ts`.

## 🔍 Forensic Audit Findings Addressed

1. **[V6.1] Cold-Miss Synthetic HTTP 200 Fallbacks & Sidecar Chart Route in Edge Public Handlers**
   - **Locations**: [publicHandler.ts](file:///Users/francisdave/Documents/folio/src/edge/handlers/publicHandler.ts#L114-L156), [publicHandler.ts](file:///Users/francisdave/Documents/folio/src/edge/handlers/publicHandler.ts#L180-L214), [publicHandler.ts](file:///Users/francisdave/Documents/folio/src/edge/handlers/publicHandler.ts#L230-L311)
   - **Conflicting Sources / Fallback Chain**:
     - `handlePublicNodeRoute`: Cloudflare KV `node:${nodeId}` → synthetic `fallbackPayload` (`snapshotId: 'snapshot-latest'`, `sections: []`) returned with `HTTP 200` and `X-Engine-Edge-Source: SUPABASE_FALLBACK`.
     - `handlePublicManifestRoute`: Cloudflare KV `portal:manifest` → synthetic `fallbackManifest` (`activeSnapshotId: 'snapshot-latest'`) returned with `HTTP 200` and `X-Engine-Edge-Source: SUPABASE_FALLBACK`.
     - `handlePublicChartRoute`: Sidecar KV `chart:${chartId}` → static `src/data/baked-charts.json` returned with `HTTP 200` and `X-Engine-Edge-Source: STATIC_FALLBACK`.
   - **Why It Violates SSOT**: Returns `HTTP 200` with fabricated payloads or static bundled JSON when Cloudflare KV is unbound or unpopulated instead of failing stop, and maintains a separate `chart:${chartId}` KV key outside the Node Canvas AST.

2. **[V6.2] Static JSON Merging & Sidecar Slicing in `edgePreBakeService.ts`**
   - **Locations**: [edgePreBakeService.ts](file:///Users/francisdave/Documents/folio/src/services/edgePreBakeService.ts#L40-L41), [edgePreBakeService.ts](file:///Users/francisdave/Documents/folio/src/services/edgePreBakeService.ts#L141-L252)
   - **Conflicting Sources / Fallback Chain**:
     - `gatherIndicatorDatasets` (L141–166): Static `src/data/baked-charts.json` → `snapshot.chartConfigs` → `options.chartDatasets`.
     - `gatherSourceMetadata` (L171–201): Static `src/data/source-sources.json` → `snapshot.sourceMetadata` → `options.sourceMetadata`.
   - **Why It Violates SSOT**: Mixes static repository JSON files and sidecar maps into published KV payloads instead of compiling a self-contained `NodeCanvasDocument` AST.

3. **[V6.3] Duplicate Edge Response Helpers & Dual KV Binding Fallback**
   - **Locations**: [_shared.ts](file:///Users/francisdave/Documents/folio/functions/api/public/_shared.ts#L12-L66), [publicHandler.ts](file:///Users/francisdave/Documents/folio/src/edge/handlers/publicHandler.ts#L19-L81), [router.ts](file:///Users/francisdave/Documents/folio/src/edge/router.ts#L40-L47), [functions/api/publish.ts](file:///Users/francisdave/Documents/folio/functions/api/publish.ts#L22)
   - **Conflicting Sources / Fallback Chain**: `env.KV_ENGINE_PUBLIC || env.KV_MASID_PUBLIC || null`; duplicate `createEdgeJsonResponse` and `checkConditionalGet` with conflicting `Cache-Control` headers.
   - **Why It Violates SSOT**: Maintains two separate definitions of edge response utilities and falls back across two KV bindings.
